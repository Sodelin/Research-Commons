## Receipt binding

Each receipt records a canonical input SHA256, every Python source hash plus the registry hash, the original reused artifact hashes, operation and complete result. Verification checks binding and reruns the actual operation. Changed inputs, changed result bytes, changed code or changed source binding invalidate the receipt. This is an integrity/reproducibility mechanism; it is not cryptographic authentication, a proof assistant, or empirical biological validation.

No whole-program Lean certification is claimed. The public project's accepted Lean components retain separate assumptions and are not automatically imported as a certificate for this Python package. No gated WABI E1–E8 extensions were implemented.
