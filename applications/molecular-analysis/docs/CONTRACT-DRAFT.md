# Molecular applications v1: interface draft

Two modules, haplotype and RNA processing, share a validated Context and Prediction contract. Coordinates are canonical 0-based half-open; input variants carry explicit 1-based VCF positions, reference and alternate ACGT alleles, chromosome and variant ID. Human assembly GRCh38.p13/hg38. Reference sequence and transcript annotation carry source IDs, version and hashes. Gene/transcript bounds/strand must lie in the reference window. No guessed phase: cis requires evidence; hypothetical is explicit; trans and unknown remain separate scenarios. All four REF/A/B/AB sequences must have the same model length, anchor/window, tissue ontology, strand, model/version, outputs and preprocessing. Reject overlapping edits; anchored indels must retain an explicit coordinate map and common crop/pad policy. No unspecified diploid aggregation.

Context JSON fields (draft): assembly, chromosome, window_start, window_end, sequence, reference_source, reference_sha256, gene_id, transcript_id, annotation_source, annotation_version, transcript_start, transcript_end, strand, tissue, model_version, output_types, sequence_length, preprocessing. Haplotype fields: variants[2] each id/chromosome/position/ref/alt; phase.kind cis|trans|unknown|hypothetical and phase.evidence; endpoint with family/output_type/aggregation/scale/pseudocount/region. Bounds/config are validated before any provider call.

Prediction is one sequence result: context identity including all settings; scenario ID; input-sequence digest; outputs keyed by supported output_type, each containing track metadata (tissue, strand, gene/transcript), coordinate-origin/bin-size and finite values. A provider protocol supplies capabilities and predict_sequence(context, scenario, sequence). Deterministic mock provider emits explicitly SYNTHETIC output. Official Python SDK adapter loads lazily and returns a structured blocker if SDK/key/approved terms/model/output/tissue cannot be supplied. No network in default mode.

Expression uses RNA_SEQ abundance tracks under a declared mask/aggregation. Splice sites, site usage and junctions remain distinct supported direct modalities. PAS usage is a derived score from RNA_SEQ and explicit 3-prime site annotations; unavailable outputs return unsupported rather than fabricated tracks. Signed per-allele y on one declared scale can define I=yAB-yA-yB+yREF. AVI/quantile ranks cannot be summed; predicted nonadditivity is a model prediction.

Result schema has computation status SUCCESS|INVALID_INPUT|UNSUPPORTED|UNKNOWN|RESOURCE_LIMIT|EXECUTION_FAILURE, evidence MOCK_SYNTHETIC|REAL_MODEL_PREDICTION, biological_conclusion_established:false, input/settings/source/build digests, every scenario+phase, endpoint semantics direct|derived|unavailable, raw/derived values and direction. Missing capabilities preserve unavailable quantities. No G6/G7 applicability or clinical claim is inferred. CLI and laterGUI call identical service functions.

Root will freeze exact Python dataclass signatures before worker integration. Std-only Rust core validates assemblies/coordinates/alleles/phase and constructs sequences behind a bounded test/CLI bridge, avoiding new dependency installations for offline delivery. No custom SDK implementation.
