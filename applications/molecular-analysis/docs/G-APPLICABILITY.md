# Application contract and the original G programme

These are new molecular application modules, not G8 and not a closure of G3/G4 or a supplier of the missing RNA/E8 grammar, weights or proofs. No accepted theorem or production solver is replaced.

| Layer | Current application contract | Requirement for a G connection |
|---|---|---|
| Source | Versioned reference sequence, transcript/site annotations, two edits and an evidence-labelled phase scenario; one sequence per haplotype. | Specify the original admitted biological source and its shared parameters. A supplied string or AlphaGenome input is not automatically such a source. |
| Observation | Model-predicted RNA coverage, site probabilities/use fractions and explicitly derived endpoints. Offline observations are synthetic fixtures. | Define the actual experimental joint observation law, assay noise, sampling unit and calibration. A predicted track is not a sampled fresh-locus outcome. |
| Target | Declared-scale endpoint changes and hypothetical combined nonadditivity. No actual history, diploid phenotype, disease classification or causal interaction is established. | State an identifiable target and the correspondence from original source to observation. More prediction features do not resolve non-identifiability. |
| Action | Initially computation and comparison; later a predeclared experiment/assay choice under a budget. | For G7, specify available actions, costs, likelihoods, admissible policies and target loss; validate the law rather than assuming model scores supply it. |

A possible G6 use is certification of a finite candidate set only after an explicit, justified source–observation map and quantitative uncertainty bounds are available. Existing JC/count concentration, rational interval tests and Lean source approximations do not bound AlphaGenome model discrepancy or turn predicted expression into calibrated confidence. Any application certificate must state its sampling and discrepancy premises and demonstrate applicability.

A possible G7 use is choosing which variant combination, tissue and RNA assay to measure next. The present software can retain those candidate contexts and endpoints. It does not yet provide the exact joint laws or validated approximate design conditions required by the original theorems. Such a design system is a future applicability project, with separate evidence and review.

RNA-seq names an assay; alternative splicing and polyadenylation name biological processes. They do not define a historical grammar. Experimental validation of a molecular prediction can demonstrate useful application behavior while the general historical recognition questions remain open.
