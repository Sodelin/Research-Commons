# Public application integration

Nolan authorized public open-source integration of these named research
applications on 8 October 2026, superseding their earlier implementation hold.
This authorization does not release unrelated private material. Application
code owned by Research Commons contributors uses Apache 2.0; external data,
libraries and service outputs retain their own terms.

Preserve the inherited source identities in MIGRATION-PROVENANCE.json and
record subsequent changes as derivatives. Existing mathematical assumptions,
UNKNOWN results and evidence tiers must remain visible. Keep keys, personal
genomes and raw private receipts out of this directory. No professor contact,
endorsement, deployment, live inference or persistent credential access is
authorized by this migration. Default scientific integration uses offline
fixtures or saved, explicitly labeled public-data receipts.

The original Cloud team retains Lean compiler scheduling. Application workers
must not launch competing Lean builds or alter its owned release inputs.
