## 2. The exact return-time set is an open upper ray

Write h=-log q. Define

    R_m = {h>0 : some finite nonempty strict W has K_m(W)=E(exp(-h))_m}.

If R_m is empty put tau_m=infinity. Otherwise put tau_m=inf R_m. Then

    R_m = (tau_m,infinity).                                      (1)

The endpoint is NOT included.

Proof of upward closure: if W realizes time h and h'>h, increase its existing leading ordinary duration by h'-h. This remains a legal strict word with the same positive number of bigons and realizes E(exp(-h')). No inverse population is used.

Proof that every attained time has an attained interval below it: write the existing leading ordinary factor as E(exp(-ell)), ell>0, so W=E(exp(-ell)) V. Multiplicativity of pair survival gives h=ell+h(V)>ell, since V contains a strict bigon and all its pair-survival factors are at most one, with a strictly smaller one. For any 0<delta<ell, shorten the same leading duration to ell-delta. Its kernel is algebraically

    E(exp(-(ell-delta))) V = E(exp(delta)) K_m(W)
                           = E(exp(-(h-delta))).

E(exp(delta)) appears only as the algebraic cancellation identity; the actual realizing word has leading duration ell-delta>0 and all remaining parameters unchanged. Also h-delta>0. Thus no positive attained h can be the lower endpoint. Upward closure and the definition of infimum now prove (1).

Exactly the same proof applies with a FIXED number L>=1 of bigons. Its return set is empty or an open upper ray. No regularity or full Jacobian rank at the realizing parameter is required. Shortening the already positive leading edge is why a closed lower endpoint is excluded under this grammar.

## 3. Caps and the fixed-target dichotomy

Restriction in arity gives R_(m+1) subset R_m, hence

    0<=tau_2<=tau_3<=...<=infinity.

Let tau_* = sup_(m>=2) tau_m. For one fixed time h>0 the exact equivalence is

    nonempty strict ordinary rivals exist at EVERY full finite cap
       iff tau_m<h for EVERY m.                              (2)

The left side retains one fixed E(exp(-h)); only the finite positive rival may vary. Every finite original completion prefix has a finite entering-root cap, so the left side supplies an exact full-prefix rival within this private interface. Its later inequivalence follows from the inherited all-copy normal form. Conversely, faithful full-topology tomography means that a cap m with h not in R_m provides finitely many legal observations excluding EVERY nonempty private word, regardless of length.

Consequently:

- If h>tau_*, every finite cap has a later-inequivalent strict rival at this SAME target.
- If 0<h<tau_*, some finite cap excludes every nonempty strict private word.
- At 0<h=tau_*<infinity, the answer depends on whether any finite tau_m equals tau_*. If none does, (2) holds; if one does, that cap excludes all such words.
- If tau_*=infinity, every positive finite ordinary time has a finite determining cap against this private class, as an existence statement only.
- If tau_*=0, every positive ordinary time has full-prefix rivals, as in the stronger uniform-small-time construction goal.

In particular, existence of SOME fixed positive ordinary target with full-prefix private rivals is equivalent to

    sup_m tau_m < infinity.                                  (3)

The forward implication uses tau_m<h. For the reverse choose any finite h strictly above the supremum. Equivalently, in survival coordinates r_m=exp(-tau_m), with exp(-infinity)=0, one needs inf_m r_m>0. A rational q strictly below a proved positive lower bound for all r_m gives an explicit fixed target.

This identifies a weaker sufficient research goal than arbitrarily-small-time returns at every cap: exact full returns with one UNIFORM FINITE pair-hazard budget across all caps already suffice. Failed small-parameter ansatzes do not exclude that nonperturbative possibility. On the other hand, separate finite-cap returns with unbounded costs tau_m do not suffice for a fixed-target counterexample.

The scalar thresholds are an organizational reduction. Computing or bounding them retains ALL diagonal and commutator equations. No full forest relation has been replaced by a single scalar observable.

## 4. Effectivity is one-sided without a new theorem

For fixed m,L, the actual forest source map is polynomial over the rationals in strict survival/coin parameters. Its exact ordinary-return survival set is the projection of a finite semialgebraic system, so it is effectively semialgebraic by real-closed-field quantifier elimination. By Section 2 it is empty or (0,r_(m,L)) inside (0,1), with r_(m,L) a real algebraic endpoint (including 0 or 1). This statement does not assert that arbitrary-length r_m is algebraic.

For a specified algebraic q and fixed m, enumerate L>=1 and apply exact feasibility to the full capped equations. This halts with one positive algebraic witness whenever q<r_m. It does not halt with a NO merely because arbitrarily many lengths fail. Thus a proved uniform bound in (3), with a specified q below it, would give finite exact witness selection at every requested cap without a guessed length budget.

Conversely, tau_*=infinity alone is neither an effective way to find a suitable m from response data nor an all-original-source G4 stopping theorem. Supplied descriptions, rival-size promises, arbitrary-real equality oracles and finite numerical tolerances are not silently added.
