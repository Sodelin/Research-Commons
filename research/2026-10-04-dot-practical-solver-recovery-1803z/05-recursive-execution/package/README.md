## CAD selector work

Unsupported cylinder shapes or failed/partial checks produce UNKNOWN.

Wolfram 15.0.1 passed a history-dependent algebraic interval/section control and a source-derived winning-action fibre. The actual fibre is obtained from complete source-pair exclusion, with original identities preserved by wolfram_export.py; adding old observations cannot create a source collision excluded before history. The fibre selects weight 1/2 with coverage and soundness True. Raw results retain the service's benign fresh-function-name warnings.

This function is not yet a complete deployed adaptive policy compiler.
