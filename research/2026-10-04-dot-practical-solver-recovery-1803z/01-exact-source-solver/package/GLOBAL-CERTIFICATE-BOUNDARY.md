# Global unknown-size rejection boundary

A source witness is enough for YES. Complete enumeration of one supplied finite ORIGINAL n/r registry can establish a catalogue-NO. Finitely many attempted registries cannot establish unbounded NO.

The independently reviewed New Frontiers interface (`STRICT-INVARIANT-GATE.md`, reviewed note SHA-25682d8e16dcf500e41e30d2e89e070b9d8d272f866032c4c19d4db1c662f7e19c1) describes a possible additional sound rejection certificate:

1. Pin the complete typed SOURCE grammar and retained-core coverage theorem, original IDs/parameter domains/row semantics, actual joint forest compiler and complete finite core census.
2. Supply one exact semialgebraic invariant per relevant type, retaining strict inequalities.
3. Verify initialization for every positive leading edge and closure for EVERY positive parameterized grammar production at the SAME persistent natural parameters.
4. Verify one joint target-exclusion sentence for EVERY retained core, using the SAME slot kernels, IDs, source parameters and shared register across all observation rows.
5. Retain exact algebraic encodings, RCF validity receipts, compiler hashes and accepted coverage/review status.

Only those complete source-admitted gates can warrant `GLOBAL_UNKNOWN_SIZE_UNSAT`. A typed-word invariant without whole-source coverage has only typed-word scope. Relaxation satisfiability is not a positive source realization. Failed or incomplete invariant search is UNKNOWN; no completeness of the invariant language or search is promised.

The accepted finite retained-core bound is not a bound on arbitrary source-generated word length. Pointwise supplied-kernel recognition does not automatically decide the coupled unknown-interface fibers of a whole source. Generic triangularity, positive stochastic support, connected polynomial parameter families and transient contraction cannot replace those biological gates. The abstract countermodels in the reviewed note are not admitted biological lower bounds.

This package reserves this certificate boundary in documentation. It does not implement or silently accept a global-certificate flag, and it does not reopen the accepted G7 complete-registry hand characterization.
