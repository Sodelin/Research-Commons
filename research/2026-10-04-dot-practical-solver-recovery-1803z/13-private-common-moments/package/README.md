## What runs end to end

`polynomial_identity.py` accepts one actual original retained source, a declared
fixed positive allocation on every original taxon, one inheritance mechanism,
protected original control IDs, legal unmarked bridge slots, complete exact
unranked law rows, and a rational polynomial of their JOINT response vector.
Every row uses the SAME original edge/gamma parameters and SAME slot kernel.
Original parent bits use the upstream convention: incoming original edge IDs
sorted lexicographically, preserved across every row. Original integer copy
labels are assigned by sorted original taxon name and within-taxon copy index.
The full forest laws retain those labels and all opaque formed subtrees.

The adapter compiles the complete JOINT live-population distribution, projects
only the declared rooted or four-copy quartet readout, and checks the supplied
polynomial by exact coefficient comparison. Each slot is tested on ALL normalized
full labelled forest rows. This larger ambient family contains every actual
positive source word. Signed test coordinates are algebraic variables, never
claimed to be realizable source parameters. Consequently a zero coefficient
identity is sound for all actual bridge words; a failed ambient test is
inconclusive for actual words. This is a conservative implementation route, not
the full D-positive-cell identity procedure from the reviewed G3 theorem.

If the identity vanishes and its exact value at the supplied profile is nonzero,
the result is `FIXED_RETAINED_CORE_ALL_WORDS_UNSAT_BY_POLYNOMIAL_IDENTITY`. Its scope
is ONLY that retained core, specified fixed background constraints and allowed
bridge expansions. Every output explicitly says global G3 NO is unclaimed.
Passing an identity stays UNKNOWN, never SAT. A supplied complete-catalogue flag
cannot promote the result; it receives UNKNOWN.

`verify_polynomial_identity.py` uses separate sparse-polynomial Fraction
arithmetic to replay the delivered compiled coordinate identity, original input
binding and nonzero input value. It also rejects altered verdicts, coefficients
and global-scope promotion. Its trust scope is arithmetic on the DELIVERED rows;
it does not independently prove source compiler fidelity or catalogue coverage.
