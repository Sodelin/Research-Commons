## Terminal semantics and outcomes

The adapter first checks that the supplied history has an admitted source. An impossible history has its own result, preventing vacuous identification. It then checks whether different-target sources still agree with that history. If needed, it constructs the actual one-call collision formula for each different-target pair, preserving their joint source assignments. Free action weights remain outside source-parameter elimination. Each source variable uses a genuinely fresh identity, preventing accidental capture by action names.

Legal candidate supports include earlier PATH row/site unions and call count. A candidate action is rechecked by rebuilding every actual-source collision at its exact returned weights. A terminal NO concerns only the complete specified registry, encoded action menu and remaining PATH budget. Catalogue limits, pair limits, incomplete QE or backend timeouts return UNKNOWN. There is no unknown-size termination or global-NO claim.

Completed generic decisions use Z3 4.15.3 exact symbolic QE/NRA. They are explicitly labelled SAME_BACKEND. This packet does not contain an independently checked generic proof certificate or Lean proof of Python/Z3. The earlier 33-pair experiment has its own independent rational-polynomial proof checker; that stronger trust label must not be transferred to these generic adapter results.

## Reproduction

    python3 terminal_g7.py examples/actual-source-terminal.json --output my-terminal-run
    python3 verify_terminal_result.py my-terminal-run/TERMINAL-RESULT.json
