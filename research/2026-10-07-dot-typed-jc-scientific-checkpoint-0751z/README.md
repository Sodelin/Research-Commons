## Mathematical and scientific contract

The model remains the known ((A,B),C) one-pulse model with backward B-to-C routing, the original rate ties and current-block pulse semantics, and the fixed six-copy phased two-site stationary clock-JC observations. The parameters are

    theta = (h,u,v,rA,rB,rC,rAB,rR,g),
    (h,u,v) in [1/32,1/8]^3,
    (rA,rB,rC,rAB,rR) in [1/2,6]^5,
    g in [1/6,2/3].

All nine mean constraints use one shared theta. Each complete six-by-two locus contributes one bounded nine-coordinate vector; its coordinates need not be independent. Both sites share the same genealogy. The request accepts shifted Bernoulli means I; the existing initializer converts once to clipped raw moments J = [max(0,2L-1), min(1,2U-1)]. For example, all nine shifted intervals [3/4,7/8] initialize as [1/2,3/4]. Putting raw intervals under the shifted tag would change the query.

The retained set means all parameter explanations inside this declared fixed domain. It does not range over arbitrary finite histories or network architectures. A nonempty outer cover does not prove that any compatible source exists. Empty complete coverage is a conditional conflict, while an incomplete checker result stays unresolved. A width conclusion concerns the complete union, not a selected component.

The generic confidence, update and abstention infrastructure is inherited from the earlier workbench. The typed connection specializes that work; it is not new concentration theory. Combining retained delta 1/10 and fresh delta 1/20 uses the general 3/20 allowance even if the older numerical cover is the entire domain. Fresh-only selection and cumulative selection are different policies. A fixed-block radius is not an anytime radius.

The old synthetic record remains `synthetic_model_check`, with `conditional_ideal_model_only` error scope. Its finite-generator law is uncertified and both confidence eligibility and issuance remain false. Equality of numerical constraints does not certify those scientific premises.
