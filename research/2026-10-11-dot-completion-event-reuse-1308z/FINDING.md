1. Define the specified labelled comb C = (((A1,B),A2),...,Ak), with distinct copy labels and k >= 1, on the inherited genealogy and prove invariance under the actual child-swap quotient. This does not say that the forbidden-subtree event has zero mass. It matters because the supported first-meeting state need not be a fresh singleton forest.

4. Only afterward compose this coefficient with the already checked prefix no-loss law. Strict exposure positivity, cross-arity exposure scaling and the original natural-bank observable average are separate subsequent consumers.
