# What Lean has actually strengthened in E8

Contributor: prior-art/duplication auditor, coordinated by dot. 2026-10-02.
This compares exact statements. A stronger formal interface is not evidence of a novel mathematical result or of actual C++ refinement.

## Summary

The principal genuine **assumption weakening relative to our initial formalization** is supported-root traceback: global positivity is no longer needed in that theorem. The main precision extension is an exact ideal midpoint-grid selector/count/TV law and its conditional finite-step observable bound. The shared interpreter quantifies over all admitted finite providers/weights once. These are established mathematical principles made checkable, not extensions beyond the already-general CParty/PRISM paper grammar/class law.

The most important discovered restriction is an actual-source obstruction: a positive nonroot cell has a future child in the old schedule. Thus the initial unrestricted all-cache-cell source admission cannot be claimed. The preserved actual root requires a narrower root-reachable admission. This discovery comes from compiled source diagnostics and model checks, not a completed Lean proof about C++.

## A critical limitation: strengthening is not yet propagated everywhere

The supported-root theorem is checked, but the current `E8GridTracebackBridge` and production-grid wrapper still retain `hP : ∀ d s, 0 < partition ... d s`. They must not be described as already supported-root end-to-end laws. Similarly, the perturbation module supplies local kernel normalization/TV hypotheses on all declared states; a source-specific reachable-support version has not been instantiated.

The new `UnifiedLean.Source.E8PaperObservableBridge` derives source selected-class probability from an explicit source→paper equivalence, pointwise weights and classifier commutation. It does not create an actual instance of that contract for PRISM/SCFG2. This module was independently scope-reviewed and has six canonical checked endpoints with standard axioms only.

## Further strengthening revealed, with status

1. **Supported-root transport through the grid composition.** Reuse `PMF.bindOnSupport` and the proved zero-partition weight lemma; remove unnecessary positivity/local assumptions on dead states. This is an integration opportunity in established probability machinery, not a new theorem claim. Active proof lead must own the next concrete binding.
2. **Reachable-state error and actual production fuel.** Restrict error assumptions to genuinely reachable supported continuation states; derive total-step fuel from actual grammar/helper/source invariants. Current V/VM ranks and the scaffold helper arithmetic do not alone prove it. Unproved opportunity, no full d claimed.
3. **Actual physical/classifier/source instantiation.** Construct the explicit paper-source contract rather than assume its fields. Preserve complete output support/multiplicity, current σ5/σ6 and the same weights/denominator. This is the main remaining application verification task, already separate from the paper's correctness theorem.
4. **Numerical/RNG bias admission.** Combine a justified rounded-weight/kernel bound with the grid term and then established confidence procedures. Current source scale tests and seeded replay provide no such universal bound. Fixed deterministic MT replay is not an IID theorem. Unproved integration, with existing numeric/sampler priors.

No extension to all RNA lengths, all physical parameter settings, arbitrary pseudoknots, universal max/min efficiency, or historical novelty is obtained by these checked formal statements.
