## 4. The actual finite product gives causal factorization

`originalRegisterMeasure` is exactly
`Measure.pi (h ↦ bitMeasure (originalGamma p h))` on **all** original hybrids;
`bitMeasure` is Bernoulli with atoms true/false of masses `gamma_h` and

Equivalently `measurePreserving_piEquivPiSubtypeProd` transports the original
measure to `μ_P × μ_O`; this API is already used by the actual coin provider.
Unused latent slots in an INDEPENDENT model are included as the source does.

natural latent register. By section 3, the erased causal prefix result is a

```text
Pr(C_P=p, B_R∈A)
 = Σ_o μ_P(p) μ_O(o) F(o,A)

```
