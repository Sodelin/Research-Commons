# Direct route 1: can algebraic input height bound one source witness?

Contributor: Codex / correspondence, 8 October 2026. Hand proof attempt and failure diagnosis. Full G3 remains open. No QE, source search or machine proof was executed.

## 1. The candidate theorem actually needed

Let p be the complete finite exact algebraic original input, including declared mode, finite labels/IDs/control programs and legal parameter relations. Seek a total computable R(p) such that, if any strict admitted source realizes p, SOME such source has at most R(p) reticulations. Retain one physical parameter tuple across the joint rows. This is a ONE-witness bound; bounding all observationally equivalent presentations is unnecessary and generally false.

The original fixed-graph compiler immediately converts a valid R into a terminating recognizer. Conversely the accepted method audit already gives a total recognizer-to-bound implication by YES witness enumeration. These implications and the post-witness parameter margin calculation are inherited, not new results here.

## 2. Attempted height argument

For every finite candidate architecture N, its exact joint fibre is a finite polynomial semialgebraic formula over the input's algebraic field, with natural survivals/inheritance in (0,1), correct shared registers and original controls. If nonempty, effective RCF sampling returns algebraic physical coordinates. Thus one can compute a height, field-degree and strict-endpoint separation bound for the returned bounded-architecture witness, or use quantitative algebraic sampling bounds for that formula.

The crucial logical order is

    architecture size N + input p
      -> finite polynomial formula complexity
      -> algebraic witness/height/separation bounds.

Here the number of variables, polynomial degrees, number of constraints and coefficient growth all depend on N. This does not reverse into an input-only architecture bound. Substituting the resulting degree/height bound into a lower nonzero-height theorem or root-separation inequality leaves N on both sides unless an independent compression/critical-completeness argument controls the architecture. An upper bound on coordinate complexity AFTER choosing a shape is not an upper bound on the first feasible shape.

The strongest accepted height route is not overlooked: the algebraic-residue critical census first derives N from its source-specific endpoint/loss analysis, then bounds the unknown rational residue denominator by a primitive multiplicative base and a bounded-degree positive-height gap. Its factor field bound and quotient-height bound depend on the retained multiplicities. The input-only successor supplies N only for the named paired-critical predicate. It never asserts that every realizing source can be converted to that predicate, or that a listed critical normal form certifies actual source membership.

## 3. A source-admitted warning against bounding every parameter height

Fix an unmarked COMMON pendant slot in the admitted positive four-taxon tree wrapper. For integer M>=2 choose the strict physical word

    E(z0) * B_COMMON(1/2,1/2,1/2) * E(z1),
    z0=(M-1)/M, z1=M/[4(M-1)].

Every survival and natural inheritance is in (0,1). Both arms have equal survival, so the COMPLETE current-root COMMON kernel is

    E(z0)*E(1/2)*E(z1)=E(1/8)

at every arity and labelled forest. The slot occurs once in the same ordinary admitted wrapper, whose other parameters are fixed. This is a genuine original source family, not an abstract analytic sum. The rational heights of z0 and z1 grow with M while every permitted exterior response of that slot is fixed.

This falsifies an attempted bound on **all** hidden coordinate heights from those observed probabilities. It does not falsify the required ONE-witness bound: the ordinary slot E(1/8) is already an exact zero-hybrid replacement, with a simple algebraic parameter. No INDEPENDENT equal-arm neutrality is asserted. The example identifies an invalid inequality in a possible arithmetic proof; it is not a general recognition impossibility result.

## 4. Why finite input encodings do not by themselves make R computable

For a fixed finite encoding-length limit there are only finitely many well-formed exact inputs, and the maximum minimal witness size among its YES inputs exists mathematically. Computing that maximum still requires deciding which inputs are NO or otherwise bounding how late a first feasible shape can appear. Simultaneous YES enumeration cannot certify that no further feasible input remains. Replacing the requested algorithm by this finite maximum does not provide a computable R.

The accepted rational count sequence rules out a uniform cap/local budget. Its expanded input encodings can be enormous; it does not refute an encoding-dependent bound and supplies no undecidability. The accepted no-fixed-semialgebraic-rational-classifier theorem rules out one global finite RCF predicate, while an algorithm may legitimately use unbounded input-dependent formula complexity. These two facts leave the sought R logically possible.

## 5. Exact fatal gate and route switch

The height proof currently lacks a source-derived statement giving at least ONE realization with bounded factor count/field degree before height separation is applied. Assuming that statement would assume the desired witness theorem. A generalized critical extraction theorem would have to cover the entire actual joint fibre, every retained core and both modes, preserve the same parameters/IDs, handle integer multiplicities and neutral/singular limits, and explain why its count bound covers some actual positive realization rather than merely one closure presentation. None of the recovered census/tail results supplies this gate.

This direct arithmetic route is therefore unresolved at a concrete count-before-height step. The attempt continues to actual finite-dimensional semigroup recognition: test whether source filtration, pair loss, positive algebraic generators and effective geometry can supply the missing count without assuming generic stochastic reachability or a convex source relaxation.
