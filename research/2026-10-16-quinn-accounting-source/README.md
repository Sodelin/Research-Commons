# Exact viewshed accounting source handoff

This independent standard-library wrapper tracks expected row IDs and exact integer sums over Boolean raster fixtures. It does not run GDAL or reproduce the original geographic study. The three Python files are the exact tested bytes, pinned in `MANIFEST.json` and `VALIDATION-SUMMARY.json`.

`Registry` fixes unique expected IDs, one run/configuration and a declared common grid/mask. Attempted is separate from the disjoint validated/failed/pending partition. Validation requires all four named zero stage exits and a same-context artifact receipt asserting checksum/grid/CRS/nodata/Boolean checks. Those checks are trusted storage-owner assertions; this code does not prove them from a GeoTIFF. Missing and unconfirmed receipts remain pending. Nonzero, stale, wrong-configuration and conflicting outcomes latch failure for this run. Exact replay is idempotent. A retry needs a new registry/run.

For nonnegative integer weights and Boolean cells on the common grid, let L be the validated weighted sum and M the weight of every unvalidated ID, including failed and pending rows. Each omitted term lies between zero and its weight, so every unrestricted Boolean completion satisfies L <= S <= L+M. All-zero/all-one omitted cells attain the bounds in that model. Geographic joint feasibility, original percentile/neighborhood/polygon/cartographic steps and a statewide certificate are outside this result. Exact integer addition preserves sums across disjoint partitions and reorderings, including totals above 2^32.

For S >= t, YES requires L >= t and NO requires U < t. For S > t, YES requires L > t and NO requires U <= t. Remaining cells are UNKNOWN; mask exclusions are MASKED. Thresholds use integers or exact Fractions.

These are static source facts; practical curvature equivalence and a failure in the published run are not established.

No original CSV, DEM or GDAL dependency is needed by these synthetic controls.

`VALIDATION-SUMMARY.json` is an explicitly derived, sanitized scientific summary of the actual 35-control pass. It is not a raw runtime receipt or a new execution claim. Private execution and access details are excluded. No canonical solver or study adoption is implied.
