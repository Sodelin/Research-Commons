## 3. Exact source and row definitions

Let O and T be `PhysicalMarkedSource Y`, and let `steps : PhysicalSteps O T`. The steps are actual source-derived protected equal-arm splices. Require `HasOuterSemidirectedPartner O.marked.source`; the existing `markedSteps_outer (physicalSteps_marked steps)` supplies the same original outer-admission property for T. The inherited source carries a finite binary rooted-LSA cut-child network, its calendar and original registry; physical probabilities/rates remain those of the source class. There is no bound on the size of the class of all such sources.

The supplier returns a single injection J from T's hybrids to O's hybrids and a source decoration D, with `PhysicalPrimitiveProvenance O T J D` and marked-ID preservation. For every finite copy carrier C, finite whole-configuration carrier F, PMF ν on F, original masks m:F→OriginalMask(O), and sample map s:C→Y, it proves:

    randomizedFullForestLaw(T, ν, m ∘ J, s)
      = randomizedFullForestLaw(O, ν, m, s).

All of T's physical parameters, J and D precede the universal quantifiers over rows. Zero-weight configurations are retained in ν, not converted into separately observed tests.

For each action a choose:

1. a finite labelled copy carrier C_a and allocation s_a:C_a→Y;
2. a finite configuration carrier F_a, one joint PMF ν_a, and original-ID masks m_a;
3. a declared fixed stochastic readout c_a from the completed unranked forest on C_a to one common output type Out.

Define P_O(a) by running that original mixed row and binding its forest to c_a. Define P_T(a) using the same ν_a, allocation and channel, with masks pulled through J. The common output type is the explicit heterogeneous-carrier adapter: c_a can encode allowed action-specific results into a common tagged type or a common coarsening. It does not expose a hidden configuration label, register, internal forest path or calendar time. No product-of-marginals substitution is made.

The action type may be a supplied legal menu or subtype of legal rows. The equality theorem holds for all typed rows, hence also for any policy restricted to the already-authorized menu/resource constraints. It grants no new observation permission. A history-dependent legality restriction must be applied identically on both sides; the policy itself is one fixed function of recorded outputs/actions and cannot query hidden source state.

## 4. Fresh-locus protocol and complete proof

Let π be the common randomized policy on the complete recorded output/action history. At each call, after π chooses a, perform a new original source realization with the fixed physical tuple, a fresh original COMMON register and a fresh whole forcing configuration drawn according to ν_a. Complete the locus and apply c_a. Retain only the recorded result and action. This is a definition of the reset experiment being studied, not an inference that arbitrary biological repetitions are conditionally independent.

Its joint reset kernel is

    K_O(a, ()) = P_O(a).map(o ↦ ((),o)),

and similarly K_T. Initial observed law μ₀ is common and source-independent, e.g. a fixed sentinel. A source-dependent initial observation would need its own preserved source row and cannot be supplied for free.

Proof:

1. Apply `physicalSteps_complete_transport` once to obtain J, D, primitive provenance, marked-ID preservation and every future mixed-row equality.
2. For any a, instantiate that equality at C_a, F_a, ν_a, m_a and s_a. Apply congruence of `PMF.bind` with the identical c_a. This gives P_T(a)=P_O(a). The configuration correlation remains inside the original ν_a-bind throughout.
3. Function extensionality gives P_T=P_O as action-indexed response functions. Mapping o↦((),o) therefore gives K_T=K_O. This proves the conditional one-step equality from the concrete reset definition. It does not assume that matching unconditional marginals of a persistent-state process suffice.
4. Substitute this function equality into the existing `experimentLaw`, using the same π, finite horizon n and initial μ₀ mapped to Unit×Out. Apply its existing output view. The complete transcript PMFs are equal, including the retained actions. This is exactly the identity-reset-state specialization of the existing generic joint-sensor preservation theorem.
5. Apply any common transcript statistic by `PMF.map`, or common randomized decision channel by `PMF.bind`. Its output laws remain equal by congruence.
6. Apply `markedSteps_outer (physicalSteps_marked steps)` to the original outer witness. Thus the result remains on actual original physical sources, not arbitrary latent laws.

This proves the displayed result for every finite n. It needs neither finiteness of the entire biological source class nor a finite action menu for the transcript equality. The included Lean candidate gives the concrete typed definitions and the entire proof by existing source transport plus congruence. It contains no `sorry`, admitted axiom, desired-law field or external computation claim. Type/API compatibility remains to be checked in an authorized integration environment.

## 5. What the built Semi foundations now supply

The built `Semi.Core` factorization results are classical statements about fibres of a supplied observation map. In a biological application that map may be a legal exact full-row profile or the derived transcript PMF. Existence of a factorization does not decide whether arbitrary rational/algebraic input lies in the physical image. It gives no total source recognizer, source-size bound or general finite determining menu.

For finite final decision set A, a randomized decoder d from transcripts Z to PMF A induces

    q_S(a) = (transcriptLaw(S).bind d)(a).toReal.

These weights are nonnegative and sum to one, so q_S is a `Semi.Statistics.RandomizedAction A`. Equal transcript laws imply q_O=q_T. The newly built `pair_risk_lower_bound` then applies to this common q: if a specified loss satisfies

    δ ≤ loss(a,O)+loss(a,T) for every a in the FULL action type A,

then risk(q,O)+risk(q,T)≥δ and the larger risk is at least δ/2. This uses no `Fintype` instance for the biological source class. Equivalently use `indistinguishable_pair_lower_bound` with observation equal to the transcript PMF and the decision rule induced by d.

This is a transfer of an existing lower bound, not a newly produced biologically separated pair. If the scientific target is intentionally preserved by the representative, no positive separating δ has been established. Exact hidden-graph identity and observable biological targets are distinct loss choices. A decoder must not be allowed to depend on which unknown source generated the transcript.

By contrast, `exists_fibre_minimizer`, `fibreMinimaxRadius_pair_lower_bound` and `exactDataMinimaxFloor_le_rule` also require `Fintype X` for the complete state class represented in the theorem. Finite observed rows, finite output alphabets or one finite graph do not imply a finite unknown-source fibre. A finite supplied hypothesis table can instantiate those statements only for that explicitly finite table. It cannot be promoted to all unknown-size original biological sources.

Both the pair lemma and finite minimax optimize/quantify over the entire declared action space. Restricting decisions to the current observation fibre changes the problem. Half a fibre diameter is a lower bound under a corresponding loss inequality; it is not the definition of the randomized minimax radius. This source adapter provides no native rational-loss-table generation or Rust refinement certificate.
