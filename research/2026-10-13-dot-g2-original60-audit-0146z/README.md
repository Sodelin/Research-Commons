# Audit of the original accepted 60-module G2 package and its extensions
Read-only source and historical-evidence audit, 13 October 2026. Prepared for Nolan by dot.

## Answer first

**Your recollection is supported by the records.** The complete original 60-owned-module G2 package was independently accepted before its full packet was lost. The surviving final review is explicit about both the actual end-to-end timed genealogy theorem and its substantial internal extensions. Calling it merely “a timed endpoint” leaves out important work that had already been done.

The loss concerns evidence availability. It did not turn the accepted mathematics into an open problem. Seventeen original source bodies and the final acceptance records were preserved exactly; 43 original bodies and much of the raw build evidence were not. The later reconstruction provides a separately checked current source package. It does not pretend to recreate those 43 historical bodies byte for byte.

The original package already included actual full-past residual factorization, same-clock finite histories, entire epoch/calendar/ancestral path transport, original joint-register assembly, faithful measurable genealogy-and-age readout, literal age-preserving pruning, strict rooted chronology, exact time-forgetting, and fixed-demographic-date nullity. These should be reused, not proposed as fresh missing extensions.

Later, separately dated October 9 work also supplied fixed-panel finite-horizon adaptive histories, noisy adaptive histories, and an adaptive count-budget bound. Those are real existing extensions, but are **not retrospectively counted among the original 60 modules**.

This audit finds no documented missing substantive endpoint *within the accepted original 60-module contract*. It cannot certify every lost helper declaration individually. In particular, absence of surviving text is not evidence that an undocumented extension never existed.

Continuous-clock-path adaptation does not follow merely from these finite endpoint/action results.

### Stopping times: what the available record does and does not establish

The complete ancestral clock cover in the original package is random and captures the whole tail. That is a genuine existing random-cover construction. It is not interchangeable with a general strong-Markov theorem at every observation-adapted stopping time.

The current fixed-time theorem quantifies t and v directly. The canonical scope explicitly warns against calling it an arbitrary stopping-time or algorithm-termination theorem. The later adaptive/noisy/budget packets explicitly retain finite horizons and disclaim unbounded stopping-time results.

Accordingly, a proposed arbitrary stopping-time extension would first need an exact statement about its filtration, measurability, allowable policy and observation, and the required stopping/termination hypotheses. This audit does not certify such a general endpoint. It also does not infer that no historical argument exists merely because a phrase was absent from a search. The 43 missing bodies prevent an exhaustive original declaration audit.

### Cross-locus use: distinguish the experiment model

The earlier [source-realizability checkpoint](https://github.com/Sodelin/Research-Commons/blob/eb284f41d13fff2602de4e98411fb15e5891f9e8/research/2026-09-30-astra-source-realizability-1908z/CHECKPOINT-1.md) already states a finite L-locus adaptive transcript error bound Lε by conditional coupling and an equivalence between finite response-profile equality and equality of finite randomized/adaptive transcripts built from the stated primitive. Those are older composition arguments, not a new discovery of this audit.

That checkpoint was initially a submitted hand-proof checkpoint; its own text alone is not a full current Lean certificate. Any transfer should follow its subsequent acceptance and exact primitive assumptions. This report does not elevate that initial checkpoint into a new kernel verification.

The original G2 package supplies rich **within-source** shared-register and history dependence. It does not, simply by that fact, specify every joint distribution across independently repeated loci, linked loci, recombination, or a new shared cross-locus latent process. “Cross-locus” must name which of these experiments is intended. The existing finite repeated-experiment composition must be checked before proposing duplicate work; a biologically linked-locus law needs its own stated source contract.

## 6. Recommendation

Do not rebuild a generic G2 history, path, pruning, clock-factorization, adaptive-history or noisy-history theorem from scratch. First reuse the exact current providers and their established assumptions.

For the specific question “did the lost full package contain additional work?”, the answer is yes: its internal clock/history/path/readout/support stack was already complete and accepted. The complete module crosswalk below makes that content visible.

The genuine availability debt is preservation of the 43 original source bodies and original raw evidence, if an authoritative archive is found. The current reconstructed endpoint already has its own verification. A newly proposed stronger experiment should be assessed against a written contract and these existing suppliers; this report does not identify a new mathematical gap solely from missing original files.

No compiler, proof construction or benchmark was performed for this audit. This publication preserves the documentary findings; it is not a fresh build certificate.
