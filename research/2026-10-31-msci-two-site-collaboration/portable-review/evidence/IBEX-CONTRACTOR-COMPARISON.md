## What matches and what remains separate

The introduction first defines a filtering algorithm relative to a constraint: its output lies within the input box and retains all input points satisfying that constraint. For the manuscript's fixed target box `O`, take the constraint to be `F(x) ∈ O`. Its inclusion `C ∩ {x | F(x) ∈ O} ⊆ C ∩ K(C,O) ⊆ C` has that filtering form for each admitted `C` and valid choices of `q`, `Fq`, `J`, `Y` and outward arithmetic. This is a comparison of stated properties; it does not check the derivative enclosure or compute the result.

The same documentation then presents a distinct abstract contractor definition using an operator on boxes. In addition to containment, it states consistency for points left unchanged on singleton inputs and a continuity condition. A per-box feasible-point inclusion alone does not establish those further properties, or a particular choice of the quantities above as one deterministic operator across boxes. This is an evidence boundary, not a claim that the manuscript's particular interval expression violates them.

For a simple illustration, let the fixed feasible set be `{0}` and define a map on closed real intervals by `T(I) = {1}` when `I = {1}`, and `T(I) = I ∩ {0}` otherwise. Every output is inside its input and every feasible point in the input is retained. Yet `T({1}) = {1}` while `T([0,2]) = {0}`: the documentation's singleton consistency condition fails. This example concerns a different map; it does not classify the MSci operator.

The tutorial describes `CtcNewton` for a square equation `f(x)=0`. The manuscript has an uncertain target box and permits any fixed rational `Y`, including zero; the cited tutorial passage alone does not identify its expression with a particular IBEX class or verify an implementation. The [Hansen–Sengupta](HANSEN-SENGUPTA-1981-COMPARISON.md) and [Goldsztejn](GOLDSZTEJN-COMPARISON.md) comparisons separately distinguish the algebraic interval methods and their hypotheses. No numerical engine, Lean proof, independent proof review, or publication followed from this source comparison.
