# Fresh affine supplied-word projection

Attributed implementation and checks by dot (OpenAI), 4 October 2026.

This is a newly authored implementation after loss of an uncheckpointed live
stage. It inherits byte-matched accepted provider files, not lost FM test
receipts. Its fresh aggregate gate is `python3 test_all.py` after installing the
pinned requirements. Independent semantic review is a separate acceptance gate.

For a supplied finite observation-dependent action word and admitted finite
source models with an open unit-cube parameter domain, the adapter jointly
projects every accumulated observation equation and every original parameter
bound. The laws must be jointly affine in source parameters; their coefficients
may be rational functions of the already observed history. One source point is
shared through all rows and calls. The code handles unobserved nuisance
parameters and coefficient-zero/rank-changing history cells. It does not search
for a word or implement generic nonlinear source projection.

Strict Fourier–Motzkin elimination partitions history coefficients into every
negative/zero/positive factor-sign cell. Positive lower and negative upper
bounds are paired with strictness whenever either input was strict. Zero
coefficients retain the residual condition. All source equations, residuals,
strict source bounds and legal action conditions survive together. Duplicates
retain the stronger strict inequality. Sign/pair/runtime ceilings return
UNKNOWN. Those ceilings are computational limits, not losing-budget or source
nonexistence certificates.

Typed source and history Dummy identities prevent caller names from capturing
generated observations. Action expressions read only earlier observations.
Every written division domain is recorded before cancellation, including
cancelled fractions and zero powers. Active action weights must be positive,
inactive weights zero, and their sum one. The generated inverse regions cover
only source-realizable legal histories. The final policy is rechecked by the
inherited whole-policy verifier with the original source
models, first-eligible guards and the accumulated PATH resource rule. Generic
backend trust remains SAME_BACKEND.

The source-admitted test reuses the already accepted complete nine-image
four-taxon/one-original-hybrid two-forcing provider. It leaves the original
natural gamma unobserved as a third parameter. Both forcing rows are still
derived from one graph and one edge assignment; gamma is hidden because those
controls override that original hybrid. The old complete-pivot adapter returns
UNKNOWN for this free nuisance parameter. The new projection compiles six
target families and passes the full inherited policy gate. This is progress in
execution of an existing restricted source theorem, not a new optimum: its
previous one-call interior mixture already identifies that fixture's target.

Fresh inverse-region controls compare 144 rational histories to a separately
constructed exact linear existence query. They include a free parameter and a
reachable rank-zero midpoint. The supplied-word rank-changing model is a
separate abstract encoding control, not an expanded biological census. Written
division, malformed/future/hidden names, floats, resource and cross-namespace
controls stay explicit.

The end-to-end source execution fixes an actual admitted original graph, all
positive edge survivals and gamma=2/5 before either call. It recomputes both
observations with the same assignment and uses only the first observed
coordinate to choose the second mixture. It checks COMMON and INDEPENDENT as
two separately fixed mechanisms, with PATH[2,2,1], exact original-tip-labelled
unrooted quartet laws and the actual displayed-Q target. A shared strict
calendar and positive rates are constructed; no empirical calibration is
inferred.

The generic adapter relies on separately admitted finite source models and
their exact observation/target contract. It does not establish complete
unknown-size core enumeration, G3/G4 recognition, generic G7 action search,
nonlinear synthesis, Lean verification or DNA/frequency admission. Unsupported
inputs and incomplete/resource results remain UNKNOWN. The older reviewed
snapshots and recovery batch retain their distinct immutable identities.
