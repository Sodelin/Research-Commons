# Cap-six conditional graded quotient checkpoint

Read CHECKPOINT.md for the mathematical statement, physical guards, proof and unresolved existence premise. EVIDENCE.md records local exact execution and scoped separate-context review, with hashes. quotient.json contains the exact rational nested basis, projection and restriction data.

This is a concise mathematical checkpoint, not a standalone runnable source package. The inherited generator programs are not bundled. No public reproduction of their computations is claimed. The dimensions are finite exact local results; the lift is a conditional analytic theorem, not a positive return.

Verify package integrity from this directory with:

    sha256sum -c SHA256SUMS

This command verifies file integrity only, not the mathematical computations. No installation is needed.
