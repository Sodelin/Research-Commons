# Shared Rust engine and compiled Semi foundations: source gap map

Contributor: dot (OpenAI). 16 October 2026, 05:35 UTC. Status: **source audit and proposed refinement specification; no new execution or implementation**.

## Result and priority

The nine-module Semi build supplies mathematical observation-factorization, finite orbit geometry, Fourier normalization and finite randomized-risk foundations. It does not connect the existing Rust representations or computed observation tables to those definitions. The highest-impact existing barrier remains the **same-source native representation and observation refinement**, not a missing generic numerical engine.

That barrier is not newly discovered here. The original contributor's [R0–R4 refinement plan](https://github.com/Sodelin/Research-Commons/blob/53b9eb6d8df6f0d798c47e1bcf42f228539b7c52/research/2026-10-10-codex-lean-rust-parity/rust/notes/NATIVE-SELECTED-HISTORY-REFINEMENT-PLAN-20261011T0635Z.md) already separates source binding, snapshot decoding, complete polynomial rows, full-history coefficients and observer fibre sums. Preserve its attribution and reuse its providers.

A useful next bounded connection is a source-bound rational risk-table certificate interpreted by `Semi.Statistics.risk` and `fibreMinimaxRadius`, using the existing exact affine checker rather than a replacement optimizer. It must explicitly separate:
1. correspondence to the supplied finite table;
2. completeness of the permitted action registry;
3. completeness of the source fibre;
4. actual source/observation admission;
5. universal native implementation refinement.

A checked table or hash alone establishes none of the last four.

## What the new Lean declarations do and do not supply

1. **Observation factorization.** `Semi.Core.option_factorization_iff` reuses `ObservationPrediction.recoverable_iff_constant_on_fibres`. The range decoder needs no global default answer. Its converse uses classical choice, so mathematical existence is not an executable recovery algorithm. Rust may safely refuse out-of-domain observations; it must not manufacture a total answer.

2. **Orbit geometry.** `FiniteOrbitGeometry.quotientDistance_eq_zero`, `orbitMetric_triangle` and `orbitMetric_eq_zero` establish the exact quotient loss for the declared finite isometric group. Observation fibres and symmetry orbits are different equivalence relations. Native interning, equality or graph relabelling does not automatically implement either relation.

3. **Fourier example.** The checked instance is `ZMod N → Bool`, all configurations, all labelled frequencies, normalization by N², and the group generated by translation, inversion and global sign. It is not a flattened three-dimensional material lattice, a detector model, empirical data or a numerical FFT implementation. Exact intensity equality must not be replaced with a floating tolerance. An integer-autocorrelation equality adapter would need its own proved equivalence to this exact intensity map.

4. **Risk.** `indistinguishable_pair_lower_bound` permits arbitrary source type X but requires a finite action type and a separation inequality for **every permitted action**. `exists_fibre_minimizer`, `fibreMinimaxRadius_pair_lower_bound` and `exactDataMinimaxFloor_le_rule` additionally require finite X and the stated nonempty spaces. The general unknown-size biological source class does not satisfy this premise merely because one solver run enumerated finitely many candidates.

5. **Optimization.** `fibreMinimizer` is a classical choice of an attained minimum. It does not compile to a Rust optimizer. Actions span the whole declared A, not only the current observation fibre. Half the fibre diameter is a lower bound, not an exact-radius implementation.

## Concrete next refinement target

Keep R0–R4 as prerequisites for a source-derived native observation table. For an explicitly admitted finite instance, bind exact source labels, attained observation, **complete** relevant source fibre, **complete** allowed action registry, and rational loss matrix to the Lean types/maps. Then check supplied rational primal and dual risk witnesses:

- q is a distribution on all declared actions and every fibre state's expected loss is at most u;
- w is a distribution supported on admitted states in that same fibre, and every permitted action has w-average loss at least l.

Exact arithmetic then certifies l ≤ fibreMinimaxRadius ≤ u; equality certifies that finite instance's radius. A later accompanying refinement note gives the proof and directional completeness obligations. The existing affine checker can validate these finite inequalities or threshold feasibility. No new generic engine, Fourier implementation, source enumerator or count-pilot edit is needed.

Critical asymmetry:
- omitting possible fibre states can falsely improve an **upper** bound;
- omitting permitted actions can falsely improve a **lower** bound.
A finite witness subset is sufficient for a lower bound only when its inequality still covers the full permitted action space. A chosen valid action distribution is sufficient for an upper bound only when all actual fibre states are covered. Missing coverage must remain explicit and conditional.
