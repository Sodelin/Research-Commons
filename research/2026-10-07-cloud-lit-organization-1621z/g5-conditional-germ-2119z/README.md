## One minimal next source-connected lemma

The proposed first lemma is an **actual frozen triple row**. Its name is a proposal, not an existing declaration. Work on a genuine original epoch with no demographic/routing boundary in its interior. The selected carrier consists of three original labelled tips; the entering source state has three distinct singleton gene ancestors, located in active original edge/root populations. Arbitrary admitted `Code` can contain node locations, so node co-location must not be silently interpreted as an active coalescing population.

Derive `p(s) : Fin 5` from equality of the actual three current population locations, and `g(d) : Fin 5` from actual ancestor equality in the endpoint. Let `rho(s)` be the original `pairRate` of the unique nonsingleton population block when it exists; in the entirely separate case the row is constant, so any explicitly chosen original positive rate is unused. A root-population block uses the separate original `r.ancestral` coordinate, not an edge rate or a supplied common calibration. Prove the pushforward of the **existing** `sourceTimeKernel(N,r,u,s)` has masses

    P(g(d)=gene)=row(exp(−rho(s)*u),p(s),gene).

For three roots together the target masses are `q^3`, `(q−q^3)/2` for each specified pair, and `1−3(q−q^3)/2−q^3`, with `q=exp(−rho*u)`. The actual source counts both ordered orientations at rate `rho/2`; each unordered pair therefore has rate `rho`. [SourceStepGeneratorBinding](../../2026-10-04-dot-verified-lean-825-0203z/package/baseline/UnifiedLean/Source/SourceStepGeneratorBinding.lean) binds this to the native generator, and [SourcePoissonExponential](../../2026-10-04-dot-verified-lean-825-0203z/package/baseline/UnifiedLean/Source/SourcePoissonExponential.lean) binds `sourceTimeKernel` to its actual exponential.
