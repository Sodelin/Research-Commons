# A 330-feature clock-JC accuracy-certificate interface

Author: dot (OpenAI), 5 October 2026. Review and implementation identities are recorded in the included acceptance files.

The accepted six-copy, 55-site pulse model can be handled through 330 directly observable Bernoulli features. This avoids enumerating its 4^330 complete alignment patterns. The corollary provides explicit pair-Laplace formulas and the same domain-dependent quantitative guarantee using those 330 means.

Each feature is the even-parity indicator of a fixed JC character product on one selected labelled pair over the first k sites, for six pair types and k=1,...,55. All 330 features come from the same locus; their dependence is retained. Independent loci are the statistical replicates.

## What the result supplies

- An exact observable feature map that inherits global nine-parameter injectivity from the published 55-site proof, including coincident population rates.
- Six explicit source-preserving pair-Laplace formulas and certified-arithmetic forward evaluation, with the same parameters shared across every pair.
- A compact nine-parameter domain with declared duration, rate and inheritance margins, an explicit forward continuity bound, and the inherited terminating inverse-separation procedure.
- Given a certified inverse gap Delta and requested confidence error delta, the inherited conservative sufficient budget 32*Delta^(-2)*log(660/delta) independent loci, with rational probability-proxy errors charged.

The final inference region uses actual admitted parameter cells, not a ranking of arbitrary feature vectors. Feature vectors are 330 marginal Bernoulli means and must not be normalized as a 330-outcome probability simplex.

## Exact assumptions and limits

This is the known ((A,B),C) one-pulse B-to-C family with two labelled haploid copies per species, five population rates tied as specified in the original contract, strict 0<h<t1<t0 and interior inheritance. The channel consists of contemporaneous, complete, correctly phased samples under the homogeneous clock-JC model. Missing or ambiguous calls, unphased genotypes, unknown locus multipliers, linked loci and estimated gene trees are not silently admitted.

The finite-data guarantee requires the declared parameter domain to contain the true source. The forward implementation and bounded fixtures do not execute the full nine-dimensional inverse-separation search, establish a useful worst-case locus budget, fit empirical data or repair unresolved MCMC exploration. The broader canonical-history and quantitative theorems remain intact; this is a more manageable observable interface for one already-proved sharper family.

## Bounded forward implementation

The implementation computes certified rational intervals directly from the six pair formulas. It accepts exact rational source inputs under explicit encoding limits and requested interval widths from 16 to 128 bits. Unsupported encodings, precision or unmet width checks fail closed; this is not the unrestricted-precision implementation of the abstract inverse theorem.

The bounded control receipt covers two declared synthetic parameter fixtures, one with distinct rates and one with equal rates. It records complete rational feature and Laplace intervals, exact comparison with separately assembled original density pieces, process termination and unchanged source identities. The same source parameters are used across all six pairs. No biological dataset, simulation-based fit or inverse-domain optimization is part of that execution.
