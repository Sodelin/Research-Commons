## Fixed full endpoint

The endpoint remains the exact all-observed-variable HPL TCM-class decoder for arbitrary finite unknown latent variables and selection sinks, with fixed named single-target soft replacements and the stated exact faithful elementary oracle. A bounded original source, a skeleton target, independent realizability of separate indicators, and a weaker source class are not substituted. ## Exact MAG-equivalence provider provenance

The modern common-discriminating-path criterion is [Ali–Richardson–Spirtes 2009, Theorem 4.1](https://arxiv.org/pdf/0908.3605), attributed there to Spirtes–Richardson 1997. It must not be confused with that paper's Theorem 3.7 on colliders with order. Both support classical hand mathematics, but neither is already imported as a checked Lean provider here.
