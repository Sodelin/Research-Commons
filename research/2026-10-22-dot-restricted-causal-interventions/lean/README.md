## Fixed full endpoint

The endpoint remains the exact all-observed-variable HPL TCM-class decoder for arbitrary finite unknown latent variables and selection sinks, with fixed named single-target soft replacements and the stated exact faithful elementary oracle. A bounded original source, a skeleton target, independent realizability of separate indicators, and a weaker source class are not substituted. ## Actual source development

- `SelectedWalkReduction.lean`: finite relation-route suffix extraction and simple-subroute existence by induction; explicit bow-aware arrival states; selected-head invariance; selected-walk-to-physically-simple-active-path reduction. This is a proof-bearing B6 component, not an assumed active-walk theorem.
- `CanonicalSelectionProfile.lean`: ordered marked-pair selector tokens, singleton F selectors, literal H_X/F/V recovery, singleton selection components, exact observed ancestry and ancestry-to-selection. The ordered token prevents duplication of an unordered pair's four mark choices. No separation equivalence is a field of `Profile`.
- `SelectedSourceProfile.lean`: extract the actual profile from arbitrary selection-component data; prove first-selected-block decomposition with an exact list equation; lift marked virtual edges; preserve the complete observed trace through route lifting; derive a simple real path through the earlier reduction; contract an active route by strong length induction; prove the precise profile effect of a named added root. Selected paths may overlap during lifting, and that repetition is handled explicitly.
- `SelectedAncestry.lean`: derive the original selected mixed graph's observed ancestry, ancestry to selection, and exact ancestor-of-Z-union-S formula; construct its canonical selected graph in the same data type.
- `SelectedProfileSeparation.lean`: compose extraction, ancestry, contraction and lifting into a two-way canonical active-path theorem with the actual graph ancestor predicate. `canonical_augmented_preservation` uses one fixed canonical graph for every named root and preserves all augmented observed paths, observed ancestry and selection ancestry. Its source remains the explicitly defined post-latent-projection selected mixed graph, not an asserted original-DAG theorem.
- `CanonicalLatentRoots.lean`: construct one hidden root per ordered bidirected pair, prove the resulting directed graph acyclic whenever the retained directed part is acyclic, preserve retained selection sinks, and prove exact marked projection by arbitrary-length latent-interior noncollider routes. The proof excludes longer hidden interiors from the actual absence of hidden-root adjacency. Concrete added indicators have no parents, exactly the named child, and retain all old arrows. Subsequent modules supply separation, augmentation commutation and finite cardinal proof bodies.
- `CanonicalFiniteBounds.lean`: proof-bearing candidate bounds of n + 4 choose(n,2) selectors and 9 choose(n,2) hidden roots. The latter is not the weaker choose(n+s,2) bound: an explicit root-tag injection uses observed unordered pairs or one of two incidences of a marked-pair selector; singleton flags cannot add a bidirected root. A fixed finite retained-vertex order is constructed explicitly.
- `FiniteProfileRegistry.lean`: injectively encode the entire admissible H_X/F/V profile, recovering all marked observed edges, all ordered/reversed bridge pairs and every singleton F flag. The source proof bounds the number of such profiles by 2^n times 96^choose(n,2). It does not replace the original TCM target by this code or assert independent realizability of indicator classes. Original-source representation, common probability witnesses and the final decoder remain separate.
- `CanonicalRootSeparation.lean`: directly prove actual two-way active-connection semantics for the hidden-root DAG, using concrete contraction/fork lifting, retained ancestry and uniform-tail loop reduction. Selection vertices remain conditioned and hidden roots remain unconditioned. `canonical_dag_selected_preservation` composes this with the selected-profile theorem for the baseline. Subsequent modules handle the same actual DAG's named-indicator augmentations; no generic latent-projection separation axiom is assumed for this particular root construction.
- `MarkedGraphEquivalence.lean`: prove marked graph-isomorphism transport of reachability, exact conditioning ancestry, arrival transitions and vertex-simple active paths.
- `CommonIndicatorRoots.lean`: explicit inverse root-label maps and an actual graph isomorphism identify adding a named indicator to the fixed baseline DAG with expanding its augmented retained graph. Prove active-path/reachability equivalence and acyclicity for the same source, without independently chosen slice realizations.
- `CommonSelectedIndicatorSource.lean`: compose those isomorphisms with selected compression for every named target, every augmented conditioning set and all observed/root endpoints. The actual fixed canonical source preserves observed and selection ancestry, remains acyclic, and keeps selection vertices as sinks. Its new indicator is exogenous with exactly its named observed child; all old arrows remain. This closes the proof-body common-source component for the selected mixed-graph input, not the original arbitrary-latent DAG or the final MAG/TCM/statistical theorem.
- `OriginalLatentProjection.lean`: start from genuine original DAG arrows on observed, selected and arbitrary latent carriers. Define the latent-interior noncollider-route projection; derive reversal, no tail-tail edges, projected directed acyclicity, selection endpoint heads, exact selected-graph extraction, and full-profile registry membership. The original latent/selection carriers are not bounded. Later modules directly justify this route-based representation by original active-path semantics, rather than inferring separation from this extraction alone.
- `OriginalProjectionAncestry.lean`: explicitly split original directed routes at retained vertices and contract each latent block, giving both directions of retained ancestry and exact retained ancestor-of-conditioning equivalence.
- `GeneralActiveWalkReduction.lean`: prove loop splicing and physical-vertex loop erasure with the true ancestor predicate, even when two occurrences have different arrival marks. The proof handles the potential newly closed collider through head/nonancestor forward propagation, and handles conditioned vertices separately. It does not assume uniform hidden marks or a shortest-path oracle.
- `OriginalProjectionLifting.lean`: lift any projected active path through its actual original latent routes, then apply the general reduction to obtain a simple original-DAG active path. This is one direction of original d/m-connection equivalence; the following three modules supply the converse through actual latent-collider detours rather than an interface assumption.
- `LatentColliderDetours.lean`: construct a directed route to the first conditioned descendant and back for each active latent collider. The turnaround collider is retained/conditioned; all intermediate noncolliders are unconditioned. Replace every original step by a concrete route with no latent colliders.
- `ReadyRetainedNormalization.lean`: erase only retained-vertex return segments. A proved true-ancestor splice changes only a retained departure, so resolved latent colliders cannot be reintroduced; original latent occurrences may still repeat.
- `OriginalProjectionContraction.lean`: extract exact noncollider latent blocks from the normalized original route, contract them, and apply physical-vertex reduction. `original_projection_connection_iff` now has both proof-body directions for arbitrary original latent/selection carriers and arbitrary retained conditioning. This directly justifies the route-based internal representation by original active-path semantics; it does not rely on merely naming it a classical projection.
- `OriginalIndicatorProjection.lean`: retain the original latent and selection carriers while adding exactly the named root to the original DAG. Prove all old projected marked edges unchanged and the only projected root incidence to be the actual named child. The resulting projection equals the augmented extracted graph on every labeled vertex, not merely up to a separate-slice equivalence.
- `OriginalCanonicalSourceAdapter.lean`: compose all original-DAG and canonical-source constructions. For one fixed bounded canonical source, prove baseline and every named single-indicator active-connection equivalence for every retained conditioning set and every endpoint, exact observed ancestry and ancestry-to-selection, acyclicity and the advertised selector/root bounds. This reaches the original arbitrary-latent source quantifiers with genuine proof bodies. Later modules supply literal HPL target transport; selected-slice faithful probability construction and the full decoder remain separate.
- `EndpointColliderActivation.lean`: resolve an endpoint-ancestral collider which is not activated by the conditioning set. A directed shortcut either replaces the accumulated prefix from the first endpoint or finishes at the second endpoint. The induction processes the original route, so a longer replacement path does not invalidate termination of the proof. Physical loop reduction is then applied to the actual active walk.
- `InducingPathSeparation.lean`: implement HPL's inducing-path condition on the original DAG's actual incidences and simple vertex list. Prove both directions of inducing path iff no observed separator. The converse uses the observed part of An{x,y,S}, excluding x and y; an explicit backward-closed-support argument proves that every path vertex is ancestral to x, y or selection, forcing every retained internal noncollider into the conditioning set. No inducing-path equivalence is assumed in the source adapter.
- `LiteralSelectedMAG.lean`: implement HPL Definition 2's literal inducing-path adjacency and ancestral endpoint marks. Package the already constructed canonical root DAG as a genuine `SourceDAG`; instantiate all connection and ancestry preservation premises; derive equality of every baseline and separate augmented marked MAG, and equality of the literal trimmed union. For empty T the literal HPL union has no edges, while the baseline remains in the equivalence certificate. The following module supplies ancestral validity; the MAG's full m-separation representation and the shared-separator equivalence certificate remain distinct obligations.
- `SelectedMAGValidity.lean`: explicit marked-route reversal gives symmetry. A directed MAG route starting outside the source's selection-ancestor set lifts to original ancestry. This proves no directed cycles and the arrowhead/nonancestor axiom; an undirected edge forces both endpoints to be selection ancestors and hence to have no incident arrowheads. These are derived ancestral-graph axioms, not assumptions on the output. Full m-separation representation and maximality are still separate dependencies.
- `FiniteOriginalTargetImage.lean`: retain the original carrier of finite sources with arbitrarily large latent and selected types. Construct the canonical registry entry from every source; prove preservation of the full elementary signature and literal TCM; prove elementary-signature equivalence to HPL's set-valued Definition 6; derive exact equality between the original class's marked TCM image and a filtered finite common-source registry, with at most 2^n times 96^choose(n,2) entries. The displayed `registryList` is explicitly noncomputable. It does not assume the B-query certificate or hide probability witnesses; subsequent modules supply finite graph decision bodies.
- `FiniteGraphDecisions.lean`: construct bounded recursive route decisions; prove the finite bound from genuine simple-subroute erasure and the finite-cardinality bound; construct explicit arrival-state enumeration and decisions for ancestry and active connection. This supplies proof-bearing terminating definitions for finite graphs with decidable edge and conditioning data, not an evaluated algorithm or an assumed graph oracle.
- `FiniteSelectedMAGDecision.lean`: instantiate those decisions on the actual original finite DAG, including selected conditioning. A finite Boolean-conditioning search plus the proved inducing/separator bridge decides inducing paths; original ancestry decides the exact endpoint marks; finite union and own-target deletion decide the literal TCM edges. The full registry still uses a noncomputable `ofInjective` construction until explicit Boolean-profile decoding and membership decisions replace it. No optimized query bound or physical faithfulness decision is obtained here.
- `ExplicitProfileDecoding.lean`: give a total decoder from the complete Boolean profile code, including all singleton flags and marked bridges. Virtual tails inconsistent with F are filtered; a cyclic observed part is replaced by the empty graph. Every decoded entry is an admissible common-source profile and `decode (encode Q) = Q` for every admissible Q, so no original source is lost. The exact original TCM-image theorem is re-proved using this finite code enumeration, not the abstract Prop-profile Fintype. Computable canonical label enumeration/order, finite signature filtering and output encoding still require integration; the coded list remains explicitly noncomputable meanwhile.

The intermediate selected graph has an arbitrary selector type and is derived from the original DAG by the supplied proof bodies. Original selection and latent sizes are unrestricted. The bounded canonical source is selected once and then all named indicators are added to that same source. This graph-source result is unelaborated and is not, by itself, the complete target or statistical theorem.
