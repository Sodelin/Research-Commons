# Seat 1: Lean completion plan for the binary balanced-cap theorem

**Decision:** continue formalizing the exact, weak undirected adjacency obstruction for countable portfolios of original binary cap-two populations, using the three-root edge-labelled source. Do not claim fixed-source genders, bounded stretch >1, or ordinary cap-three hosts. The general Alexander §6 question and the precise balanced variant are different. The paper supplies the model and question, not this cutoff proof. The pinned provider is Alexander research commit e2502c82ab9a77c00543932f775a71e5374221f7 (`BinaryAvoidance.Edge`, `aperiodic_target_avoided`, `InfiniteConservation.eventually_regular`). Round 3 provides `TwoLiftTriangle.triangle_iff`, `TwoLiftLanguage.same_language`, and the chronological encoding bridge.

## Dependency DAG

1. **Source model.** Pinned base Edge plus binary avoidance → unmerged Up and exact language → merged source vertex type `Option (Nat × Bool)`, level 0 at none and level n+1 at some (n,s), with exact edge/adjacency bridge. New MergedRoot component checks this, exact parent/child lists, exact root shape, two distinct children at each vertex, strict edge chronology, functional labels, and two distinct opposite-labelled parents at each nonroot. To certify the full *population object*, still package these with finite sublevels/infinite vertices under the `ChronologicalEncoding.RelationalPopulation` definition; check the three roots as a Nodup list rather than merely shape.
2. **Source triangle signature.** Merge does not create a triangle at the only new root: its two neighbors have the same level. Over positive levels, recover round 3 triangle characterization from the obvious equivalence of the two Up relations. Therefore every triangle edge lies in a same-sheet untwisted consecutive triple. Use a protocol `∀ m≥1, (m ∈ A ↔ arbitrarily late zero-runs of length m)` with every zero in a complete finite run and runs separated by ≥2 ones; select twists outside runs. Two short-edge rays plus arbitrarily late switches give a connected cofinite component after finite deletion. For each retained cofinite tail, classify all sufficiently late triangle-edge components by zero-runs and derive the invariant.
3. **Host transport.** Relational population → ChronologicalEncoding.present → natural presentation; `exact_adjacency` preserves underlying graph. Apply `eventually_regular` to construct a finite source/host neighbor-list interface at degree four, append two parent and two child entries, using chronology to prove disjointness. Delete an entire host chronological prefix of length m containing host degree exceptions **and images of the three source roots**. Injection implies the deleted set in the source is bounded in coordinate: for each of the m possible images there is at most one preimage. Use a simple induction over m, giving the maximum source level among any existing preimages. Do not work with arbitrary finite delete sets here.
4. **Component isomorphism.** Equal finite degree plus weak injection implies local neighbor surjectivity. Use the checked generic `neighbor_lift_of_same_degree` (or the round-3 Nat specialization). New checked `same_component_iff` lifts whole walks in the retained host back to the retained source; `induced_adjacency_iff` gives exact adjacency on images. Apply both with a kept source representative in the connected cofinite tail. Its entire induced component is isomorphic to the entire induced host component around its image. Existing walk definitions may be bridged by simple induction if a common relation is imported.
5. **Counting avoided by explicit diagonal.** Index host signatures by (j,m,r), host index j, chronological cutoff m, and representative r, each natural. Signatures use components of the induced host graph after deletion, then the triangle-edge subgraph **inside** that chosen component. Choose a size n+3 bit that means arbitrarily many disjoint finite triangle components of that size. New checked `SignatureDiagonal` codes triples injectively and complements precisely the bit at its code. One twist sequence encoding A(n)=diagonal n suffices to refute any proposed countable portfolio; no cardinal arithmetic imports or explicit enumeration of finite subsets. A second theorem gives pairwise incomparability (same cofinite component argument for another lifted host).
6. **Final assembly.** Make the model, graph language, and candidate embedding theorem consume the same actual source relation. Rebuild pinned sources and components in a clean directory; reject weakened controls e.g. unequal degree, allowing a switch inside a claimed zero-run component, or an adjacency-only source graph not tied to the labelled one. Report exact axioms and no `sorryAx`. Until then this is a checked component chain plus complete hand proof, not a Lean theorem in original §6 model.

## Highest-risk remaining lemma and recommended order

The next most useful endpoint is **exact component size via a bounded zero-run**, not a general “finite edits preserve graph invariants” theorem. State: above the maximum removed source level and its two-level margin, each finite maximal zero-run of m bits bracketed by two switch bits (on the side between consecutive runs) induces one triangle-edge connected component of m+2 vertices in each sheet, and every sufficiently late nontrivial triangle-edge component is of this form. Prove triangle membership is coordinate-local by the round-3 theorem, connect overlapping triples by walk induction, and prove no triangle edge crosses the run's interval or sheets. Use adjacency of consecutive coordinates rather than general finite connected graph tooling. A component in the retained graph at sufficiently late coordinates sees exactly the same triangles, because each triangle spans only two levels. State the signature as: for every finite list of vertices there is a size-m component avoiding the list (equivalent to infinitely many distinct size-m components); an isomorphism transports it by finite lists. This keeps the host side abstract and dramatically reduces library burden.

Next, implement the actual switch generator. The hand proof's triangular schedule (at stage r, append every m≤r in A, plus two ones after each and at least two per stage) is robust. Lean can define stage words by recursion/prefix data; alternatively use consecutive disjoint deterministic slots with natural sizes, fill a slot by zeros iff the encoded A-bit holds, always leave two ones between slots; define maximal runs using arithmetic intervals. All infinite claims reduce to the ability to repeat each candidate bit arbitrarily late. No decision procedure for determining A is asserted; Classical.decEq or Classical.propDecidable is expected.
