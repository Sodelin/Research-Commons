# Round 3 provenance and replay admission

1. **Static gate.** Resolve the commit+path from the release, bind the exact Git
   object and SHA-256 bytes, allow one manifest path per source, and reject spelling
   collisions, traversal, unlisted files, modified controls, and incomplete import
   closures. A coherent archive is not verification of the upstream Git ref itself.
2. **Fresh proof gate.** Start with no project oleans; pin the compiler plus standard
   library and resolve only approved imports. Separate no-dependency
   `FiniteBallDiagonal` and `TerminalExtension`, then check
   `TwoLiftTriangle → TwoLiftLanguage` plus BinaryAvoidance, and check the observation
   pair with the clean PresentedCappedHost import DAG. Execute the full packaged
   bundle once as release regression. Run finite Python geometry separately.
3. **Typed downstream gate.** Verify exact declaration type, axiom closure, and
   dependency lock; use a consumer that evaluates the exact theorem, and explicit
   controls that would fail a scope-widened statement. A receipt, successful compile
   of an imported module, or an executable fixture does not close a whole result.
4. **Catalog join.** Reuse current theorem intake; key candidates by namespace,
   compiler and normalized exact type, then record source commit/blob/hash and
   transitive import digests for the attestation. Add typed dependency edges with
   roles `kernel_import`, `exact_consumer`, `negative_control`, or
   `related_unproved`. An equal display name is not a join key. Quarantine drift,
   and invalidate replay receipts when source or transitive lock changes. Version
   declaration status separately from whole theorem/solver status.
5. **Admission in this council.** Replay checked sublemmas as scoped components;
   preserve full spare-child / combined two-sheet as hand proofs, not automatic
   conversions. Keep fixed-source-color transfer and matching-fibre grid witness
   open. Keep observation endpoint conditional and solver integration absent.
   A qualified catalog edge needs matching assumptions and conclusion, not merely
   matching language/fixture labels.
