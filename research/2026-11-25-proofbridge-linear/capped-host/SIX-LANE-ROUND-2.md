# Alexander 001 follow-on: grid minors

Two pinned Lean proofs rule out a finite square grid minor of side n > k * fullRootCount(p) + 1 in the natural-order infinite balanced k-child host. Each cell is a nonempty, finite connected list of host vertices. Distinct cells have disjoint vertex sets, and horizontal/vertical neighbors are joined by an actual host edge with endpoints in their own branch sets. Arbitrary walks with shared transit are not the statement. This extends the grid obstruction used in round one; it is not a claim about larger child caps, the countable-host-family problem, a newly built Mathlib Real consumer, or originality of the classical grid-cross method.

- [Direct endpoint](EfficiencyGridMinorEnd.lean): uses bounded connected-hit intervals and the existing common-bag lemma, then counts distinct cells only at the common bag.
- [Reusable endpoint](GridMinorObstruction.lean): uses the largest first hit among finitely many convex cut sets, so the common-cut lemma does not need right endpoints. The separate incidence lemma shows that meeting all crosses is equivalent to covering all rows or all columns. Only the covered side needs coordinate separation for that counting proof, not a full cell assignment.
- [Exact contract parity](GridMinorRouteParity.lean): both endpoints implement the same explicit proposition. Both recover the original embedding obstruction via singleton branch sets without calling the earlier theorem.
- [Controls](GridMinorControl.lean): a one-root ray with width at most 2 routes all twelve edges of a 3x3 grid if transit may be shared; that weak routing is not a minor. [A separate C8 example](ScopeCheck.lean) has a square minor but no square subgraph in an abstract graph, not necessarily a host in this model. [A positive consumer](GridBranchUnionConsumer.lean) imports the union lemma for two non-singleton linked branch sets.

## Replay and evaluation

Use pinned Lean 4.33.1 (commit 819816b2e0a3bf405af45ae5c7af2491d8f5bee6). In a clean source staging directory, include the five Commons sources listed in [the baseline](grid-minor-baseline.tsv). They match Commons e77c3ad997ccfbd9fa10b9ff36c9a3181be8679e. Into a local `SamuelAlexanderResearch` directory under the staging directory, copy the three listed source modules from [the companion pin](https://github.com/Sodelin/Work-on-Samuel-Alexander-Research-/tree/e2502c82ab9a77c00543932f775a71e5374221f7/lean/SamuelAlexanderResearch). Run `bash replay-grid-minor.sh /path/to/lean`. Verifies eight Git blob IDs before the build. The clean run started with no compiled files, exited zero in 19.699 s, and used only propext, Classical.choice, and Quot.sound for the two endpoints. [Replay log](GRID-MINOR-REPLAY.log).

Five alternating-order [addon rebuilds](grid-minor-benchmark.json) from the same already-built common dependencies took median 1.576 s direct and 3.765 s reusable. The direct addon compiles two modules; the reuse addon compiles five, including extra interfaces. This is a check-cost comparison, not time to discover the proof, nor an estimate of savings on future theorems. Branch-cross connectivity is shared; no duplicate credit.

Scoring uses the same 40 scope, 25 gap closure, 20 reusable evidence, 10 measured economy, 5 collaboration as round one. Direct: 40 + 25 + 17 + 10 + 5 = **97**. Reuse: 40 + 24 + 20 + 6 + 3 = **93**. The direct side closed and independently replayed its endpoint; the reuse side's completed endpoint relied on coordinator integration of its common-cut design and the shared verified branch-cross code. Reuse produced the stronger counting interface and consumer; direct is the fast default for this target. These are judgments about this round, not a strategy ranking over a corpus.

The classical background is the [grid cross/bramble argument](https://www.math.uni-hamburg.de/home/diestel/books/graph.theory/preview/Ch12.pdf). Preserve the ordinary five-slot automation; this was a separate bounded run.
