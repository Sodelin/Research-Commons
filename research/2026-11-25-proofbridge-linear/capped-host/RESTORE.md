# Restoring the capped host proof components

The source and its version history live in Research Commons. The separate recovery archive includes the transitive local source needed for the grid check. Use Lean 4.33.1 at commit `819816b2e0a3bf405af45ae5c7af2491d8f5bee6`. In the extracted archive run `bash replay.sh /path/to/lean`. No copied build cache is required. The three `SamuelAlexanderResearch` source modules come from [the pinned companion project](https://github.com/Sodelin/Work-on-Samuel-Alexander-Research-/tree/e2502c82ab9a77c00543932f775a71e5374221f7/lean/SamuelAlexanderResearch).

A clean replay compiled all nine providers, then checked the separate consumer. It verified the common cut and that a grid of side greater than k times the number of roots plus one cannot embed in the naturally ordered balanced host. It also checked a one-cell boundary control for the generic k=0 model. This is the full grid obstruction in the natural-order model, not full Alexander-001: real-date transport, the eligible finite padding and infinite-word language preservation, and final assembly still need their own proof. The automation setup and installed compiler are not part of Git history.
