# Literal supplied-certificate support proofs

This additive emitter reuses the unchanged checked-certificate parser and
literal proof generator from the verified unified solver. For each accepted
rational certificate at levels 1..8 it preserves the original base proof and
adds an exact coefficient/level binding to the selected positive-support
adapter. The proposed Lean conclusion bounds distinct positive-mass survival
values by L−1, conditional on the same finite bank's exact original moments.
No latent target, source witness or requested bound is supplied to generation.

Run `python3 -B emit_support.py CERTIFICATE.json NEW_OUTPUT_DIRECTORY` from this
directory. The checked input contains exact rational coefficients, normalized
moments, and a weighted-square identity; no floating-point calculation is used.
The output includes the unchanged `Certificate_<identity>.lean`, its new
`Support_<identity>.lean`, and an emission manifest marked `compiled=false`.
The output directory must be absent; existing evidence is never overwritten.

`prepare_cases.py` prepares seven deterministic cases: the three prior cubic
certificates, the endpoint linear polynomial, a certificate with zero constant
term and nonzero evaluation at 2, a level-four square, and a level-eight
certificate with unchanged lower-level coefficients. The bounded Python
controls authenticate original source bytes, certificate identities, exact
nonzero evaluations, malformed-certificate refusals, and output preservation.
They do not prove the generated Lean source elaborates or refine the native
program. A successful separate compiler receipt is still required.
