# One entry point for existing solver, selected readout and support emission

**Source-only integration draft. No runtime tests or compiler runs have been performed for this packet.** Execution awaits the shared owner's quiet-window release. The runtime delegates existing mathematics, decoding, source search and native checking; it introduces no new solver or native compiler.

`runtime.py` accepts either original request unchanged:

| Request schema | Exact delegate | Result scope |
| --- | --- | --- |
| `unified_research_solver_v1` | Existing `solve.dispatch` | Original certificate/generation/menu, RC1 or source-search contract |
| `selected_native_common_readout_v1` | Existing `selected_readout.run` | Exact selected native readouts; physical/source decision remains UNKNOWN |

All five original unified tasks remain available: `check_certificate`, `generate_singleton`, `common_menu`, `native_rc1`, `source_search`. The strict original certificate parser rejects duplicate fields, floating/nonfinite input and excessive nesting. The primary bytes are preserved literally in `REQUEST.json`; their SHA256 is separate from the original canonical JSON identity. Selected requests reach their delegate as those same bytes. Unified requests reach the unchanged dispatcher as the strictly parsed original object. No new request wrapper, protected label, fitted parameter or renamed ID is inserted.

The output directory must be absent. The 256 KiB bytes/UTF8 transport gate precedes directory creation for both CLI and direct API. An oversized request is refused without preserving a truncated request as though it were complete. Bounded malformed inputs retain their literal bytes and a refusal result. Unsupported entry schemas/tasks and unavailable runtime/provider identities return UNKNOWN. Original delegate refusal/UNKNOWN distinctions remain intact; this layer does not rewrite established validation contracts.

`RESULT.json` records the complete delegate result and its preserved file hash, invocation/return state, exact provider pins, primary and derived request identities, and optional support-emission results. Existing delegate subdirectories retain source backend/native execution/check receipts. For `source_search`, a certified source witness or certified exclusion within the declared complete covered registry retains its exact original `scope`, `covered_class`, semantic checker and feasibility flag inside the unchanged child result. This entry point neither enlarges that scope nor labels all existing source results UNKNOWN.

For selected-copy readouts, even complete 48-row formal matches remain physical/source UNKNOWN. The full padded 6/7/8-copy descriptors are retained by the existing adapter; its native execution computes the selected 2/3/4-copy readout. No full padded native table, typed physical row equality, protected dependency expansion or universal native refinement is added here.

Optional `--emit-support` reuses the exact existing `emit_support.emit`. It emits one `support/<certificate-id>/` directory per distinct original certificate identity and retains every input reference to a duplicate. Literal certificate and support sources plus the emitter's manifest are preserved. Emission is conditional on supplied moments and remains **uncompiled**. It does not convert a native match into a Lean row proof. Optional emission failure is recorded separately and does not alter an already returned delegate's semantic outcome.

For certificate checking, `--rust-binary` accepts only the observed original checker SHA256 `1a508f23613bb527e5605c806fb8215ed6a16adeed4c4147658236790064d805` or the observed checker/generator `3d7678fac5ba8138b28a08e40c6ca8ac2b3a6e13267350d48480997e53f27ef7`, with their exact closed build receipts and separate execution observations binding those executable hashes. The singleton `--native-generation` route requires the latter capability. The executable is checked before and after dispatch. RC1 parsing, forward computation, exact request replay and runtime/source authentication remain owned by the existing pinned `native_bridge`, including its original child limits. No arbitrary executable is invoked as a certificate checker by this facade.

Example commands, **not executed for this draft**:

```sh
python3 -B runtime.py --request /path/to/original-unified-request.json \
  --output /path/to/absent-output --emit-support

python3 -B runtime.py --request /path/to/original-selected-request.json \
  --output /path/to/another-absent-output --emit-support \
  --parity-binary /path/to/pinned/parity-solver \
  --parity-sources /path/to/authenticated-restored-tree
```

Forward the old backend Python, certificate-checker or RC1 options as required by the chosen task. Do not supply certificate-checker options to the selected-readout schema. Run future execution through the existing conservative guard with one owner; this source draft starts no background process and changes no resource setting. CLI exits 2 for UNKNOWN, 1 for refusal and 0 for other delegate results; inspect the full result for its actual certificate/source scope rather than treating exit 0 as universal YES.

Trusted boundaries remain the reused native/back-end implementations, Python exact arithmetic/transport and extraction, observed source-to-binary build relationship, compiler and operating system. Finite execution controls can check this new delegation/identity composition but do not prove universal native correctness. Lean compilation, actual physical source/row proofs, the missing protected-representative provider and arbitrary-input G3 remain separate work.
