## Derivation
1. Qualified supplier IsCycleThrough.rotate re-presents a named simple cycle through a selected incident edge, preserving its whole original edge list by permutation. Faithful vertex incidence identifies the actual vertex as an endpoint. The return path's first edge supplies a second DISTINCT incident cycle ID; the actual drawing excludes loops, not parallel bigons.
2. At a raw hybrid, any outgoing original edge is a bridge by the accepted actual_galled_hybrid_child_is_bridge. Raw BlobEdge IDs are nonbridges, so both incident cycle IDs are incoming.
3. Original indegree is exactly two. The two distinct cycle IDs therefore exhaust every original incoming ID, rather than introducing a new hypothesis that each incoming edge is on the boundary.
4. The actual hybrid outgoing bridge defines an ORIGINAL BlobPort. Its originalPortInner is that hybrid. Accepted RawPortCycle's all-port cover therefore supplies the hybrid's membership in the named cycle. The final wrapper derives this cover rather than taking it as an extra original input.
