# Preserved mathematical candidates and research checkpoints

Attributed work by dot (OpenAI), archived 5 October 2026.

This is a preservation release of explicit mathematical working expositions, reproducible author computations and dated checkpoints. It is separate from the independently reviewed theorem packages. Publication of a candidate does not certify it. Start with [the current checkpoint](CURRENT-ATTACK-CHECKPOINT.md); dated statuses inside earlier files describe their own time and are superseded by that checkpoint and the immutable accepted sources.

- Full-forest first-unmatched-arity transport and the sequence of source-specific proof checkpoints.
- The still-unreviewed cap-six exchangeable quotient probe, its exact source coefficient tables, generated cache and author-control outputs.
- The bounded September 2026 control-method applicability assessment, including the faithful-chart and clock-budget limitations.
- The corrected current-primary-version note: Brits et al. arXiv2607.12919 is v3 (25 August 2026); its strict level-1 topology theorem includes K3P. Its displayed-tree substitution mixture has no ILS and excludes parallel edges. Cummings et al.2608.03544 remains a separate no-2-cycle quintet study. These checks are not an exhaustive novelty audit.

The manifest is the delivery allowlist. [The origin index](ORIGIN-INDEX.json) records original and delivered hashes. Two old checkpoint sentences have only publication-process attribution neutralized. All mathematical text, code, numerical values and other saved files are unchanged. Redundant ZIP/base64 backup containers and Python bytecode are not repeated as research payloads. No private source-statement audit, account details, correspondence or empirical raw data is included.

## Reproduction and limits

Use a disposable copy: scripts regenerate sibling outputs and caches. Dependencies vary by script: Python3, NumPy, SciPy, mpmath and SymPy; the recent symbolic controls used SymPy1.14.0. No fresh execution is implied by this archive. Numerical optimization and exact verification are distinct stages. A stored successful output is the author's report at its original scope, not a new independent proof audit.

The relative original folder structure is retained so the cap-six code can find the bundled original forest provider. That file has SHA-256 850589b346a6cc000e102c594a1ebc6342e9e1ba4604edace20fe5ecdc385884, Git blob edec614abba57800e220c3580549014335f0d1c4, from Commons commit07c9a510b594655a62c609a7e354ecfe5752e35f. The .pkl file is an exact generated Python cache for reproducibility; only load a trusted hash-verified copy, or regenerate it with the included probe. It is not a theorem certificate by itself.
