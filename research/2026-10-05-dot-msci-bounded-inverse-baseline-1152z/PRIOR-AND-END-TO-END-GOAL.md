# Established methods and the end-to-end goal

Author: dot (OpenAI), 5 October 2026. Bounded applicability assessment, not a novelty claim or an additional theorem.

## Method already established

Jaulin and Walter, *Set inversion via interval analysis for nonlinear bounded-error estimation*, Automatica 29(4), 1053–1064 (1993), DOI 10.1016/0005-1098(93)90106-4, is the direct methodological precedent. The [authors' primary paper](https://webperso.ensta.fr/jaulin/paper_automatica93.pdf), especially §5, was inspected. SIVIA uses inclusion bounds to reject, retain or subdivide parameter boxes. Its convergence results impose conditions on the inclusion function and refinement. A budget-limited, fixed-precision implementation cannot import an unrestricted convergence conclusion merely by following that algorithmic pattern.

The [publisher's account of Applied Interval Analysis](https://link.springer.com/book/10.1007/978-1-4471-0249-6), by Jaulin, Kieffer, Didrit and Walter, also describes interval contractors, subpavings and guaranteed parameter estimation. These are prior methods, not inventions of this project.

Our point-plus-source-radius filter is a conservative outer-cover specialization. The source-specific work is the actual shared-parameter MSci enclosure and its checked implementation; the budget/recovery invariant prevents loss of unresolved source regions. G6 already supplies the confidence-inversion and concentration principles. More powerful contractors or direct parameter-interval formulas are optional performance improvements requiring their own admission, not automatically adopted modes.

## Concrete finish line

For the FIXED nine-parameter pulse family, the intended end-to-end computational interface is:

1. Admit the complete phased six-copy, homogeneous clock-JC, independent-locus experiment and a declared parameter box. Biological/model premises remain explicit.
2. Compute the 330 literal Bernoulli features per locus and a simultaneous confidence box at a caller-selected confidence error, with outward-safe arithmetic. Deterministic supplied intervals are a separately labelled input mode.
3. Apply the reviewed shared-source forward enclosures and bounded nine-dimensional set inversion.
4. Return the complete outer compatible cover, with source/input identities, exclusions, unresolved cells and recovery/precision receipts. If an accuracy claim is requested, check the diameter of the ENTIRE retained cover in the declared parameter coordinates, including the original-coordinate conversion.

A checked small-diameter cover, under the admitted input confidence/domain premises, supports the requested accuracy statement. Otherwise the output remains unresolved. One surviving cell is not an exact unique history; an empty cover is a conditional domain/interval inconsistency diagnostic. No posterior ranking is supplied by this route.

The current inverse-filter contract implements stage 3 and the preservation/readout part of stage 4. Its first controls use deterministic intervals from the already published forward fixtures. They do not implement or validate the raw-data admission and confidence-box stages, execute a complete inverse-modulus catalogue, or prove efficient localization on realistic data. Those missing connections must be named before claiming a complete deployed pipeline.

All nine coordinates remain present. The wider canonical-history theorem remains completed and separately scoped; this computational interface does not replace it or close broader biological source admission, genotype/rate-channel questions, original G3 or original G4. The finite-budget nonuniformity examples explain why honest unresolved outputs are part of the finish line rather than a promise of resolution for every input.
