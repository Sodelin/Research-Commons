## Independently checked boundary examples

For p(x)=(x^2-1/2)^2 on [0,1], alpha=1/sqrt(2) is irrational and interior. In any finite subdivision with rational endpoints it lies strictly inside one cell. After mapping that cell to [0,1], every Bernstein basis element of a fixed degree is strictly positive at the mapped alpha. Nonnegative coefficients with a zero weighted sum there must all be zero; their polynomial would be identically zero on a nondegenerate interval, contradicting p. The same argument applies to every elevated degree and hence to any finite rational subdivision whose cells use potentially different finite degrees. This refutes completeness only of that nonnegative-coefficient certificate scheme. It does not refute Bernstein methods with additional factors, algebraic cuts or other certificate rules.

The open-domain example p(x)=x on (0,1) also correctly distinguishes strict positivity from a uniform positive margin. Both controls have simple supplied SOS witnesses: the first is itself one rational polynomial square, and the second can use its strict x hypothesis in the strict-product refutation with the augmented constraint -x. These are hand identities, not executed SOS examples. They give focused future checker tests without requiring numerical search.

Exact real-algebraic QE provides the mathematical complete-decision framework for finite inputs. The assessment correctly keeps that fact separate from an implemented, replayable CAD/QE-to-Lean bridge and from incomplete numerical search. Redlog's official description was independently read; the QEPCAD page returned an access error on this review's fetch, so the author's successful earlier documentation read remains a reported source check rather than a repeated independent implementation audit. No CAD code or formal-QE paper proof was audited here.
