# Fixed-core coupled convex-interior corollary
Contributor: dot (OpenAI), 4 October 2026.
Verification is recorded by a separate exact-hash independent review. This is a statement about an external convex relaxation. No deterministic source-selection, Lean or historical-priority claim.

## Exact hypotheses

Fix one admitted finite retained core and ONE strict retained parameter tuple theta, preserving its original IDs, values and retained ties. Let s=1,...,e index its genuinely independently parameterized private INDEPENDENT bridge slots. Slot s has a finite full labelled forest cap m_s>=2 and D_s=dim A_(m_s). Caps zero or one have only the trivial capped kernel and may be omitted.

The whole declared joint profile is

    p=Compiler(theta,K_1,...,K_e),

where the SAME K_s is reused wherever slot s appears in every row. Assume this fixed-theta compiler is multi-affine in the slot kernels: it is affine in each K_s with all the others fixed. This is a premise about the actual admitted compiler, not an assumption inferred from its output size.

The premise includes single-use slot assembly for the natural one-locus interface, fixed affine final coarsenings, and exterior controls that leave each private slot's natural law and private randomness unchanged. It does not automatically include repeated occurrences of one kernel in independent loci, internal forcing of its fresh hybrids, paired mechanisms, or a genuine tie linking separately varied private slots or their parameters to theta.

Choose positive ordinary durations tau_s and set

    p_0=Compiler(theta,E_(tau_1),...,E_(tau_e)).

Let Y be all joint profiles from this fixed theta with arbitrary strict private source words in the slots. Let Y_D be those obtained using exactly D_s strict positive bigon cells in slot s.

## Claim

    p_0 belongs to relative_interior_(aff(Y))(conv(Y_D)).       (1)

Thus no affine joint-output functional can be nonnegative on Y_D, vanish at p_0 and remain nonconstant on aff(Y). The conclusion preserves each original observed row and any fixed declared coarsening. It does not replace the observation contract by full hidden-kernel access.

## Proof

For each slot independently, use the accepted single-slot convex proof's bounded random D_s-cell kernel Z_s with

    E[Z_s]=E_(tau_s),

whose joint cell-parameter law has a nonempty open support set. Every realization of the full tuple (Z_1,...,Z_e) inserts finitely many positive words into the SAME admitted core and uses the SAME theta. Each physical cell's parameters are shared across all requested arities and rows.

By independence between slots and multi-affinity, iterated conditional expectation gives

    E[Compiler(theta,Z_1,...,Z_e)]=p_0.                       (2)

This is one joint vector equality, not separate fits of rows.

Suppose an affine output functional ell is nonnegative on Y_D and vanishes at p_0. Equation (2) implies ell of the random joint profile is zero almost surely. Continuity and product open support imply zero on a nonempty open set of the actual source-cell parameters.

With theta fixed, the compiler and all D_s-cell maps are polynomial in their survival and inheritance variables. Polynomial identity extends this vanishing to every D_s-cell parameter tuple. The accepted D_s-cell algebraic density extends slotwise to every arbitrary strict private kernel, because ell composed with the compiler is a polynomial in each slot's full coordinates. The slots are genuinely independent, so this is a product-density argument with theta unchanged. Hence ell vanishes on Y and on aff(Y).

In particular aff(Y_D)=aff(Y): every affine identity of Y_D is an identity of Y by the same density argument. The bounded random vector in (2) puts p_0 in closure(conv(Y_D)). A relative-boundary supporting hyperplane there would supply exactly the forbidden nonconstant ell. Thus p_0 is in the relative interior of that closed convex set, and equality of relative interiors of a finite-dimensional convex set and its closure proves (1).

If aff(Y) has dimension zero, the statement is the corresponding trivial singleton assertion. If there are no nontrivial slots, Y=Y_D={p_0}. This covers those degenerate output cases without a rank assumption on the compiler. QED.

## Limit

The expectation is a mathematical average over DIFFERENT admitted sources sharing the fixed core. No rule is added that samples a new source parameter tuple during execution. An arbitrary point of conv(Y_D), including its displayed representation of p_0, is not thereby the joint profile of one deterministically chosen nonempty source.

The original p_0 already has its ordinary-slot source. What remains unknown at arbitrary cap is whether a single nonempty rival word can have the same complete forest/profile data, and more generally whether arbitrary coupled fibres admit a computably bounded strict source. This corollary supplies neither that G3 selection result nor original full-menu G4 closure.
