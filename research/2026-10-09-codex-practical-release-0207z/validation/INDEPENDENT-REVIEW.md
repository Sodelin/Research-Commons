recover conservatively to the original domain with all normalized widths1.

numerical replay still rejects it and returns RECOVERED_UNKNOWN. Thus this
control exercises recomputed numerical evidence beyond detection of changed
bytes. A513-frame journal exceeds the512-frame cap and is refused.

attach historical claims to altered fixtures. Before freeze, the application
owner added expected hashes for examples, saved receipts, dependency manifest
and finite-data obstruction; diagnostic source changes now prevent PASS.

leaving reviewed production files untouched. The final exports contain no

credentials. Stable trusted package files are still a premise; these hashes
are not signatures or protection against replacement of the whole package.
