## Conclusion

The new source search has not identified a theorem proving the missing algebraic whole-observation-fibre implication. It has identified precise reasons why the nearest positive-realization, phase-type and attainment theorems do not suffice, plus a useful exact joint-realization obstruction in an adjacent model. This is a bounded primary-source applicability result, not proof that no suitable theorem exists.

The open target remains: for exact algebraic observed input, does the existence of a complete target point in the all-semialgebraic inductive hull over a real-closed extension imply that SOME standard finite strictly positive original source realizes the SAME entire joint observation fibre? The actual source may use a different permitted core or hidden tuple. For a fixed finite architecture, real-closed-field transfer already handles the parameter field. What is missing is existence of a finite source architecture/factorization in the first place.

The stronger unrestricted real-state statement is already false in accepted project results. The observable-hull example uses a transcendental observation, so it does not settle this algebraic-input question. ## Exact transfer judgments

1. [Aznagulov,2609.14623v1](https://arxiv.org/abs/2609.14623v1): priced finite-state attainment requires an existing finite-cost realization. Bounded-dimension closure requires a bounded state count, finite entropy liminf and the stated path topology. It does not create a finite source from hull compatibility. The model is a general stationary CTMC, not the original acyclic coalescent grammar. Classification: excluded direct bridge; useful architecture-cost comparison.
2. [Cortese et al.,2406.11696v4](https://arxiv.org/abs/2406.11696v4): exact positive reduction starts with a supplied positive linear system and characterizes nonnegative projector-factor reductions. Its linear reachable space permits signed inputs and is distinguished from positive reachability. Classification: excluded direct bridge; useful sign/representation checklist for any proposed reduction.
3. [Lindqvist,2023](https://pubmed.ncbi.nlm.nih.gov/35132532/): Theorems4–5 concern equivalence and canonical uniqueness of supplied nonredundant competing-risk/Coxian phase-type models. The similarity matrix may have negative entries. Classification: source-equivalence tool at its supplied-model contract; no Kingman/current-root realization construction.
4. [Peralta,2605.15395v1](https://arxiv.org/abs/2605.15395v1): Theorem4.2 gives a joint denominator factorization obstruction for finite positive Markov reward systems. Theorems4.5–4.6 construct a law whose every positive scalar projection is PH, but whose joint law has no finite Markov reward representation. Classification: a genuine adjacent joint-realization obstruction. It reinforces the need for common parameters, but uses a whole Laplace-law observation and a different source grammar; no G3 NO conclusion follows.
5. [Allman–Ané–Baños–Rhodes,2025](https://pubmed.ncbi.nlm.nih.gov/41123850/): Theorem5.7 identifies networks in specified C4/C5 classes under genericity and declared gene-tree/sample conditions. It assumes a model-generated law; it is not a realization test for arbitrary observed input. The paper explicitly leaves raw-sequence-to-gene-tree reliability as a premise. Classification: biological source/observation admission and conditional identification, not hull-to-source existence.
6. [PhyloCoalSimulations,2023](https://pubmed.ncbi.nlm.nih.gov/37254872/): the exact record specifies the independent/common/correlated inheritance model and official implementation source. Classification: generative-model reference, with no new code run or universal inverse theorem claimed. [Zhu–Degnan](https://pubmed.ncbi.nlm.nih.gov/27780899/) further warns that displayed-tree agreement does not determine the full coalescent observation law.

Existing moment/finite-atomic realization, HMM and finite-word equivalence results remain in the earlier literature ledger. A finite positive atomic law is not automatically a finite Bernoulli-product private word; arbitrary mixtures need an admitted graph construction. The new search does not rename those already known restrictions as discoveries. A separate existing applicability note on [Mattner, 2204.06040](https://arxiv.org/abs/2204.06040) concerns fixed numbers of unweighted Bernoulli trials and cumulants. Its bounded number of distinct probabilities does not bound integer multiplicities. The old dyadic source construction already uses one repeated factor type per approximant while minimum total length diverges. That prior comparison remains an unreviewed applicability note, rather than a new theorem acceptance here.

## What an applicable next theorem must provide

- Preserve the exact finite rooted binary cut-child galled class, positive finite population parameters, and literal COMMON/INDEPENDENT current-root routing.
- Retain the original IDs, fixed/read-only edges, one shared parameter vector and joint randomized control programme across all rows.
- Conclude a standard FINITE source somewhere in the complete algebraic observation fibre, rather than only a signed representation, limiting source, generic joint distribution, finite-dimensional CTMC of another class, or approximate match.
- Supply either a source-faithful finite factorization/extraction theorem, a sufficient exact algebraic-fibre representation criterion, or an admitted obstruction with the same algebraic-input quantifiers.
- Keep data/model validity separate: no empirical fit or simulation establishes the universal implication.

Theoretical value remains possible without an immediate algorithm. A valid characterization, sharper obstruction or exact source transfer would count. No paper in this bounded search has yet supplied it. Further source work should be chosen by this contract rather than by the word “realization” alone.
