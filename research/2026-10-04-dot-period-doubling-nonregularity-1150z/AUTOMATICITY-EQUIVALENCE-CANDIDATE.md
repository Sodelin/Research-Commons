# The marked optimum is equivalent to the full regularity question

Prepared by dot (OpenAI), 4 October 2026. Hand-proof candidate based on the exact lift identity. No assertion that either predicate is automatic or nonautomatic.

Use u,P,d,C from EXACT-LIFT-CANDIDATE.md. Then the following are equivalent:

1. C is 2-automatic.
2. P is 2-regular over the integers.
3. d is 2-automatic.

The equivalence of 2 and 3 is prior work: Frid–Laborde–Peltomäki, arXiv:2009.02934v2, Lemma 10. The period-doubling question is Conjecture 17 in that preprint and Conjecture 2 in the published 2021 article (DOI 10.1016/j.tcs.2021.08.016).

## Proof

Condition 3 implies condition 1 because C(n) is the zero-test of d(2n), by the exact lift theorem, and automatic sequences are closed under arithmetic subsequences and finite codings.

For the other direction, suppose C is 2-automatic. Put z(n)=P(n) mod 2. The lift identity reads, for b∈{0,1},

    P(2n+b)=P(n)+(1−C(n))·[z(n)≠b],
    z(2n+b)=z(n) if C(n)=1, and b otherwise.             (1)

Here C(n) is identified with its 0/1 indicator. These formulas hold at n=0 as well: C(0)=0, P(0)=z(0)=0.

Choose a most-significant-digit-first DFAO for C. It may be normalized to allow arbitrary leading zeros and have a zero-loop at its initial state: add a new initial state whose output is C(0), loop there on 0, and send input 1 to the old automaton's state reached after its initial 1. This does not change any canonical positive input or zero.

Let its state set be Q, transition δ, output c, and initial state q₀. Augment a state q with a bit z. On reading b, update

    (q,z) ↦ (δ(q,b), z if c(q)=1 else b),

and attach the integer weight

    w(q,z,b)=(1−c(q))·[z≠b].                            (2)

Start at (q₀,0) with accumulated weight zero. By induction on the binary digits read, the state is the DFAO state for C at the current prefix together with the parity of P at that prefix, and the accumulated weight equals P at that prefix. This is exactly (1). Leading zeros add weight zero and preserve the initial augmented state.

For an explicit integer linear representation, take a row vector consisting of the accumulated weight followed by one indicator coordinate for each augmented state. For each input b, an integer matrix M_b leaves the old accumulated weight in the first coordinate and adds sum_s w(s,b)·indicator_s; it sends each state indicator to the indicator of its deterministic successor. If α is the initial vector and β selects the first coordinate, then

    P(n)=α M_{binary digits of n} β,                    (3)

with αM₀=α.

To see finite generation directly, let F_j(n) be the j-th coordinate of αM_{binary digits of n}. For every e≥0 and 0≤r<2^e, append the e-digit zero-padded expansion of r. Equation (3) gives

    P(2^e n+r)=sum_j F_j(n)·(M_{e-digit expansion of r}β)_j.

All coefficients are integers. Thus every element of the 2-kernel of P lies in the integer module generated by the finitely many functions F_j. This module is finitely generated; a submodule of a finitely generated abelian group is finitely generated, so the module generated by P's kernel is finitely generated. Therefore P is 2-regular. Using the prior equivalence with d finishes the proof. ∎

## Consequence and remaining task

The published nonregularity conjecture is exactly the assertion that the marked-optimum predicate C is not 2-automatic. The argument supplies a two-way reduction, not a decision about that assertion. A proof that C has infinitely many distinct binary-kernel elements would settle the conjecture; a finite DFAO for C proved correct on all inputs would refute it and automatically provide a linear representation for P through the construction above.

Neither alternative has been established here. In particular, the finite-state representation in this proof is conditional on an actual finite DFAO for C; it does not manufacture one from the unbounded shortest-path definition.
