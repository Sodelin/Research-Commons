## Current direction

Nolan requests a generalizable explanation of when external representations improve research, alongside tests in our actual Commons. Local usefulness and generality are separate obligations. This run will not equate a schema check or a small pilot with universal validation.

The literature supports purposeful retrieval, preserving source context, and explicit update handling. It does not establish that graphs, tiny atomic notes, JSON, or another repository always improve outcomes.

- [A-MEM, NeurIPS 2025](https://papers.neurips.cc/paper_files/paper/2025/file/19909c36f51abc4856b4560aff3d36d6-Paper-Conference.pdf): active indexing/retrieval/linking/evolution pipeline; not raw GitHub persistence.
- [LongMemEval, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/d813d324dbf0598bbdc9c8e79740ed01-Paper-Conference.pdf): flat indexing is a strong baseline; atomic compression can lose crucial information; temporal retrieval and reading choices matter.
- [Karpicke and Blunt 2011](https://learninglab.psych.purdue.edu/downloads/2011/2011_Karpicke_Blunt_Science.pdf) and [Blunt and Karpicke 2014](https://learninglab.psych.purdue.edu/downloads/2014/2014_Blunt_Karpicke_JEDP.pdf): retrieval activity can matter more than drawing maps versus writing paragraphs.
- [Bergman et al. 2010](https://onlinelibrary.wiley.com/doi/10.1002/asi.21415): human folder-navigation associations do not specify an optimal agent hierarchy.
- [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/): historical models show context-position sensitivity; current models need their own tests.

Full source extraction, limitations, tests and synthesis will be added in this namespace.
