# Structured CAD value execution

This is a concrete boundary required by the inherited G7 CAD selector: an exact symbolic cell value must become an executable, observation-only algebraic action. `cad_value_export.wl` exports typed JSON syntax directly from Wolfram expression objects. It does not parse supplied expression text. `cad_value.py` evaluates that syntax on closed real-algebraic recorded observations and earlier own action coordinates, emits an exact defining-polynomial codec and replays it.

The exporter supports exact integers/rationals, declared history/earlier-action symbols, sums/products, integer powers, principal rational powers, Min/Max and univariate polynomial Root objects. Undeclared symbols, approximate values, transcendental functions, duplicate names/identities and malformed mappings return UNKNOWN. The declared coordinate namespaces and original backend code/output are recorded. Multiple-function Root systems and arbitrary Root neighborhood representations are excluded.

The root evaluator enumerates all distinct real roots by exact QF_NRA and an explicit final UNSAT query, orders the closed values, derives each input-polynomial multiplicity by exact successive derivatives, and selects the requested index. Wolfram's Root indexes count multiplicity: Root of `(x-1)^2(x-2)` has real values [1,1,2]. The output number codec uses its own defining polynomial and root index; these indexes must not be confused. Official indexing and symbolic-parameter documentation: https://reference.wolfram.com/language/ref/Root.html . The stored fresh multiplicity control matches this convention.

Principal fractional powers execute only at nonnegative real bases, with zero forbidden for negative exponents. General complex principal powers are UNKNOWN. A zero leading coefficient requires a separately exported lower-degree cell; it is UNKNOWN here. Node/depth/degree limits are explicit execution resources (defaults 4096/64/128), not source bounds or mathematical NO. Every solver query has a configurable timeout. Neither that timeout nor these limits promise a universal wall-time bound for exact preprocessing.

The structured AST retains written divisions and negative-power domains. However a CAS may simplify an expression BEFORE export. Therefore the producer must preserve the original domain restrictions in the certified winning relation and its cell guards. Exporting a simplified value alone never proves its original written-domain, history-reachability or scientific admission conditions. The earlier affine compiler's written-domain guarantees are not inferred from this serializer.

Fresh exporter controls retain all raw Wolfram 15.0.1 code, warnings and output. Five successful forms include a history-dependent quintic Root, square root, midpoint, reciprocal and minimum. Seven malformed/undeclared forms fail closed. Python tests exercise the exact exported objects, repeated and simple root indexing, algebraic coefficient fields, earlier own roots, zero roots and denominator/resource boundaries. Generic decisions remain SAME_BACKEND.

The source replay uses the unchanged admitted four-taxon/one-original-hybrid provider and the already reviewed three-call policy. It replaces only the executable quadratic selection with the actual exported principal-power AST; the original source graph, positive edges and gamma still predate all calls, both fixed modes are separate, and the third action consumes the second observation's irrational coordinate. Whole original histories and target coordinates replay with PATH [3,2,1]. The unchanged symbolic policy proof at package manifest `01a30dea3eff2b77bf4a8f0be5b4d4626d30eb8e8c45c00b35967137d2d4776f` has 216 obligations; this package reuses that proof and does not relabel it as a new symbolic proof. `PROVIDER-BINDINGS.json` pins the exact borrowed source closure and derives the new driver explicitly.

Run `python3 run_workflow.py` with the official Python dependencies in `requirements.txt`. The workflow performs only the new AST controls and exact source replay. Fresh Wolfram exporter execution is separately recorded; running that source again requires Wolfram Language. The initial exporter control and final strengthened mapping control are both preserved.

This package executes supported cell VALUES. It does not yet compile arbitrary cell guards, connect every complete winning-action fibre to recursive resource states, or prove coverage of every generic policy branch. Complete history-first CAD-to-policy compilation, generic adaptive synthesis, G3/G4 unknown-size recognition, empirical admission and Lean certification remain open or separately scoped. A value-export or point result alone is never a whole-policy or global source-recognition certificate.
