# Preserved independent review and replay evidence

Contributor: dot (OpenAI), 5 October 2026.

This is a closed archival supplement covering retained independent reviews, exact controls, development drafts and replay outputs that are not already delivered as exact public blobs or lossless decoded artifacts. It adds no mathematical, implementation or empirical acceptance. Historical status statements refer to their original versions and dates; use the separately published final source/review chains for current claims.

[COVERAGE.json](COVERAGE.json) classifies the complete 01:21 UTC scan of 1,162 retained files in 43 reviewer/assessment directories. It distinguishes exact existing public bytes at commit ce6f64b6, existing lossless raw identities, separately queued component/projection coverage, this archive, raw attribution predecessors and a redundant public-tree listing. This scan is not an assertion that every historical original was recovered or that the final queued components are already on main. The final combined preservation register supplies their delivery status.

[RAW-IDENTITIES.json](RAW-IDENTITIES.json) identifies all source bytes delivered here. Large JSON outputs use deterministic lossless gzip, with original size, SHA-256 and Git-blob identity retained. Small files and previously compressed files are unchanged. This archive preserves incomplete or superseded replay directories as evidence, not as standalone current software distributions. Referenced provider/package paths may belong to the separately published source packages.

In particular:
- Folders called disposable/replay may contain earlier candidate implementations, failed controls or nondeterministic solver receipts. A recorded PASS is not new independent acceptance of that historical version.
- Restore-test fixtures deliberately contain conflicting/non-JSON bytes at receipt-like names. Their classification is explicit; they are negative-test data, never proof receipts.
- A file named pre-syntax is a failed draft, not the accepted checker.
- Raw attribution predecessors and private-path metadata are not silently reclassified as exact public recovery. Neutral public projections retain their separate hashes.
- No raw biological alignment, proprietary source, private correspondence or credential is part of this archive.

Run python3 verify_archive.py to verify all delivered raw identities, decoding in memory without writing or executing archived programs. The original build/backend runs are not repeated. Archive scripts have varying dependencies and historical relative paths; publication does not endorse running an old candidate.

The original full G3/G4, NANUQ composition and empirical/statistical inference obligations remain unchanged. Preservation is the gate before further implementation or mathematical expansion, not a substitute for correctness or a claim that all work is complete.
