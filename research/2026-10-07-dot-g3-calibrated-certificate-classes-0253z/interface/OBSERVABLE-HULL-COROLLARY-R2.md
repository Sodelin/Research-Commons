## 1. The observable intersection, with quantifiers in the correct order

Fix the original natural COMMON eight-row menu and its finite core catalogue. Define the set of profiles not rejected by this certificate class as

    O = intersection_(P_c in V_c for every core c)
             union_c F_c(P_c).

This is a set-theoretic definition. It makes no claim of semialgebraicity, effective membership or equality with the actual source image. A profile is outside O exactly when one finite family of valid core invariants excludes its entire original fibre.

For each core one may also define O_c=intersection_(P in V_c) F_c(P). Because the catalogue is finite and its invariants can be selected independently, elementary logic gives O=union_c O_c. This does NOT replace O_c by F_c(intersection_(P in V_c) P). The generally valid inclusion is only

    F_c(intersection_P P) subset intersection_P F_c(P).

A different hidden state may survive each invariant, even if no one state survives their intersection. No compactness of nonclosed invariant sets is being assumed.

Let J_(c,n) be the earlier computable nested universal-template invariant, or the later cofinal canonical product at one shared theta. Co-finality in the family of finite semialgebraic invariants gives the equivalent observable description
