# How much of the original G2 has been recreated?

13 October 2026. Read-only capability review for Nolan.

## Bottom line

**The complete documented original G2 endpoint has already been recreated and checked.** The reconstruction also contains the substantial clock, history, full-path, joint-register, age-readout and support machinery named in the original acceptance. I found **no demonstrated missing functional theorem within that documented contract**.

The 43 unavailable original files are an archival count, not 43 mathematical gaps. Their old internal statements cannot all be compared word for word. That uncertainty does not make the current checked endpoint a miniature version.

### What the counts actually mean

- 16 original modules are byte-identical in the current package.
- One more original module is retained as an exact prefix, followed by a documented completion-reader normalization.
- 42 other original module roles have current functional providers. Some roles were split across several new modules; a role mapping does not certify every old helper declaration.
- The remaining original helper, G2EpochObservationBlocks, is documented as unused by the final endpoint. Its old statement is unavailable, so there is no sound basis to invent a missing theorem from its name.
- The current verified corpus has 68 G2 modules: 65 timed-source modules, two separately developed operator-criterion modules and one routing module. The source verification covered a 166-module project. Counts alone do not prove one corpus stronger than another.

## What could we reconstruct right now?

The named original endpoint and all its documented capability layers already have implementations. Rebuilding them again would duplicate verified work.

If a downstream consumer needs a differently shaped interface, the present source provides enough precise statements to derive small adapters. For example, an observation of finitely many blocks of the proved entire epoch path can be defined as a measurable map from that path. Mapping `actual_cross_carrier_epoch_path_law` through the same measurable observation preserves its law immediately. The necessary inputs are the original positive rates, compatible selected initial views and measurability of the specified observation. This is an available composition route, not evidence that a new “observation blocks” theorem is missing or that it reproduces the undocumented old helper.

No adapter should be built until a consumer specifies an input/output mismatch that existing theorems do not already handle. There is currently **no highest-value missing original-G2 theorem justified by this comparison**. The highest-value immediate work is using these providers in the next concrete consumer, rather than recreating the original file layout.

## What remains genuinely unknown?

We cannot enumerate and compare every private/local helper declaration in the 43 lost bodies because their original statements and raw declaration audits are unavailable. Historical acceptance establishes the full documented endpoint and named capabilities, but does not reveal every auxiliary lemma. G2EpochObservationBlocks is the clearest underdocumented interface: its name and unused status are known, its full contract is not. That is insufficient statement evidence for faithful reconstruction.

This review therefore distinguishes functional coverage of the documented contract from complete historical declaration identity. It does not claim that every possible old helper has been reproduced.

## Later extensions already available

Finite-horizon adaptive selected/observed histories, noisy adaptive histories and adaptive count-budget transport were added separately on October 9. They should be reused and credited; they are not new missing original60 capabilities. Their contracts fix the panel and declared endpoint/action or sensor interface, and require the actual row/sensor premises supplied by their source bindings.

The full all-time path theorem is stronger than agreement only at one finite observation list. Nevertheless, it is not by itself a general strong-Markov theorem at every stopping time. An arbitrary stopping-time, infinite-horizon adaptive, continuously adapted control or biologically linked-locus claim would need its own precise contract. Nothing in the surviving original review establishes that these were required unfinished pieces of the original package.

For fresh-locus repeated experiments, existing finite adaptive/noisy transcript composition is reusable once the consumer provides the actual same observation channels, row equality and conditional fresh-draw experiment. It must not be confused with a shared linked-locus latent model.
