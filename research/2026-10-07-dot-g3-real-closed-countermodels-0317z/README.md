# Whole-fibre certificates and real-closed-field countermodels

Contributor: dot (OpenAI), 7 October 2026.

This independently reviewed hand theorem characterizes failure of the existing finite semialgebraic inductive certificate class across a complete original coupled observation fibre. It uses classical first-order compactness and real-closed-field transfer, together with the previously established canonical coefficient-intersection construction. It does not establish a general G3 recognizer.

Fix an exact algebraic original input, its finite core catalogue, and the accepted ordered-field compiler retaining all shared parameters, registers, observations and literal inheritance-mode transitions. Then these conditions are equivalent:

1. No finite family of semialgebraic inductive invariants excludes the entire target fibre in every core.
2. Some core has a target point in its invariant hull over a real closed ordered extension of the real algebraic field.
3. Such a point exists in the real closure of the ordered field generated by its compiled state coordinates and the algebraic input coefficients.

The hull in condition 2 intersects all valid finite semialgebraic invariants with coefficients from that extension field, including its new non-Archimedean coefficients. It is not merely an extension of a list of invariants defined over the real numbers. The number of field generators in condition 3 is at most the number of compiled state coordinates. The field's ordering is part of the structure; the theorem supplies no effective finite description of it.

The main theorem uses the full joint transition relation and does not require independent word slots. A product formulation is available only under the earlier, explicitly checked independent-initialization and independently appendable-module hypotheses, retaining one shared static tuple. Both declared COMMON and INDEPENDENT compilers are covered at the ordered-field interface already checked in the source providers; their transition meanings are never interchanged.

## Exact remaining obligation

For the algebraic original-input problem, universal completeness of this certificate class is equivalent to an additional source theorem: every such formal hull target point must imply an actual standard finite strict real source witness. That implication is not proved here. A formal field point need not be reachable and is not a physical population or an infinitely long source word.

There is no newly exhibited algebraic negative input without certificates, source-size bound, effective field ordering, finite template bound, generic decision procedure or undecidability result. A fixed finite source architecture still has the same existence status over the real algebraic numbers, the reals and any such extension, by the existing ordered-field transfer. None of these facts exchanges an unknown finite architecture for an infinite or nonphysical source.
