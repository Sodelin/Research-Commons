## 2. Repair A: stabilize reconstructed witnesses across precision

Suppose G6 supplies actual sources N_k with observation error at most 2^(-k). If one could certify a common finite architecture budget and a common compact parameter window wholly inside original admission for a cofinal subsequence, compactness would give an exact admitted witness. Every shared parameter and every row must remain in the same witness window. Bounds on source size alone do not stop positive durations or inheritance weights from approaching forbidden endpoints.

This conditional compactness inference is valid. It gives no terminating test for finding the requisite window, or for certifying that none exists. Enumerating windows yields only another YES procedure: on a fixed compact semialgebraic source window, exact intersection with the algebraic observation fibre is already a fixed-size real-algebraic decision. An actual YES lies in some such window; an exact NO misses every window, possibly while its distance from the unrestricted source union is zero.

The quantifier needed is one window working at all precisions. G6 provides a possibly different bounded source at each precision. Its approximation budget grows with precision and is not that common window. Recognizing eventual boundedness of the selected reconstruction, or the absence of any alternative bounded subsequence, is not supplied by G6. A poor reconstruction can diverge even when a simple exact source exists, so failure of one reconstruction sequence is not an original NO certificate.

This is the inherited nonescape/compactness issue, not a new impossibility result.

## 3. Repair B: make exact fitting a finite target label

For this fixed input y, define a two-valued label on actual sources by A_y(N)=1 exactly when every original observed probability equals y. At any fixed shape this label is algebraically decidable. One might try to ask G6 whether the label-1 source image is empty, using its effective target-labelled clouds.

The proposed use is invalid without a new theorem. G6's source replacement preserves its actual target because the replaced private chains are switching-neutral for Q/S. It approximates numerical laws; it does not preserve an arbitrary exact numerical equality. The finite label alphabet alone is not the preservation premise.

To apply the same machinery to A_y, one must prove that whenever any strict finite source satisfies all equations, some bounded reconstructed source still satisfies them EXACTLY. Evaluating that claimed same-label approximation theorem at any one fixed positive tolerance would already give an input-effective bound on an exact witness, because the label-1 condition itself enforces exact fitting. This is the original missing witness theorem, not a consequence of approximate law preservation.

Equivalently, imposing the exact y-equations inside each bounded G6 catalogue tests only the bounded part of the original fibre. It need not capture the unbounded source merely because the unconstrained catalogue approximates its probabilities. No changed physical readout or observed acceptance bit is licensed here.
