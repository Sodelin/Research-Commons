## 1. A finite probability lemma, allowing an arbitrary positive remainder

Let `mu = sum_(x in A) w_x delta_x`, where A is a finite set of distinct positive real numbers, every w_x > 0, and their sum is 1. The numbers need not lie on one geometric progression. Call `(r,alpha)` a normalized positive binary divisor if

```
0 < r < 1,  0 < alpha < 1,
mu = (alpha delta_1 + (1-alpha) delta_r) *_times nu
```

for a probability measure nu on the positive reals. The remainder is not assumed to be another Bernoulli product or to be a biological source.

**Lemma.** All such pairs form a finite set `D(mu)`. For each pair the remainder is unique and finite. The following construction gives exactly D(mu).

(a) Enumerate `r=y/x` for x,y in A with y<x.

(b) On A draw an edge `x -> r x` whenever both endpoints belong to A. Since 0<r<1, each component is a finite directed path. Write its successive vertices as `a,ar,...,ar^k`, and set

```
P_a(z) = sum_(j=0)^k w_(ar^j) z^j.
```

A singleton component has k=0 and will reject this r.

(c) Take the negative real common roots zeta of all P_a. For each root put

```
alpha = -zeta/(1-zeta).
```

Divide every P_a by `alpha+(1-alpha)z`. Retain the pair if and only if every quotient has nonnegative coefficients. Its remainder nu puts those coefficients at `a,ar,...,ar^(k-1)` for each path. Zero coefficients are omitted.

**Proof.** Positivity gives `supp(nu) subset A` from the alpha term, and `r supp(nu) subset A` from the other term. In particular nu is finite. At least one supported y of nu gives both y and ry in A, proving (a).

Along one path, put v_j=nu({ar^j}). At its top, no predecessor in A can contribute; at its bottom, nu cannot put mass there since its r-image would lie outside A. Thus, with v_-1=v_k=0,

```
w_(ar^j) = alpha v_j + (1-alpha) v_(j-1),  0<=j<=k.
```

This is exactly `P_a=(alpha+(1-alpha)z)Q_a`. All v_j are nonnegative. A singleton path would require its positive weight to be zero, so cannot occur. The divisor's root is `zeta=-alpha/(1-alpha)<0` and is common to every P_a. This proves necessity, including the nonnegative quotient requirement.

Conversely, retained quotients define a nonnegative finite measure with exactly the asserted convolution. Their total mass is `sum_a Q_a(1)=sum_a P_a(1)=1`. They therefore define a probability remainder. Each polynomial division and hence each remainder is unique. There are finitely many candidate ratios, and for each ratio a nonzero polynomial has finitely many negative roots. This proves sufficiency and finiteness. QED.

Gaps in a geometric progression cause separate paths; they must not be filled with unobserved positive atoms. A negative common root alone is **insufficient**: its quotient can have negative coefficients.

For s=|A|, a coarse size bound is `|D(mu)| <= binom(s,2)(s-1)`. Multiplicities of a repeated identical binary divisor cannot exceed its common-root multiplicity in the path polynomials. Multiple individually valid divisors need not be jointly removable: every later division must still have a positive remainder. No independent source factors are assembled merely by selecting entries from D(mu).

### Direct margins from observable endpoint weights

Let x_max=max A and x_min=min A. For every divisor,

```
mu({x_max}) = alpha nu({x_max}) <= alpha,
mu({x_min}) = (1-alpha) nu({x_min/r}) <= 1-alpha.
```

The endpoint identities follow from positivity: max supp(nu)=x_max, while min supp(nu)=x_min/r. Hence both coin probabilities are at least

```
epsilon(mu) = min(w_(x_max),w_(x_min)) > 0.
```

The finite ratio list gives the additional asymmetry bound `-log r >= delta(mu)>0` whenever D(mu) is nonempty. This is an analytic bound; computation of logarithms is unnecessary for the algebraic palette algorithm. When D(mu) is empty there is no unequal binary divisor, rather than an undefined positive margin to impose.

If the atoms and weights have usable real-algebraic encodings, (a)-(c) terminate using algebraic multiplication/equality, polynomial gcd, negative-real-root isolation, exact division and sign determination. **No logarithmic commensurability oracle is required:** the path graph checks only `y=r x` on a finite set. For arbitrary real data the assertion is semantic finiteness, without an exact equality algorithm claim.

## 2. Why an actual private cell divides a legal directed marginal

Use G1's root-retained marked core. Let W be an eligible unmarked two-port word on a proper cut bridge. Choose an original taxon a below that cut and b outside its descendant taxon set. The original root-LSA and sampled-descendant assumptions ensure that this cut has a nonempty proper taxon side. Every selected displayed path from a to its meeting point with b traverses W. Changing an internal parent choice in a parallel-arm cell changes the selected arm, not whether the path traverses W or where a and b first meet outside it.

Fix an unequal cell in W. Orient its two survivals as `x_short > x_long > 0`; define `r=x_long/x_short` and let alpha be the natural COMMON probability of the shorter arm. The entire directed survival can then be written on the **same source probability space** as

```
X_ab = Z r^B,
Pr(B=0)=alpha,  Pr(B=1)=1-alpha,
B independent of Z.
```

Z includes x_short, every ordinary passage, all other private cell choices, and the actual joint distribution of outside routes/program configurations. Independence holds because this unmarked bit is a fresh natural COMMON bit with no exported register or protected control use. We integrate the outside joint law as it stands; we do not replace it by products of marginal path laws or query a conditional configuration.

Therefore `(r,alpha) in D(mu_ab)`. The lemma applies with an arbitrary positive remainder precisely because the outside graph need not itself be a serial Bernoulli word. Both inequalities for alpha follow from this *unconditional* factorization. A proof using only one conditioned outside configuration would not justify the unconditional endpoint-weight bound.

The two physical arm parameters and original parent occurrences remain intact. Orienting them is only notation: if the source's original first parent is the longer arm, its natural probability is `1-alpha`. No actuator or original ID is relabelled.

The argument works for every eligible slot in every competing G1 core. A finite union over all ordered taxon pairs gives a global target palette and, when nonempty, positive global margins. Cells in the bounded retained core, protected sites, and bits dependent on an exported register are **not** asserted to satisfy this private divisor condition.

This source factorization is COMMON-specific. In INDEPENDENT mode routing is per current lineage and there is no single B that supplies every entering copy. We do not infer the COMMON measure from an INDEPENDENT-only menu.

The representation is descriptive.
