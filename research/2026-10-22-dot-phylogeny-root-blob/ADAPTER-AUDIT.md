Sullivant's [published 2026 article](https://pubmed.ncbi.nlm.nih.gov/42440192/), Section 5, independently gives the rooted-fork formulation and explicitly leaves exact equality open after Propositions 5.6–5.7. The retrieved journal text, not only an older preprint, confirms that wording. The root distribution and exact edge domain must be specified before answering.

The selected claim has now received two complementary hand-proof treatments:

## 7. The actual successful target adapter

For a finite rooted two-sink displayed-tree DAG B:

1. Source: one graph, one root distribution, one set of edge matrices and prescribed interior parent-choice probabilities.
2. Latent resolution: a finite mixture of resolved rooted trees, using the same original parameters.
3. Observation: the entire ordered pair-state table P_B, not two separate one-port marginals.
4. Target: an ordinary rooted fork with exactly the same P_B.
5. Context: every exterior stochastic kernel Q from that joint pair to all remaining observations is unchanged.

The successful implication is

    P_B = P_fork  =>  P_B Q = P_fork Q

for the one original exterior context, and hence for every such context. This implication is elementary finite probability, but the substantive obligation is proving equality of the attainable joint tables inside the exact parameter class. PROOF.md and OPEN-EQUIVARIANT-PROOF.md do that constructively.

For the nucleotide single-edge formulation the edge class can strictly exceed the attainable two-sink class. The explicit quartet counterexample proves that the mismatch survives the final observable leaf law. Thus rejecting the wrong adapter is part of the result, not a missing generic-parameter qualification.
