# Supported alternatives to AlphaGenome API access

Codex integration coordinator, 8 October 2026. Read-only primary-source investigation requested by Nolan. No model weights, terms acceptance, account login, client creation, inference, new credential access or paid compute provisioning occurred.

**Official local inference is available.** Google DeepMind publishes [AlphaGenome Research](https://github.com/google-deepmind/alphagenome_research/tree/8112c2b95352471f7cde9635b14a9f26cf47c5d0), a JAX model implementation, with pretrained weights from [Hugging Face](https://huggingface.co/collections/google/alphagenome) or [Kaggle](https://www.kaggle.com/models/google/alphagenome). Its pinned README explicitly says weight access requires accepting separate [noncommercial model terms](https://deepmind.google.com/science/alphagenome/model-terms) and recommends at least an NVIDIA H100 GPU. The software license is Apache 2.0; weight, training/evaluation data and other artifact terms are distinct. Our application license does not relicense them.

The pinned local `dna_model.py` implements `predict_sequence` and `output_metadata`, and has a `create` function for a local checkpoint. The Hugging Face convenience factory calls `whoami`, may invoke interactive `login`, then downloads a checkpoint. It must not be invoked in a model-visible tool to collect a credential. An authorized user can acquire a checkpoint through the distributor's normal secure UI/client and approve persistent credential storage separately. Local inference should then use an authenticated local checkpoint and the required pre-cached, licensed reference/metadata assets, with automatic downloads disabled or separately bounded and authorized.

The current research project requires Python >=3.11 and additional JAX/TensorFlow/checkpoint dependencies; the recovered remote provider imports the pinned SDK's v1 API and constructs a remote client directly. The local implementation is therefore a supported alternative, **not an already-tested drop-in provider**. Preserve the inherited provider and add a reviewed local adapter rather than silently replacing it or mixing model/settings identities. Both routes still require matched context, phase and four sequence scenarios; neither establishes measured RNA, calibrated uncertainty or plant applicability.

This executor reports approximately18GB RAM, no `/dev/nvidia0` or `/dev/nvidiactl`, and no `nvidia-smi` command. Those observations do not prove CPU execution impossible, but no practical local inference benchmark or suitable accelerator has been established. No cloud GPU was ordered and no compute charges were authorized. A bounded hardware feasibility check would precede any such deployment.
