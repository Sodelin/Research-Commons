## Why these results belong together

The rare-array theorem controls the complete chronological kernel without a word-count loss, but convergence to the ordinary kernel is neither exact attainment nor nonattainment. The old accepted eight-cell theorem already supplies an exact complete-five source, so the retraction results start from real source coordinates rather than a freely chosen matrix perturbation. Their normalized version repairs an overly pessimistic inference from the unscaled Jacobian: positive-limit weight and placement margins permit a uniform normalized correction neighborhood.

That improvement still does not put a specific higher target inside the positive source image. The old sixth-diagonal coefficient supplies a concrete obstruction for the fixed seed and sufficiently small relative perturbations. Thus a sound local IFT can exist while that local chart cannot solve the next exact target. Other banks, larger normalized changes, other components and different source regimes remain open.

- Actual finite source cells, opaque current-root routing, positive physical gaps, one shared parameter tuple and original labels are retained. Formal inverse ordinary matrices are comparison tools, never physical negative-duration edges.
