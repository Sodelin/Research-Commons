SOURCE ONLY, uncompiled and unselected. This generic finite algebra module
builds banks on the same site carrier with the existing Function.extend.
All unlisted coordinates retain one background bank. Prefix k sets exactly
indices less than k to their higher-exposure bit. Consecutive prefixes differ
only at the next listed site; injectivity prevents accidental reuse of a site.

An exact single-coordinate difference identity and unequal actual arm values
imply strictly increasing exposures. Exponentiating their negatives gives
m+1 distinct survival values. If a finite set covers every bank's survival,
its cardinality is at least m+1. This conclusion is derived, not supplied.

accepted biological source law. An actual-source caller must instantiate it
with the separately derived affine bank-flip identity, derive injectivity of
actual cell sites and support membership, and then apply the supplied exact
certificate. Those source/distribution/certificate bindings are not hidden
premises of this helper. No external configuration PMF is factored, no native
floating-point calculation supplies an exact inequality, and no physical
