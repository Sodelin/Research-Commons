## What the interface does

1. Authenticate an explicit analysis request, complete six-copy/two-column dataset, selection design and source-anchored admission record.
2. Extract the nine literal integer parity counts, keeping both columns within their shared locus. The fixed character is chi(A)=chi(C)=+1 and chi(G)=chi(T)=-1.
3. Construct simultaneous intervals at a caller-selected rational error delta. The bounded radius search accepts only an exact certificate of 18 exp(-2 m r²) <= delta. It assumes no independence between the nine features within a locus. If no informative radius certifies, it returns the full [0,1] model range.
4. Convert the shifted intervals exactly into the unchanged source interface, then run a fresh pinned producer and numerical checker. Preserve all compatible sources and recompute the complete exported union widths.
5. Report separate admission, arithmetic, numerical and accuracy statuses. Unsupported admission, incomplete input or unverified numerical output cannot become a data-confidence result.
