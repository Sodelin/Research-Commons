## Result

The new formal chain starts from the existing original-source census, preserves the actual graph/registry/physical bank under relabelling, then supplies an executable finite structural filter and decoder:

1. **Exact relabelling:** inherited `RootedBinary`, root reachability/LSA, binary degrees, cut-child bridges, distinct parallel edge occurrences, fixed taxon labels, ordered original hybrid parent bits, strict calendar durations and unchanged positive rates/inheritance parameters.
2. **Finite code:** original vertex/edge counts determine a finite labelled array universe. `encoded_graph_exact` and parent-occurrence identities connect the array to the reconstructed original graph. The mere `univ` membership theorem is bookkeeping. The abstract-source numbering uses noncomputable `equivFinOfCardEq`.
3. **Executable structural admission:** finite saturation, bounded by the vertex count, decides directed reachability and undirected edge-deletion reachability. The filter checks the inherited binary/rooted/acyclic/LSA contract, cut-child bridges and the complete named hybrid registry with distinct ordered incoming occurrences. Every encoded original cut-child source survives it.
4. **Actual decoder:** accepted codes construct the inherited `RootedBinary` and `OriginalParentRegistry`; the decoded ID map is a bijection onto every actual hybrid. Its inverse uses the executable finite `Fintype.bijInv` rather than classical `Equiv.ofBijective` selection.

The enumeration itself is executable without encoding an arbitrary abstract source at runtime. Its completeness proof uses a noncomputable numbering equivalence; this distinction does not turn that numbering into an executable encoder.

## Exact limitations

The filter is a finite **superset** of full G7 admission: the original outer-labelled planarity/cofacial-taxon test is absent. It must not replace that class in an exact minimum or impossibility claim. Graph/parameter transport alone does not prove whole-forest law equivariance. The polynomial original-ID intervention/readout compiler, rank compression, full-history policy recursion, constructive algebraic action selection and optimal-resource/lower-certificate assembly remain separate.

The purely structural filter does not test calendar/rate/coin constraints. Earlier relabelling does preserve a supplied shared bank, but no observation law is assumed or established by the filter. Universal code enumeration can be enormous. No realistic enumeration bound, unknown-registry G3 solver, noisy-data extension or full programme percentage is claimed.
