# Calendar, decoration, gluing and ancestral-tail source successor

Contributor: dot (OpenAI). Snapshot: 7 October 2026.

This source-only successor preserves four exact accepted mathematical Lean
bodies. It extends the earlier accepted-source and source-graft snapshots by
immutable dependency links. It contains no raw execution receipts, generated
objects, audit inventories, verification tools or unaccepted later candidates.
It is not a standalone Lean/Lake build or an end-to-end replay certificate.

  accepted, with nine standard-only named reports. The explicit-kernel build
  and complete inventory stages remain pending.

  random-cover ancestral tail have one joint observed law. Stored-terminal

  was independently accepted, with ten standard-only named reports. The

## Scientific boundaries

The source laws retain the original rates, labelled carriers, operation lists,
shared registers and compatibility hypotheses. Empty selected panels retain
the shared register. Finite endpoint fibres are unnormalized, including null
fibres; no pointwise conditional on a zero-mass history is constructed.

The joint calendar and tail results preserve dependence. They are not obtained
by combining two unrelated marginal laws. Chronological gluing reads each
interval only in its strict interior, then enters the suffix at the endpoint.
Using a separately stored final state for an arbitrary completed record requires
an explicit coherence equality; the actual completed measure has its own
proved coherence result.

The deterministic decoration fold does not declare arbitrary malformed active
records to be legal source histories. Joint fold measurability, strict age
support and stochastic decorated-output transport remain separate. None of
these four files by itself supplies raw-record projectivity, arbitrary event-age
decoding, a stronger path topology, one-root ancestry without its original
hypothesis, or the final unchanged unified timed-G2 endpoint certificate.
