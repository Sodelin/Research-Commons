## Source-critical findings

1. Accepted summable-Hoeffding confidence inversion already provides all-time correctness for fresh-row adaptation. Sharper confidence sequences are an efficiency opportunity, not a missing G6 premise.
2. Howard’s bound covers average conditional means under dependence. Fixed source-law estimation under changing policies needs an invariant mean or a supplied conditional-model conversion.
3. Universal Inference offers an existing anytime target-testing pattern with certified upper null-likelihood bounds. Combining it with accepted G6 nets is a proposed source-specific implementation route; normalized predictable numerators and correct joint likelihoods remain explicit.
4. A DNA channel cannot simply be asserted to act on topology/bin labels. The primary MSC-JC forward model uses metric gene-tree lengths. Finite-length gene-tree estimation can be systematically biased even as independent locus count grows; inferential bootstrap support is not a uniform TV calibration certificate.
5. Specialized QF_NRA/NLSat and Wolfram real-polynomial QE fit finite hazard-cell feasibility. Generic nonlinear solver behavior, incomplete output and certificate trust must remain separated.
6. FLINT/Arb supplies inclusion-safe exponential/numerical components. Source-image feasibility and two-sided cloud approximation are still enforced by the accepted G6 construction.
7. Mathlib has concentration components worth pin-checking; no whole G6 formal verification is asserted.

### G6-08a — Joint multinomial confidence region

**Status:** CHECKED_REUSABLE_PRIOR_ART

**Existing method:** Lindon–Malek Dirichlet-mixture martingale inversion

**Exact assumptions:** Independent one-hot Multinomial(1, theta) observations with a fixed probability vector; positive preselected Dirichlet hyperparameters; unit initial mixture wealth. Conditional fresh-row application must be justified under the experiment filtration. Coordinate dependence inside each one-hot vector is intrinsic, not an iid-feature assumption.

**What saves effort:** Closed-form mixture likelihood ratio B(a+S)/(B(a) product_j theta_j^S_j); invert below 1/alpha to get an anytime joint simplex region.

**Remaining gap / non-transfer:** The inhomogeneous Bernoulli/Poisson extensions use special common multiplicative effects; they do not permit arbitrary changing genealogy probabilities. Maintain correct zero-probability conventions and outward-safe special-function evaluation.

**Use decision:** Reuse one region per declared joint row when categorical counts are available; invert against certified target images. Compare cost with accepted Hoeffding baseline rather than assuming uniformly smaller sets.

### G6-08b — Bounded-vector confidence under dependence

## Conservative executable compatible-set specification

This is an adapter specification for the accepted proof, not a new implementation or a claimed new theorem.

1. Declare the finite experiment row and alphabet, its true source-law contract, target map, chosen norm and summable confidence allocations. Each locus contributes one joint transcript when within-locus observations are dependent. A vector of marginal features is permitted for coordinate concentration without multiplying their likelihoods.
2. Maintain a simultaneous confidence region for the declared observable law. Start with the accepted Hoeffding route. The checked multinomial/vector methods can replace it only after their filtration and conditional-mean hypotheses and outward inversion are discharged.
3. Compile each candidate target into the accepted source-preserving cloud construction. Preserve common parameters across rows. A sampled set of feasible points is an inner approximation, so absence of a nearby sample is not safe exclusion. An arbitrary stochastic-box superset can be safe for exclusion but is not a complete source-image representation and can prevent termination.
4. Use certified OUTER enclosures of every target image plus the appropriate channel/truncation/numerical discrepancy neighborhoods. Discard a target only after certified disjointness from the confidence region. Inflate in the declared metric with correct coordinate-to-metric constants. An overlapping box, unresolved strict inequality, timeout or solver UNKNOWN retains the target.
5. A SAT source witness certifies feasibility only for the exact encoded constraints; it does not validate the compiler. A source-bound UNSAT result excludes only that encoded cell. Full target exclusion needs coverage of all cells. Complete convergence needs the second cloud-approximation direction, not only safe outer covers.
6. Issue a target only when the retained set is nonempty and all retained sources/targets have the same requested target value. Empty retained sets trigger contract/numeric diagnostics, never success. Keep ambiguity and nontermination explicit. The accepted local-margin sufficient condition is 2(epsilon + eta + b + zeta) < delta_m; account for each contribution once. It is not a universal sharp lower bound for arbitrary errors.

For an optional likelihood implementation, use a predictable normalized joint numerator and a certified UPPER bound on the composite-null likelihood. A feasible maximizer alone is a lower bound and is unsafe as a replacement denominator. Probability-space cloud errors need an explicit likelihood error conversion; log-likelihood is not uniformly Lipschitz near zero probabilities. No such complete adapter was executed here.
