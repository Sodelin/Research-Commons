# A private proper-bridge slot is observable inside any fixed positive exterior

Contributor: Codex whole-source subagent, delegated by the G4 lead, 13 October 2026. **Hand-derived extension of inherited triangular tomography; independent review requested.** No Lean verification, general-target closure, or historical novelty claim. The user has authorized renewed parallel research; no additional agents were spawned by this contributor.

## Exact conclusion and its restriction

Let C[-] be one fixed admitted original source exterior with one occurrence of a private two-port slot on a proper cut bridge. Choose an original taxon a below that bridge and a distinct original taxon b outside its descendant side. Keep every exterior parameter, original ID, parent occurrence, and authorized joint randomized program unchanged. The slot's driving randomness is private: it has no latent register shared with the exterior. Its incoming current roots are opaque labelled genealogies. K and L are any two finite strict admitted replacements of this same slot; they may have different unknown sizes.

For each mechanism separately, and each finite m, the following are equivalent:

1. K and L have equal complete fresh-input labelled forest kernels for every k <= m.
2. C[K] and C[L] give equal probabilities for the finitely many selected b-spine topology events defined below, for k <= m.

The tests are ordinary full rooted labelled unranked topology events in the **unchanged original source**, at original-copy allocations. They add neither a taxon nor a completion and do not change the target's exterior. When every original taxon must be sampled, use k copies of a and one of every other taxon and prune to the a copies and b. Thus at most m+n-1 sampled copies suffice. The output is a semantic exact finite decoder; its coefficients require the supplied fixed exterior. It is not an observation-only algorithm for an unknown exterior.

The same conclusion holds for a declared finite mixture of exterior configurations. Only its actual single jointly drawn configuration law is used; conditional deterministic rows are not observed. The slot must remain private and have the same kernel in every configuration used in the argument. A correlated slot/exterior register or a control that changes the slot's transition under that exterior mixture requires a joint-tensor version and is outside this statement.

Consequently, **if** a fixed private target K has an all-size finite-forcing certificate in the full private forest interface (and, for a BOTH assertion, the same physical target and shared tuple supply both modes), the same target placed in C[-] has a finite-forcing certificate against all strict rivals obtained by replacing only that slot while keeping C fixed. This is a conditional transfer and does not assume that the missing private reticulate-target finite-forcing assertion has been proved.

## 1. Selected outcomes and a universal refinement obstruction

For k labelled copies a_1,...,a_k, let F_k be the finite set of rooted binary unranked forests on these labels. Order the components of f in F_k canonically, for example by their smallest label. Define T_f by starting with the single leaf b and successively attaching each component of f as the sibling of the current b-containing tree. These are distinct rooted labelled topology outcomes because the maximal subtrees branching off the b-to-root path are exactly the ordered components of f.

Suppose an already constructed forest h on the a labels is present at the upper slot boundary. Genealogy histories are opaque thereafter: no later operation splits an existing component or changes its internal topology. Therefore a final outcome T_f is possible only if every component of h is a clade of T_f avoiding b, hence is contained in one component of f with its topology preserved. In particular,

```
Pr(T_f | h at the slot exit) != 0  =>  |h| >= |f|,
|h|=|f| and Pr(T_f | h) != 0      =>  h=f.
```

This conclusion uses no claim that the upper exterior is an ordinary population, that the first a-b meeting is fixed, or that there is no later independent splitting. Every such operation preserves opaque clades. For forests of the same root count, refinement with equal count forces identical partition blocks and identical component topologies.

## 2. The leading coefficient is a triangular matrix with positive diagonal

Temporarily work at a single k, with the entire exterior fixed. By selected-label projectivity, all unselected taxa can be pruned from the gene process. Since the slot lies on a cut bridge with b outside, the b lineage never enters the slot and cannot meet any a lineage on its younger side. Every surviving selected a lineage traverses the slot once.

Before the lower slot boundary the k fresh a lineages have produced some forest g with j <= k roots. Condition internally on this forest and on any remaining exterior configuration or state needed to evaluate later operations. Source factorization and privacy of the slot express the selected topology vector as a finite linear function of the fresh rows K_1,...,K_k, using graft substitution for a row K_j applied to the j opaque components of g. Conditioning is proof bookkeeping only.

Write that exact linear expression as

```
p_k(K) = A_k K_k + R_k(K_1,...,K_(k-1)).                 (1)
```

Here K_k is the vector indexed by F_k. A term involving K_k occurs exactly when no a merger took place before the slot. A_k[f,h] is the coefficient of K_k(h) in the selected outcome probability for T_f, including the probability of that no-merger entry event and the genuine correlated exterior law. All these coefficients are nonnegative.

By Section 1, ordering F_k by increasing root count makes A_k upper triangular, with no off-diagonal entries between distinct forests of equal root count.

Each diagonal entry is strictly positive. Choose any exterior configuration with positive program probability and any permitted finite sequence of natural exterior routes with positive probability. Require that no selected a-a merger occurs below the slot and that no merger of the selected roots occurs on any finite exterior edge after the slot. Every such no-merger probability is positive: there are finitely many selected current roots and finite edges with finite lengths. All h components and b then reach the original ancestral population without further merging. There the prescribed sequence that attaches the ordered components of h to the b-containing lineage produces T_h with positive probability. At r=|h| current a roots, that final factor is

```
kappa_(r+1) = product_(j=2)^(r+1) 1/binom(j,2) > 0.
```

This exhibited positive subevent establishes A_k[h,h] > 0. Under a randomized exterior program it lies inside a positive-weight configuration; no deterministic summand is queried. Thus A_k is invertible over the actual coefficient field. No negative-duration source or physically inverse population is introduced.

One can avoid conditioning terminology altogether by compiling the fixed finite exterior's joint boundary tensor and contracting every term except the fresh private row. The same no-clade-breaking argument gives the zero pattern, and the same positive source history gives the diagonal. The tensor need not factor into independent lower and upper marginal tensors when the exterior contains a shared program register.

## 3. Induction recovers the entire capped private kernel

For k=1 the private kernel is the unique one-token forest. Suppose K_j is recovered for j<k. The fixed exterior makes every coefficient in R_k known, so subtract its value from p_k(K). Equation (1) and invertibility give

```
K_k = A_k^(-1) [p_k(K) - R_k(K_1,...,K_(k-1))].         (2)
```

For equality rather than numerical reconstruction, the exterior need not be computationally supplied: the same A_k and R_k apply to both replacements. Equality of their earlier rows and selected probabilities forces K_k=L_k. Induction proves necessity in the theorem.

Conversely, equality of all fresh rows through m gives equality of the full opaque-forest actions through m by inherited graft substitution. Substituting those equal tensors once into the same fixed exterior gives identical selected observations. More generally it gives identical responses for any same-exterior experiment whose total slot input does not exceed m.

The count of selected scalar outcome probabilities is sum_(k=1)^m |F_k|. They may be recovered from fewer full-law experimental rows, one allocation per k. If a particular declared channel discards these rooted topology events, this theorem does not apply to that weaker channel.

## 4. Conditional transfer of a private finite certificate

Let a finite private certificate for K require fresh forest rows through M (and any declared COMMON row needed by that certificate). Use the finitely many original-source observations above in the corresponding modes. Every same-exterior replacement L matching them has the same private prefix, and hence, by the **assumed private certificate**, the same entire permitted private law. One substitution into the unchanged C proves equality of every later same-exterior response. All observations of C[K] use one physical source and shared tuple. The proof does not refit an exterior or slot between observations.

This is stronger than merely saying that a specially chosen four-taxon positive wrapper is faithful. It shows that, for private proper-bridge replacement, a **fixed positive reticulate exterior itself cannot hide a first finite-cap difference** when the full rooted topology menu is available. The inherited four-taxon theorem supplies the triangular idea; this note extends the refinement/positive-diagonal argument to the actual unchanged exterior and retains correlated exterior configurations.

## 5. Why this does not give general full-core transfer

In the original master, a rival can change the exterior graph, exterior parameters, protected core, and multiple private words at once. Its observation equation is then

```
p_k(L; C') = A_k(C') L_k + R_k(C';L_<k),
```

whereas the target has A_k(C), R_k(C;...). Equality of the observed vectors does not permit cancellation of those different operators. Finite COMMON support recovery and the finite unequal-cell divisor palette do not identify C'=C in INDEPENDENT mode or recover these matrices.

Even on one fixed graph, simultaneous changes to nested unknown words act as nuisance transformations of one another. The same-exterior proof supplies no observation-derived uniform choice of the slot's target across that fibre. A finite list of core templates is not a finite list of parameterized exterior maps.

Therefore this result discharges the **same-exterior visibility** subobligation: it is unnecessary to replace an arbitrary fixed positive exterior merely to detect a single private proper-bridge difference. It leaves the **unknown-exterior comparison** and **private unknown-size finite-forcing** obligations open. It supplies neither a rival-size bound nor an exact fixed-target all-prefix negative construction.
