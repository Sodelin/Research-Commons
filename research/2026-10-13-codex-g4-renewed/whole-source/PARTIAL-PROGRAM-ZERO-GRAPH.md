# A finite zero-gap graph can replace a single complete-control program

Contributor: Codex G4 lead, 13 October 2026. Hand-derived consequence of the reviewed original-source directed-gap theorem. Review pending. This is a legal-menu sufficient criterion for the original unknown-size rival problem, not closure for natural reticulate targets or INDEPENDENT-only observations.

## Precise menu and target criterion

Fix any admitted finite original target T and its declared finite original-ID interface H. Use one graph and shared parameter tuple for all observations. Suppose the actual BOTH menu contains finitely many paired programs P_1,...,P_m with the following source meaning. Program j jointly assigns every site in a subset H_j of H for the entire locus. Its law is the same in COMMON and INDEPENDENT, may correlate these assigned choices arbitrarily, and is exogenous to the remaining natural independent site bits. Conditioning on a positive-weight assignment leaves the inherited controlled-resolution adapter applicable. Sites outside H_j retain their original natural laws and strictly interior coins. This hypothesis does not add an unavailable control to the menu or expose deterministic summands as observations.

For each distinct pair of original taxa A,B, let Delta_j(A,B) be the INDEPENDENT minus COMMON probability of the selected crossed cherry {a1,b} on a1,a2,b under P_j. Define a directed graph G_T on the taxa by

    A -> B iff Delta_j^T(A,B)=0 for at least one available j.

**Theorem.** If G_T is strongly connected, finitely many legal paired topology observations force T's entire permitted response law against every admitted finite rival of initially unknown size having the same declared interface.

The size-bound part uses at most 2mn full-law queries with n+1 sampled copies: duplicate A and sample one copy at every other taxon, for each mode and program. Pruning supplies every B comparison. Add a finite target-dependent determining subcollection from the inherited bounded-shape polynomial theorem. The result is semantic finite forcing; this note does not claim a new effective certificate-selection algorithm.

## Proof of the unknown-size exclusion

By the reviewed [directed paired-gap theorem](UNCALIBRATED-PAIR-GAP.md), every conditioned resolution has a nonnegative directed gap. A hybrid not assigned by a program survives its resolution, with its original proper nonempty child-cut descendant set unchanged. These are the inherited resolution and ancestry facts, including parallel occurrences and suppression rules; no new core reduction is assumed.

Suppose a rival W matches the displayed legal observations and has a hybrid h outside H. Write S for the nonempty proper set of taxa below h's child bridge. It is outside every H_j. For every A in S and B outside S, the same hybrid witnesses a strictly positive directed gap in every positive-weight configuration of every program. The uncalibrated theorem and the unchanged cut imply

    Delta_j^W(A,B)>0 for every j.

The mixture remains strictly positive; no deterministic configuration is recovered from it. Equality to target data consequently forbids every edge of G_T from S to its complement. But a finite strongly connected digraph has an outgoing edge across every nonempty proper vertex subset: take a directed path from a vertex in S to one outside S and its first crossing. This is a contradiction. Thus W has no hybrid outside H, yielding the derived bound h(W)<=|H|.

There are finitely many original admitted binary source shapes with fixed taxa, bounded hybrid number and this finite interface. The already accepted fixed-shape polynomial/Noetherian determination theorem applies separately to each rival shape, preserving all original parameter restrictions and the full permitted menu. A finite union of its target-dependent determining observations, together with the preceding zero-gap bank, forces the full law. The rival-size bound is proved from legal target zeros, not inserted as a premise.

## A genuinely partial-control instance

Take any admitted ordinary tree on at least four taxa and insert one strict private bigon on each pendant edge. Mark all these n bigons with their original IDs. Let P_A assign only the marked bigon on taxon A's pendant edge; it can be any joint assignment law on that one site, used identically in the two modes. Every other pendant bigon remains natural.

Under P_A, no surviving hybrid is ancestral to A but not B, for any B different from A. The reviewed gap theorem therefore gives Delta_A(A,B)=0. The union graph contains every directed pair, hence is strongly connected. Each individual program leaves n-1 target hybrids natural. No program resolving all target hybrids and no inversion of a randomized program matrix is required. This is an arbitrary finite strict target in its specified menu, and the rival quantifier remains unbounded before the certificate is applied.

## Scope and exact remainder

The earlier one-program complete-control theorem is recovered when one program has zero gaps for all ordered pairs. Strong connectivity is a sufficient criterion for this zero-gap construction; no necessity claim for finite forcing or for the numerical gap bank is made.

For a natural-only reticulate target, its gap-zero relation is already a preorder. Every actual hybrid cut is a proper nonempty forward-closed set, so its zero graph cannot be strongly connected. The criterion therefore does not solve that remaining branch. More generally, failure of strong connectivity only says this exclusion argument leaves some possible hidden cuts. It does not supply exact rivals matching the nonzero data, higher observations, or every finite prefix.

This discharges a legal-observation-to-size-bound obligation for the stated class of paired partial-control menus, using the entire original source class and unknown-size rivals. It does not discharge the source-sensitive countable-persistence bridge, general natural INDEPENDENT/BOTH forcing, or an impossibility alternative. The graph argument is elementary and the source inequality, resolution adapter and bounded-shape theorem are inherited. No computational or Lean verification, or historical novelty claim, is made for this deduction.
