## Reproduce through the existing service

Node 24 and Python 3 use only their standard libraries. No local Lean compiler,
package installation, model API, new identity or background service is needed.
Supply the already verified native record CLI and its trusted binary SHA256:

```sh
python3 -B check_online.py --case two \
  --record-codec /absolute/existing/featurectl --codec-sha256 VERIFIED_SHA256
```

Cases `three`, `probe`, `reject-false` and `reject-sorry` use the same interface.
The driver captures the original Node return in RAM and seals it before any
record persistence. A missing codec, changed source/host version, timeout,
missing theorem audit, proof error or placeholder cannot become a PASS.
The record CLI's own existing identity and guard remain authoritative;
this wrapper grants no encryption policy or account entitlement.

The public driver itself passed a new transport-probe execution with its
real-pipe encryption binding. The two mathematical documents and rejection
