# Two-sided source and exact-law game transfer

G7ExactLawSourceTransfer is a conditional semantic adapter over the EXISTING
Experiment, Consistent, Winning, Valid and run definitions. It constructs no
physical source, native law or provider. Its Representation fields are proof
obligations that an actual provider must discharge.

A representation relates admitted physical and symbolic points with BOTH
coverage directions. Every related pair preserves its target and every exact
action response. The same pair therefore fits the ENTIRE history. Legality
and resource updates must also match. Representatives may be nonunique; actual
different-target sources with identical responses cannot be silently merged.

Eight selected declarations actually passed hosted Lean4.35.0/mathlib56a005:
related_consistent_iff, consistent_has_source, homogeneous_iff, winning_iff,
valid_plan_iff, physical_run_of_symbolic_valid, physical_pair_of_symbolic_pair
and physical_pair_of_symbolic_loss, all in Astra.G7ExactLawSourceTransfer.
Six require no axioms; physical_run_of_symbolic_valid uses propext/Quot.sound;
physical_pair_of_symbolic_loss uses the standard three. Three benign inherited
deprecation observations remain; no errors/sorry/unsafe diagnostics were accepted.

The SAME supplied plan transfers, rather than only an existentially different
plan. A valid symbolic plan then identifies the physical source's actual target
through the existing valid_run_identifies. A symbolic different-target pair or
semantic losing result lifts to two admitted physical sources fitting that
same full history. This is not one fixed pair defeating every possible policy.
