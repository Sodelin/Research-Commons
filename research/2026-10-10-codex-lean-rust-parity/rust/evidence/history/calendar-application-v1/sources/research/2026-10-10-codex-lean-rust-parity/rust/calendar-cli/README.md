# Supplied-calendar frontend

This separate package exposes the accepted exact calendar, word and ancestral-completion libraries to general JSON input. It preserves the parent package and all earlier executable identities. `calendar-solver solve --request PATH` writes a canonical `source_calendar_result_v1` to stdout; no arguments reads stdin. `calendar-solver check --request PATH --certificate PATH` performs complete bounded replay.

The request and status contract is [the reviewed application contract](../../design/CALENDAR-APPLICATION-CONTRACT-20261010T1458Z.md). The practical application's `calendar-law` command stages fresh output and invokes both replay and the independently pinned spectral/copy reference through [native_calendar_component.py](../native_calendar_component.py). It reports `SUPPLIED_CALENDAR_TABLE` only after complete coefficient, calendar-agenda and symbolic physical-substitution checks. Compiler and provider budgets can return `UNKNOWN`; provider exhaustion is not independently proved by its framing check.

The output describes one supplied original-ID graph, sampled copies, rational calendar, shared inverse rates, original hybrid probabilities and fixed mechanisms. Gamma is the probability of original parent occurrence 1, parallel edges remain distinct, and the natural register is drawn once. Physical substitutions remain exact `EXP_NEG` records on one shared bank. The command does not infer unknown sources or parameters, fit observations, establish scientific source admission, or certify a full solver.

Dependencies are exact top-level serde versions plus the complete new Cargo.lock. The [source freeze](../notes/CALENDAR-FRONTEND-SOURCE-FREEZE-1.json) binds their downloaded archive checksums and unchanged accepted inputs. The separately preserved [offline build receipt](../evidence/calendar-frontend-build-1/BUILD-RECEIPT.json) records the actual compiler and tests; the [component pins](../CALENDAR-COMPONENT-PINS.json) identify the executable and checker closure. No claim of universal third-party verification is made.
