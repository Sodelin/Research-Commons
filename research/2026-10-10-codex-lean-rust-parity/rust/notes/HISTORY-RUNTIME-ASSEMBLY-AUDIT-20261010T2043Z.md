## Older implementations that discharge real pieces

### Original graph admission is already implemented upstream

[source_census.py](../../../2026-10-01-g7-continuous-design/source_census.py), SHA256 `d004c3730d26ebffa9ec19d842adc0b86bcaac46e216228c15b295b0c5f94396`, is already pinned and staged by current `certified-bounds`. `Network.structure` checks the binary rooted DAG. `admitted` then checks the least-stable root by deleted-vertex reachability, deletes exactly the outgoing original hybrid-child occurrence for its undirected bridge test, and calls `cofacial` on the declared taxa. `cofacial` subdivides **each indexed edge** before adding a taxon-only apex and calling NetworkX planarity, preserving parallel occurrence topology. This is the existing labelled cofacial algorithm; it should not be described as absent from the whole historical software corpus.

`census(n,r)` uses binary stubs and a complete supplied original registry, including repeated-parent parallel edges. Its canonical key renames only ordinary internal vertices, fixes root/taxa/hybrid labels and retains incoming parent occurrence order. Exhausting a resource prefix is not census completeness. Universal enumeration completeness has accepted hand/source evidence; Python/NetworkX execution is not a Lean refinement theorem.

The accepted [G7OriginalAdmission](../../../2026-10-09-dot-g7-original-registry-admission-1908z/sources/G7OriginalAdmission.lean) has decidable `BinaryValid`, `RegistryValid`, `CutChild`, `sourceOfValid`, `decodedRegistry` and exact code/numbering providers, but explicitly leaves labelled planarity separate. Current Rust `Source::validate` checks binary/rooted/LSA/registry predicates; it does not call the old cut-child/cofacial checks. The [named decoder adapter](../../reuse/sources/G7NamedCalendarSourceAdmission.lean) binds only N2 and NP, including parallel false→edge2 / true→edge3. Generic input representation and full admission must not be inferred from these two fixed equalities.

### Exact observation fitting and a positive physical source already exist

Recovered [solver.py](../../../2026-10-04-dot-practical-solver-recovery-1803z/01-exact-source-solver/package/solver.py), SHA256 `42e4353d3033e807e26bc409c724fcdee2a01552a630c9364f428f92f9ffe0db`, safely parses exact law records, randomized original forcing programs and rooted/unrooted/joint-quartet readouts. `equations` compiles **all rows under one graph and parameter vector**. `verify_witness` independently checks strict algebraic positivity and every equality. `physical_realization` assigns contemporaneous leaf ages and strict internal ages, then gives each edge the exact rate `-log(x_e)/duration`; ancestral rate is one. This is real positive source reconstruction for its free-edge clock contract, already consumed by the public finite-registry path.

[verify_certificate.py](../../../2026-10-04-dot-practical-solver-recovery-1803z/01-exact-source-solver/package/verify_certificate.py), SHA256 `525b888190d03c2bf6a510a4aab271ab18fe22fa507821faed9409db142f8840`, rechecks admission, original taxa/registry, source laws, targets and physical realization. It distinguishes direct exact witnesses/linear contradictions from general UNSAT requiring disclosed same-backend replay. Complete finite exclusion compares against the actual recomputed census. [bounded_search.py](../../../2026-10-04-dot-practical-solver-recovery-1803z/01-exact-source-solver/package/bounded_search.py) enumerates additional candidate registry sizes, returns a positive witness when found, and explicitly returns UNKNOWN after any finite unsuccessful range.

The standalone solver also implements target identification and two-source ambiguity witnesses. DNA/counts/calendar laws and added clock ties are rejected. Alternative global mechanisms form a tagged union; they do not generate paired COMMON/INDEPENDENT observations from one physical source.

Two concrete composition obligations prevent blindly wiring this fitter to `calendar-law`:

1. Old [law_compiler.py](../../../2026-10-01-g7-continuous-design/law_compiler.py), SHA256 `eb829017262d571d32d2ac4e08e4afffcd00c02210e2b1ec6337dee59862cdb7`, uses **`g=P(incoming occurrence0)`** in both common and current-lineage independent routes. 2. The fitter's positive rate uses a logarithm of an algebraic survival and is generally irrational. Current calendar DTO accepts rational inverse rates.
