For cap `M≥2` and one ordered input list `(z_i,alpha_i)`, the columns are

`[1, G_3(z_i), ..., G_M(z_i)]`, where `G_j(z)=sum_{k=0}^{choose(j,2)-1} z^k`.

The constant coordinate retains **total mass**; it supplies the omitted `j=2` moment because `G_2=1`. No normalization to total mass one is required. A single output list must preserve these coordinates jointly before any source/carrier/destination is chosen.

The deterministic audited algorithm scans columns from left to right, chooses the first available nonzero pivot row, divides its complete row by the pivot, and eliminates that column from every other row. It selects the first free column, sets its null direction coordinate to one, sets each pivot coordinate to minus the corresponding reduced-row/free-column entry, and sets the remaining coordinates to zero. It verifies that every original matrix row annihilates the direction. The constant row forces both signs. It uses `theta=min(alpha_i/d_i : d_i>0)`, updates every weight by `alpha_i−theta*d_i`, removes zero weights, and repeats until at most `M−1` atoms remain. Ties in the minimum do not change theta. Retained input order fixes original index order. Every successful positive-input elimination deletes at least one atom, so the loop terminates.

The accepted formal target is [G6PositiveGeneratorCompression.lean](../../reuse/sources/G6PositiveGeneratorCompression.lean), SHA256 `1ca6ba901ef8505e9a05f68e74dfa0050dcd84b5ac74f954082c0aecd755bbe9`. Its [95-module certificate](../../lean/G6-COMPRESSION-CERTIFICATE.json), SHA256 `3568802f0ef4bb6dff41fc7c3ab51bc34144567d039cb877779cf3951de2b1f8`, records 2,492 owned declarations/1,575 theorems, full aggregate/owned audit PASS, no missing modules/owned axioms/nonstandard axiom rows. That source deliberately supplies a **noncomputable** Caratheodory existence theorem, not this algorithm's executable refinement.

`positive_tail_compression` allows `alpha≥0`, returns positive `beta` on supplied original **Fin-index preimages**, preserves total mass and all tail coordinates, and permits the empty result for total mass zero. `all_level_moments` restores the constant `j=2` coordinate. `original_population_compression` consumes those same certificates, `z<1`, the actual typed `RootedBinary`/Code, `CoLocated` for every copy and `liveCard≤M`, and proves equality of every whole original population quotient. `exists_uniform_original_population_compression` chooses the one atom list before all source rows are quantified. This already supplies the source-class moment transfer; per-row or per-carrier choices would not implement its quantifiers.

The old Python extractor uses atom values and strictly positive test inputs. The bounded private Rust consumer must additionally drop input zero weights before the loop, return empty on all-zero input, retain original indices through filtering/elimination (including duplicate z values), reject negative weights/noninterior survivals, and independently verify unique in-range selected IDs, positive final weights, cardinal bound, mass and common moments. Rust's existing `BigRational`/`BigInt` arithmetic and canonical `p/q` formatter suffice without float arithmetic. Initial cap is 2..4, matching the current copied-carrier scope; limits for atoms/frame/work must be explicit with checked integer accounting and UNKNOWN before oversized generation. Bit growth still requires process limits; mathematical equality is not a runtime cost theorem.

Root authorized a separate additive private crate after this inventory, preserving the accepted core/frontend/helper/runtime. Design and reuse are reviewing its exact limits/framing and producer-certificate correspondence. The smallest formal checker binding casts rational equalities to real geometric sums and then applies the existing certificate-consumer theorem; it does not need an RREF completeness proof to establish soundness of a successful checked certificate. Supplied rational survival atoms are distinct from exact `exp(-duration/u)` values of a rational calendar, which are generally transcendental. A valid compression certificate does **not** admit an arbitrary mixture as an original source, build a positive network, identify common-bigon baseline/private-register guards, prove one-bank source grafting, approximate a full program semigroup, or settle source admission. Those are distinct source consumers. The original three-calendar saved-output comparison remains first when the sole Lean evaluator delivers its outputs.
