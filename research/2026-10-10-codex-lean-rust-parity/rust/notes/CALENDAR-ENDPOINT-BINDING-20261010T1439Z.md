# Generated-calendar raw endpoint binding

Codex Rust implementation role, 2026-10-10T14:39Z. **Sourced finding and
conditional hand proof plan, not a new checked theorem.** This note changes no
Rust compile input, runtime, proof source, public interface or scientific gate.
The [machine inventory](CALENDAR-ENDPOINT-BINDING-20261010T1439Z.json) records the

The compatible missing lemma is: every **raw** endpoint in the effective natural
word rows for a complete original calendar has every original copied lineage at
the supplied ancestral root. It can be derived structurally from already
accepted pointwise source movements and temporal invariants. It does not require
whole-edge gathering, positivity of an endpoint coefficient or an independent
survival cube. G1/G2/G5 mathematical completion is unchanged.

## Exact accepted endpoint premise

[G7EffectiveCompletedWordCoefficients](../../reuse/sources/G7EffectiveCompletedWordCoefficients.lean)
has a fresh complete 166-module audit, with 4,599 owned declarations and 2,887
theorems in its [certificate](../../lean/EFFECTIVE-COMPLETED-WORD-CERTIFICATE.json).
Its word and natural-word identities require, respectively,

```lean
∀ row ∈ wordRows N H common word s, AncestralRoot N row.1
∀ row ∈ naturalWordRows N sample H common word, AncestralRoot N row.1
```

The original [AncestralRoot definition](../../../2026-10-04-dot-complete-original-g1-1549z/src/UnifiedLean/Source/SourceAncestralCompletion.lean)
is `∀ x : Copy, copyLocation (state s) x = .rootPopulation N.root`. This is all
copied lineages through their current ancestors, not only live representatives.
Nonempty Copy and the same positive original rate bank are explicit completion
premises. The accepted coefficient identity binds the unchanged completed
polynomial to the actual ancestral rational limit; it does not derive calendar
root support for its caller.

[SparseWordComposition](../../reuse/sources/G7SparseWordComposition.lean) retains
the raw flat-map Cartesian rows, including zero polynomial products and rows
whose later sum cancels. Native word composition instead normalizes full selected
views and retains nonzero polynomials. The current native completion guard checks
all copied populations and literal witnesses in those retained rows. That guard
is useful operational validation, but it cannot by itself discharge the raw-list
premise above. Neither a gamma=0 evaluation nor cancellation may erase a raw
nonroot branch from this proof obligation.

## Which complete agendas have the required structural support

Use one typed RootedBinary N, its actual sample map `Copy → X`, original parent
registry H, one fixed hybrid mode vector, and the unchanged full V register. Start
from the actual singleton-at-sampled-tip initial state. For natural initialization,
each original hybrid bit is drawn once with original gamma=P(parent1), with
nonhybrid bits false, before following the word. The fixed-register initial
support argument works for every register, so the natural mixture is a final
raw bind rather than an extra temporal assumption.

The agenda must contain the sorted distinct ages of **all** original vertices.
At each age a, it exits every original edge occurrence whose source has age a,
then enters every original vertex of age a. Parallel occurrences retain their
separate IDs. Between consecutive distinct dates a<b, it includes the adjacent
epoch of duration b−a, before the b boundary. There is no invented leading or
trailing finite interval. Within either boundary phase, any complete matching
date list is sufficient for the structural invariant; ascending IDs are one
such list. Exits and entries are not interchanged.

The supplied Calendar requires strict source-to-target age descent on every
original edge. It does not require zero tip ages, nonnegative absolute ages or
a common tip date. Future samples can wait at their original nodes until their
own entry date. Ties between incomparable vertices are allowed, with one whole
exit phase before the whole node phase. Strict edge ages ensure node entry never
creates an edge already expired in that phase. The last date is the maximum of
all vertex ages and, by the existing rooted calendar timing theorem, the original
root age.

An arbitrary Conditional start or caller-supplied partial word is outside this
corollary. A conditional-tail version needs an admitted starting state satisfying
BoundaryReady/AfterNodes at its starting date and a FutureComplete remaining
schedule. Omitting the root entry can leave a copy at the root node; omitting an
edge's exit can leave it on that edge when the root is entered. SourceValid or
final inclusion of an `Enter(root)` letter alone does not rule these out.

## Concrete proof/provider plan

The following are proposed new proof-only lemmas, not checked additions in this
inventory. Reuse owns their source and integration owns their eventual checks.

1. **Raw population location preservation.** Induct on `destinations N fuel s`
   from [EffectiveCoefficientSupport](../../reuse/sources/G7EffectiveCoefficientSupport.lean).
   Its branches are the entering state and actual `Choice`/`merger` descendants,
   not every arbitrary finite Code. The inherited effective population provider's
   `merger_eq` identifies these with `stepDestination N s (some p)`.
   [CalendarCompatibility](../../../2026-10-04-dot-complete-original-g1-1549z/src/UnifiedLean/Source/SourceCalendarCompatibility.lean)
   already has the pointwise `actual_step_destination_epoch`, and its underlying
   `merge_population_preserved` plus exact encode/decode copy-location identity
   prove the stronger equality for each Copy. Deduplication and `populationRows`
   map membership preserve the result without a coefficient condition.

2. **Raw full epoch preservation.** Induct on
   [FullEpochSupport.fullRows](../../reuse/sources/G7FullEpochSupport.lean), retaining
   whole ancestor-closed copied panels, not a list of live owners alone. Use exact
   panel restriction/lifting and the accepted
   [ConstructivePanelJoin](../../reuse/sources/G7ConstructivePanelJoin.lean)
   `joined_copyLocation_left/right`, together with
   [EffectivePanelJoin](../../reuse/sources/G7EffectivePanelJoin.lean)
   `joinedCode_eq_joinCode`. Each raw destination preserves the entering
   copyLocation for every outer Copy, including carried nonminimum representatives
   and the untouched exterior node panels. The existing fullRows register
   invariant remains unchanged. Thus every `epochRows` destination preserves
   EpochCompatible for any a,b when the entering state satisfies it.

3. **Raw boundary movement.** Derive raw `exitRows` membership from its pure row
   and raw `nodeRows` membership from its root/ordinary/COMMON/INDEPENDENT cases.
   The old [BoundaryLocations](../../../2026-10-04-dot-complete-original-g1-1549z/src/UnifiedLean/Source/SourceBoundaryLocations.lean)
   pointwise `exitCode_copyLocation`, `ordinaryCode_copyLocation`,
   `rootCode_copyLocation`, `actual_pulse_code_location` and
   `parent_move_is_node_movement` have no positive-mass premise.
   [EffectiveNodeCoefficients](../../reuse/sources/G7EffectiveNodeCoefficients.lean)
   supplies actual incoming-edge equality at the indegree-one ordinary case;
   effective boundary Code equalities retain original parent occurrence IDs and
   current-owner routing. Consequently every raw node row satisfies NodeMovement.
   COMMON uses the entering stored bit; INDEPENDENT enumerates one bit per current
   owner and carries each owner's entire ancestry fibre. Neither updates registers.

4. **Complete raw phase invariant.** Lift the pointwise movement lemmas through
   raw bindRows membership, using `List.mem_flatMap`/`List.mem_map`. Reuse the old
   [PhysicalSupport](../../../2026-10-04-dot-complete-original-g1-1549z/src/UnifiedLean/Source/SourceCalendarPhysicalSupport.lean)
   invariants and pointwise lemmas:
   BoundaryReady → AfterExits after all dated exits, then → AfterNodes after all
   dated nodes. Its exit-removal/no-creation and node-movement/no-creation lemmas
   already provide the necessary induction on processed IDs. Generalize over
   complete date-matched phase lists; do not infer raw-list equality from the
   accepted phase-permutation PMF theorem.

5. **Raw chronological tail induction.** Repeat the exact
   [InitializedCalendar](../../../2026-10-04-dot-complete-original-g1-1549z/src/UnifiedLean/Source/SourceInitializedCalendar.lean)
   FutureComplete/strictly ordered remaining dates argument. Its
   `after_nodes_to_epoch` and `epoch_to_next_ready` are pointwise lemmas. Combine
   them with step 2 and step 4, instead of the positive-support bind eliminations
   in `actual_calendar_tail_support`. Obtain AfterNodes at the final date and
   `∀ v, C.age v ≤ finalDate` for **every raw endpoint**.

6. **Initial and final discharge.**
   [EffectiveInitialization](../../reuse/sources/G7EffectiveInitializationCoefficients.lean)
   enumerates exactly actual `initialCode` states; old
   `actual_initial_calendar_boundary` proves readiness at the earliest date for
   each register. The final proof in `initialized_original_calendar_ancestral_support`
   then applies verbatim to each Copy: AfterNodes excludes node v because its
   age would be strictly beyond the maximum; AfterExits excludes edge e because
   its source age would be beyond that maximum; BoundaryReady fixes any remaining
   rootPopulation's vertex to N.root. This supplies raw hroot for naturalWordRows,
   including zero polynomials, and then the accepted ad551 completion consumer.

7. **Calendar occurrence and native binding.** Prove the supplied rational age
   cast is a Calendar, the exact unique date list and complete original-ID phase
   lists have the required membership/order, and each generated interval slot
   names its adjacent date occurrence. Slot renaming changes coefficients only,
   not raw destinations. For equality to the inherited compiler's event word,
   use the separately accepted phase-permutation provider and exact occurrence
   mapping at the physical law level. Universal Rust canonical encoding,
   selected-view dictionary normalization and per-step arithmetic refinement are
   still separate obligations; finite native comparisons do not replace them.

## Scope of the already accepted and pending providers

The old initialized/natural calendar support theorems prove positive-PMF support
for actual complete calendars. The newer completed-calendar theorem already
derives actual naturally initialized infinite-completion laws at the same source
bank. These mathematical consumers stay complete. The new work above is their
raw executable-row support interface, needed by the explicit sparse ad551
consumer. Empty Copy has vacuous root placement, but ad551 and native ancestral
completion require Nonempty Copy; its separate empty-source endpoint must not
be admitted by pretending this premise holds.

Structural root placement uses source movements and the calendar schedule,
independently of gamma probabilities or positive rate magnitudes. Physical word
and limit-law equality still uses the same positive original rates, original
gamma orientation, sample/parent registry and fixed modes. Inverse-rate slot
relations remain `X(slot,i)=exp(−duration(slot)/u[i])` in the current producer;
this note makes no independent slot-box or whole-edge image claim.

The old gathering chain can later simplify slot banks to original whole-edge
exposures. It is not needed for this endpoint proof and its separate pending
acceptance must not block or be assumed by raw calendar support. Current compiler
or provider UNKNOWN results contain no partial table and supply no executable
endpoint certificate. All current public/runtime/source-admission flags remain
unchanged.
