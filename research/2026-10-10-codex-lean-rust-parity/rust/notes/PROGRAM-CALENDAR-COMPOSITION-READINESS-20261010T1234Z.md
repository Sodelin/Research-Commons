## Exact state and operation order

Fix one original graph, sample map, copied carrier and original parent registry
for the entire word. Preserve distinct original edge occurrences, including
parallel edges with identical endpoints. Each hybrid has one fixed COMMON or
INDEPENDENT mode and a registry-derived ordered pair `(parent0,parent1)`.
Original gamma is probability of true/parent1, as recorded in
[SOURCE-PARENT-ORIENTATION](../../design/SOURCE-PARENT-ORIENTATION.md).
It is not the frozen LAW-v1 variable for choosing incoming occurrence0.

The existing `Context`/`Snapshot` invariant is the native canonical
`encodeActual` image: live representatives are sorted; each ancestor is live and
represents itself; well-labelled ordered genealogies partition every copied
label; a representative belongs to its own fibre; live genealogy and location
slots are present and dead slots absent; original-source descendant placement is
validated; and the register has one Boolean for **every original vertex**.
This does not describe every arbitrary inherited `Code` encoding with harmless
dead-option garbage.

At every output key retain the full ordered `SelectedView`: each outer Copy has
its ancestor's ordered genealogy and original population, and the entire vertex
register remains shared. Keep one validated canonical literal snapshot as a
range witness for that view. Representative independence of the actual source
row is an inherited theorem, so a witness can feed the next step after duplicate
selected views are combined. Never turn this intermediate latent carrier into a
declared biological observation by default. Genealogy leaves use outer local
Copy IDs; the injective `global_labels` map enters an explicit later readout.

The symbolic interface follows `OriginalCalendarSchema.Symbol`:

- `Interval(slot)` invokes the unchanged full mixed epoch on one population
  bank containing all original edges and one ancestral population.
- `Exit(e)` moves owners at original edge occurrence e to its source node.
- `Enter(v)` resolves from the fixed original graph and modes: root to ancestral,
  ordinary node or leaf to its unique incoming edge, hybrid to stored-register
  COMMON or current-live-owner INDEPENDENT. Parent pairs are not caller fields.

Each source operation keeps the full register. COMMON uses its entering stored
site bit and contributes polynomial1 in a conditional row. INDEPENDENT draws
fresh bits for current live owners at the hybrid node; carried copied labels
in a merged owner are routed together. It does not redraw the stored register.
The existing [boundary provider review](BOUNDARY-REFINEMENT-PROVIDERS-20261010T1157Z.md)
and [finite checkpoint](BOUNDARY-CHECKPOINT-20261010T1223Z.md) pin those bodies and
their finite executable evidence.

Actual generated calendars use sorted distinct original vertex ages. At the
first date execute its boundary batch. Between adjacent dates execute one epoch
of their nonnegative difference, followed by the older date's batch. A batch has
**all original edge exits before all node entries**. Within each phase the
inherited source uses `Finset.toList`; ascending native IDs need a matching
enumeration or proved same-phase permutation independence. This does not allow
an exit to commute with its own source-node entry, or a whole mixed epoch to
commute across arbitrary boundaries. Equal-age incomparable vertices share one
batch, with no inserted holding interval. `SameOrder` retains both weak order
and ties. `Calendar.edge_older` alone does not impose leaf age0; that is an
additional constraint in the current natural-cell chart.

## Initialization, bank transport and controls

`Initial::Conditional` takes one validated canonical snapshot and coefficient1.
`Initial::Natural` creates one singleton genealogy per original copied sample
at `N.leaf(sample(copy))`, identity ancestry, and empty source history. Draw every
original hybrid register bit once using the shared gamma bank; set all nonhybrid
register bits false. The polynomial of a register assignment b is
`product_h (gamma_h if b_h else 1-gamma_h)`.

There are exactly `2^h` initial full-register destinations, even for empty Copy
or an entirely INDEPENDENT mechanism. Keeping the full register distinguishes
those states until a declared readout forgets it. Across all assignments the raw
expanded monomial contribution count is `3^h`, since hybrid coordinates are
distinct and an assignment with f false bits has `2^f` monomials. Precheck both
counts before enumeration/expansion. This is different from one INDEPENDENT
boundary's repeated powers of a single gamma variable.

For declared slots0 through j−1 the proposed variable order is slot-major:
`(slot,E:0),...,(slot,E:e-1),(slot,A:root)`, then
`ORIGINAL_GAMMA:0,...,ORIGINAL_GAMMA:h-1`. This is a canonical native convention;
the typed source bank is `(J × Option E) ⊕ Hybrid N`. Rename each exact epoch
coefficient into that slot's coordinates and every boundary/initial coefficient
into the same hybrid coordinates. Repeated use of a supplied slot means the
same formal coordinate. The generated-calendar schema instead gives each
interval occurrence its own slot, identified by its word position subtype;
occurrence-rank numbering requires an explicit bijection.

Physical evaluation is
`X(slot,i)=exp(-pairRate(i)*duration(slot))` and `Gamma(h)=gamma_original(h)`.
One physical rate for each original edge/ancestral population serves **every
slot**, one duration serves every population at a slot, and each gamma is shared
through initialization and all visits. Rational sparse polynomial coefficients
are exact. Rational ages and rates can give irrational exponential coordinate
values, so a rational formal table is not by itself an exact rational physical
probability or an independent survival-cube realization. Any numerical
evaluation needs its own enclosure/error contract.

Original fixed-ID controls are a later distinct consumer. The inherited
`controlledWordPolynomial` keeps natural initialization outside control
substitution. Only transitions substitute forced gamma0/1 and use the inherited
controlled mode; forced sites route current owners deterministically. Globally
substituting in the initialized polynomial or mutating a COMMON register to
simulate forcing changes the original source law. No per-visit mechanism
mutation is proposed in this first fixed-source word consumer.

## Proposed bounded internal composition

The design role's reviewed proposal uses the existing at-most-four-copy graph
context, explicit `edge_count+1 <= 32`, at most16 slots, at most32 word symbols
and at most256 expanded word variables. These are private resource bounds, not
mathematical source-size bounds or a public RC1 operation.

The wrapper should compose exact sparse rows by left-to-right dynamic
programming, reusing the existing population, epoch, boundary and polynomial
providers. The proposed common limits are4096 logical selected-row provider
queries,65536 cumulative raw branches,262144 cumulative raw term products,
4096 normalized destinations per stage and65536 normalized terms per stage.
Design will freeze final names, defaults, order of checks and fixtures.

Required accounting:

1. Validate the entire context, initialization, mode registry, slot references
   and word before publishing any row. Precheck natural `2^h` destinations and
   `3^h` raw initial term contributions before enumeration.
2. Invoke a child provider on each deterministic current selected key/witness;
   count a logical query even for empty or identity panels/actions. Pass remaining
   cumulative child work limits, so many individually small calls cannot evade
   the word bound. Existing per-panel destination limits remain explicit.
3. For each next-stage transition table precheck total raw branches
   `sum_{current rows} outgoing_nonzero_row_count` and raw term products
   `sum_{contributions} incoming_term_count * outgoing_term_count` before
   expanding Cartesian polynomial products. These count incoming **normalized**
   polynomials and the child provider's **normalized** outgoing polynomials;
   child work counts separately account for obtaining those rows.
4. Generate the stage, sum duplicate full selected keys, remove zero coefficients
   and check normalized destination/term limits. Every surviving key has a
   validated canonical source-valid range witness with unchanged register.
   A stage limit produces UNKNOWN without a partial table.
5. Use arbitrary-precision derived coefficients and checked exponent/counter
   arithmetic. Distinguish malformed input, deterministic resource UNKNOWN and
   internal witness/coefficient failure. A cache must not change logical query
   accounting or budget-dependent mathematical results.

An empty conditional word is identity and makes no kernel query. An empty
natural word still returns its full once-drawn register mixture. Prefix states
with zero polynomial disappear before the next query. Every successful complete
row has symbolic total mass1; evaluating only a few parameter points is not a
substitute for complete coefficient comparison.

## Terminal completion, readout and whole-edge gates

A `FULL_VIEW` terminal is immediately compatible with the supplied-word scope.
An optional `ANCESTRAL_COMPLETE` terminal additionally needs every supported
Copy location to be exactly the original ancestral root population. A generic
supplied word can end at nodes or edges, so this property must be verified, not
assumed from the name of the request. For a genuine initialized generated
calendar it is already proved by the original calendar-support providers.

[G7AncestralRationalCompletion](../../../2026-10-09-dot-g7-completed-calendar-polynomial-2330z/G7AncestralRationalCompletion.lean)
justifies ancestral survival0 through the actual completion limit. The selected
completion table sums literal destination coefficients0 into full selected
fibres; it is not a direct equality of raw Code and selected indices. Its current
G7 typed consumers require nonempty Copy. The empty carrier has a separate
identity completion and must remain explicit rather than imposing nonemptiness
on the completed original G2 all-panel theorem. Completion can be deferred from
the first native word consumer until its executable coefficient bridge is pinned.

A rooted/unrooted or population-preserving unranked readout is a later explicit
finite pushforward of this joint table. Preserve shared original parameters
while summing its fibres. Existing source G1 unranked step/epoch/boundary
lumpability and G2 complete timed/all-panel projectivity are inherited results;
they are not missing new mathematical transport theorems. Admitting a readout
to the original observation menu, or a state-dependent control policy to a
physical calendar, is a distinct obligation. The existing adaptive abstraction
also already proves finite endpoint/action transcript equality for the fixed
selected carrier and same register.

The stronger whole-edge reduction is separate. The attributed
[all-original-edge exposure argument](../../../2026-10-10-dot-g7-pending-codex-recovery-0952z/source-notes/ALL-ORIGINAL-EDGE-EXPOSURE-PRESERVATION.md)
gathers only an original edge's local epoch factors across complementary actions,
between its own entry and exit, then telescopes their exposures. It retains
current-owner routing, parallel occurrence IDs and natural initialization.
It does not permit arbitrary interval variables to be renamed to independent
whole-edge variables by syntax alone.

The saved same-calendar
[G6OriginalWholeEdgeSurvivalLift](../../reuse/sources/G6OriginalWholeEdgeSurvivalLift.lean),
SHA256 `9aff47125e6a7d9ec1d6c7cc4550368f918e1b2ee8efce684c49232d8a690850`,
constructs `rate_e=-log(z_e)/whole_duration_e` on a supplied strict calendar;
reuse confirms no accepted compilation receipt for this draft. The stronger
delivered `G7OriginalSurvivalCoverage`, SHA256
`013d5d57a955e911ba808e4b1f91e5b63e8bdd4523bc1a09db64b5dfc2f73a69`,
still follows a failed `G7OriginalEdgeOperators`, SHA256
`1fbdf2ea7574fc6128b2f3025ddf4dbc43beba51559c759ba3436addafcedbf5`.
Their [delivered latest status](../../../2026-10-10-dot-g7-pending-codex-recovery-0952z/LATEST-CANDIDATE-STATUS.json)
is failed/uncompiled, not acceptance. Noncomputable logarithmic real realization
also does not turn the extracted formal table into native rational physical
parameter witnesses, supply arbitrary graph admission, or close source census,
algebraic hypothesis fibres, QE or minimax policy synthesis.

## Proposed finite acceptance and next action

The independent design oracle will compose a whole mixed-population generator
per interval and whole-Copy coin marginalization per boundary, then compare all
formal coefficients, full ordered views, original placements/registers and
literal range witnesses. Reuse/integration own comparison to actual inherited
typed providers through the sole Lean compilation lane. Relevant controls are:

- Conditional empty-word identity; natural empty word with retained unused
  hybrid register; no-hybrid initialization and empty Copy.
- Original leaf entry, positive interval, edge exit, source-node entry and root
  entry in their actual order, with explicit all-root completion refusal before
  the root-entry step.
- Repeated COMMON visits with the same register; INDEPENDENT after a merger
  carrying several Copy labels as one current owner; asymmetric original
  gamma1/3 and two distinct hybrid coordinates.
- Parallel incoming occurrences, mixed edge/ancestral panels, carried ordered
  subtrees and a nonmonotone injective global-label embedding.

  coincident incomparable original ages, malformed registry/slot references,
  exact and one-below cumulative budgets, and no partial output on UNKNOWN.
- For a later controlled consumer, forced transitions with the natural initial
  register distribution unchanged; for a later generated-calendar consumer,
  same weak order/ties and a genuinely different order-cell refusal.
