## Internal carrier and recurrence

Use a supplied admitted `RootedBinary N`, sample assignment, actual source-valid finite snapshot and specified original population `Option E`. For the first native library carrier, use at most four local copied labels, an injective embedding into the global copied-label registry, an ordered labelled tree per live representative, one exact original population tag and the entire unchanged Boolean `V` register. Genealogy leaf fibres partition the local copy carrier; each representative belongs to its own fibre. Recover the ancestor map from those fibres. Dead genealogy/population fields are `none`, as in the original `encode`; omit historical event lists exactly as the inherited snapshot does. Zero-copy unused panels have the identity row.

`CoLocated N s i` quantifies over **all local Copy**, not merely all current roots displayed by a convenient list. It permits original edge `some eid` or ancestral `none`, whose literal location is `rootPopulation N.root`; node-boundary states cannot coalesce. Every sampled local taxon must descend from that original population. For a LAW group that contains only a subset of global copies, instantiate a restricted copy carrier with its original sample assignment and label embedding. Applying the all-Copy theorem to a mixed-population global frontier is invalid; combining different groups later requires the actual population-split/factorization provider.

Enumerate ordered pairs `(a,b)` of distinct current representatives in numeric order. A merger retains `a`, removes `b`, replaces every ancestor equal to `b` by `a`, sets genealogy `a` to the **ordered** graft of the prior `a,b` genealogies and preserves every original location/register. Attached earlier subtrees remain opaque. Re-encode only live genealogy/population fields. Reverse `(b,a)` generally has a different literal destination.

Normalize exact sparse one-variable rational polynomials only after contributions are added. With `n=choose(liveCard(s),2)`, the literal full-row recurrence is the diagonal `X^n` plus, for every ordered legal choice, the recursively computed destination row lifted term by term:

`(m,a) ↦ [(m,a/(2*(n-m))),(n,-a/(2*(n-m)))]`.

For terminal live count at most one, use the unchanged-snapshot constant-one row. Use fuel `card(local Copy)` as in the inherited definition, not an observation/source-size completeness bound. At every nonterminal lift, inherited degree descent gives `m<n`; do not accept division by zero or replace this premise with totalized rational division. Zero coefficients disappear exactly. Reachable destination rows may be generated without materializing the enormous `FinEnum (Code N sample)` universe, but this optimization needs a proved zero-support/reachable-row correspondence before an all-Code completeness claim.

## Unordered quotient and acceptance

The quotient forgets live representative choices and recursively canonicalizes ordered grafts by minimum copied-leaf ID, then sorts forest roots by that minimum. Locations/registers are preserved by the literal row and may be forgotten only by the separately declared ordinary-forest readout. For a requested canonical forest `F`, sum the coefficients of **all** original destination snapshots mapping to `F`. Equality to a single literal destination, or multiplying one arbitrary destination by two, is not the contract.

Each unordered current-root merger has two ordered orientations, each with the inherited half rate. The fibre sum must equal the existing `GParity.Law.edgeKernel` / Rust ordinary path kernel. In particular, two singleton roots give unchanged probability `X` and two literal merged destinations each `(1-X)/2`; their common unordered destination has `1-X`. Three singleton roots give six one-merger literal destinations, each `(X-X^3)/4`, and three unordered one-merger destinations, each `(X-X^3)/2`. The full three-root terminal fibres have probability `1/3-X/2+X^3/6`. These are hand-derived controls, not substitutes for the general quotient proof.

Acceptance must include:

1. Actual compiled Lean output from a type-safe original `RootedBinary`/`Code` fixture using the **inherited effective coefficient definition**, including actual code generation. Compare all normalized literal destination coefficients against Rust.
2. An independent exact ordered-half recurrence oracle that retains representatives and ordered grafts; compare every literal coefficient and the complete unordered fibre sum, rather than only total mass.
3. Zero/one root, two/three/four singleton roots, nontrivial already-carried subtrees, a nonminimum representative, restricted global-label embeddings and different frozen registers. Check original descendant validity and preserve all original IDs/population tags.
4. Exact quotient equality to the existing LAW edge kernel, with no changes to accepted public protocol bytes. Prove label transport and representative/graft-orientation lumpability before a general source-law refinement claim.
