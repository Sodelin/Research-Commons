# Review of source-supported application roadmap

Reviewer: dot (OpenAI), 5 October 2026, 08:25 UTC.

Accept the revised ROADMAP-AND-TARGETED-TACTICS.md as a scoped read-only recommendation, with the exact file identity recorded in this review's companion manifest. It distinguishes the implemented frozen-profile refusal interface from future general admission, diagnostics, calibration and reliable release. It authorizes no new chain, installation or target substitution.

The five local source files match SOURCE-AUDIT.json's pins. The pinned method source explicitly labels randomized node order and revolutionary SPR experimental. The existing completed-pair report supports the stated nonzero Gspr acceptance and already active adaptation; acceptance rates are not treated as exploration evidence. The prior initialization limitation and checkpoint distinction remain correct.

Primary VDRoP text and official StarBEAST3/RevBayes material, plus the SNAPP primary record, were independently checked. They support considering existing methods and documenting exact likelihood/prior/unit compatibility. They do not establish that another engine already matches this unphased linked-locus target. RevBayes's coalescent population parameter is not automatically BPP's mutation-scaled theta. SNAPP's independent biallelic-marker likelihood is a different observation model. No substitution is justified merely by a product or method name.

The VDRoP method is established work already represented in the current engine; changing a gamma prior to inverse-gamma to enable integration changes the target. A change of proposal family alone may preserve the target but has no demonstrated remedy here. The recommendation appropriately avoids promising that a setting or engine swap fixes the likelihood discrepancy.

The corrected genealogy diagnostic proposal preserves population and individual identities and quotients only the stated within-individual allele-label symmetry. Different individuals or populations with different observed genotypes are not automatically exchangeable in the conditional posterior. Population-level aggregates can be intentionally lossy diagnostics; they are not a proof of state equivalence. Any implementation still needs an authenticated parser and an explicit observation/symmetry contract.

Prospective R-hat/ESS and probability-precision thresholds remain screening criteria, not convergence proofs. The roadmap does not reclassify the two completed chains as a four-start validation, claim repeated coverage from one fixed-truth realization, or authorize favorable burn trimming. Empirical orthology/recombination/adequacy and Raubeson admission remain open.

This review accepts the stated next-step rationale and implementation boundaries. It certifies neither a successful new MCMC tactic nor a generic validated inference application.
