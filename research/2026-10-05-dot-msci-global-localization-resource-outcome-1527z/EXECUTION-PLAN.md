## Exactly five controls and finite ceilings

- Distinct/equal single-source requests: at most 1024 stage calls, 63 splits, 64 retained states, depth 16.
- Two-source and uninformative requests: at most 128 stage calls, 7 splits, 8 retained states, depth 8.
- Zero-budget two-source request: 0 stages/0 splits, original root retained.

These limits are fixed before execution. The preliminary implementation-design paragraph mentioned 512 stages; the final cap 1024 is deliberately chosen before any trial because a fully processed 63-split binary tree can require 767 scheduled stage calls. This is not a post-result budget escalation. The uninformative short circuit consumes no stage calls.

Every producer has a 120-second inner wall limit, and numerical replay has its own 120-second/count limit (at most the request's stage cap). Each stage process runs with 512 MiB address-space and 150-second outer wall limits. The accepted watchdog polls recursive regular-file bytes every 0.05 seconds, with a 256 MiB stop bound and 4 MiB receipt reserve. All nested inputs, journals, partial files and receipts count; symlink escape is forbidden. This is a polling termination rule, not a hard no-overshoot quota. Cleanup/reaping, UTC start/finish times and observed overshoot are recorded. Fresh cache prefixes with bytecode writes disabled avoid stale local source caches.

Rational input bounds remain 256 bits/160 text characters. Interval arithmetic rounds outward at 80 bits with a 2048-bit intermediate guard; the reused joint preconditioner has its 4096-bit guard. Each JSON commit is limited to 8 MiB. The replay additionally caps total authenticated journal bytes at 256 MiB. Unsupported arithmetic retains the complete pre-stage state.

## Parent-linked evidence and recovery

Each immutable commit has a safe relative name, consecutive sequence, exact parent content hash, fixed source/request/contract identities, one transition and the complete current frontier. The pre-state remains committed during evaluation. A replacement or both children must be fully recorded before the new commit is published atomically without replacing an old file.

Replay first authenticates a complete bounded path to original-request genesis, then streams and numerically re-executes every transition. Parent hashes alone are not accepted as proof. A missing ancestor, forged self-rehashed witness, invalid ancestry or incomplete numerical replay discards all inherited narrowing and returns a NEW authenticated-original-domain UNKNOWN cover. Invalid original input identity yields no cover. A killed producer remains a failed attempt even when a separate recovery validates an outer cover.

One unit mock initially tried to mutate a frozen interval object's field; the test was corrected to mutate its containing state dictionary, which is the intended pre-state ownership/refusal test. The old mock source/log remain local history. No numerical localization run failed or was repeated for that test correction.
