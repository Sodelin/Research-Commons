## 2. Every original hybrid has a child cut edge

Fix a hybrid h. Its two incoming occurrences lie on its galled tree cycle. An edge occurrence on a cycle is not a bridge, including the length-two cycle consisting of parallel incoming occurrences. By the primary equivalence above, h is incident to a network cut edge. Its degree is three, so the remaining incidence, its unique child edge, must be that cut edge.

This is not an inference that all tree nodes have a tree child. No strong tree-child hypothesis is added. It does not remove 2-cycles, 3-cycles or fair coins. The published equivalence is used as a graph-theoretic supplier; its proof is not rederived here.

## 3. The child cut is proper

Delete h's child edge e=(h,w). The component containing w is below h. It contains at least one taxon: in a finite directed acyclic phylogenetic network, following outgoing edges from w must reach a labelled leaf.

Every root-to-leaf path for a taxon in that component crosses e, because it is the only connection to the root side. Conversely, a directed path starting at w cannot leave that component: leaving would cross the same bridge backwards. Hence its taxon set equals the descendant taxon set of w and of h.

If that set were all original taxa, every root-to-taxon path would pass through h. Then h would be a stable ancestor below the root, contrary to root=LSA(X). Therefore the descendant cut is a nonempty proper subset of X. This supplies the “proper child-cut” phrase used in the later entire-I acceptance.
