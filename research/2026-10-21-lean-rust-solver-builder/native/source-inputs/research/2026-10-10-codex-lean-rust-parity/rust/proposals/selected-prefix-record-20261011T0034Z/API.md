## Callable API and retained information

`source_selected_prefix.rs` is an external private Rust module using the existing
`parity_solver` library and its exact num-* dependency versions. A later counted
scheduler harness may include it and declare those existing dependencies. There
is deliberately no Cargo target/export/build command or public protocol here.

```rust
selected_prefix_record<'a>(bank: &'a Bank, spec: &Spec)
    -> Result<Decision<'a>, Error>
```

The borrowed immutable checked bank binds the original graph/occurrences,
vertex/hybrid/sample/copy labels, height ages, physical logarithmic rate and
shared slot power expressions, fitted old g and original Gamma=1-old g, trace,
and fixed global mechanism. It does not establish that caller trace equations
were generated from that graph or prove source admission. Spec contains only:
full agenda order choice, prefix end, recorder limits, child word limits and
unchanged provider limits. No independent assignment/mode/rate bank is accepted.

`Order::NativeAgenda` retains current ascending original IDs. A supplied complete
cohort order must contain each original Exit and Enter exactly once in its
correct date/phase; interval positions and numbers remain the same. No exits
cross entries or dates. The supplied order is retained literally. All full-order
and endpoint validation occurs before initialization/resource gates. `End::After`
selects any prefix including zero letters; `End::BeforeCommon(hid)` resolves that
original hybrid vertex, requires its fixed mode COMMON, and stops before its
entry, including preceding exits and tied nodes. Ancestral completion is never
called, even if the original bank's requested terminal was completed.

The table retains entering **complete selected view** plus every ProgramStep
endpoint. Each view keeps each outer local Copy's ordered genealogy and original
population plus the full original V register. Original global/string label maps
remain in Bank; tree leaves in these views are local Copy IDs, not global IDs.
Literal representatives/ancestor IDs are omitted by the explicit observer.
Every selected state has a validated conditional range witness, not an asserted
literal Code at every path position.

States are interned by the complete selected key. DAG nodes are interned by
(parent PathId, destination StateId). Final rows carry exact polynomial weights
for entire initialized endpoint sequences. Histories ending in the same selected
state remain distinct if any earlier endpoint differs. No path factorization is
assumed. `record_views(leaf)` returns entering view first, then every endpoint.
`stored_seed(leaf,hid)` reads the original initialized register bit and checks
whole-register retention throughout. It draws no coin and proves no independence.
Table fields are private; data accessors are immutable. There is no hidden
private-bit erasure, rooted observer coarsening or register marginalization.

## Exact reusable conditional path

1. One public `word::word_row` call on the same symbolic request, Natural,
   empty word, FullView. One original hybrid bit is drawn symbolically once;
   old g is already complemented by Bank, never by the recorder.
2. For each stage/current selected state, one cached public `word_row` call on
   Conditional(current range witness), that single letter, FullView, with the
   identical context/common vector/slot count/full variables. Source_word7fbb's
   conditional initializer clones that snapshot and returns polynomial one,
   with work assignments/contributions=(1,1). Natural2^h/3^h Gamma factors occur
   only in its disjoint Natural branch. The candidate checks conditional child
   work remains (1,1) and one query, unchanged variables, unit polynomial mass,
   range witness consistency and full register preservation.
3. Multiply exact parent-path polynomials by those conditional rows; combine
   only identical complete selected sequences. Final polynomial mass is one.
   Caching reuses a conditional row, not the historical path coefficients.

All routing/calendar/clock/epoch/initializer kernels remain in the old library.
The candidate adds capped sparse rational multiplication/addition in the existing
Polynomial representation to compose record coefficients; it introduces no law
recurrence. Coefficient signs are not interpreted as probabilities. No survival,
logarithm or fractional root is evaluated. Each slot still references the ONE
physical bank in Bank, and each original Gamma axis stays in its same position.

## Resource/refusal semantics

Recorder defaults/hard counts: conditional queries4096; cumulative raw path
extensions65536; cumulative monomial products262144; frontier paths4096;
selected states8192; DAG nodes65536; cached destinations4096; conservative live
term slots65536; exponent cells4194304; scalar arithmetic operations1000000;
power exponent4096. Rational operand/result bits default4096/hard65536. Zero
limits are allowed; above-hard counts are invalid configuration. Child/provider
limits may be reduced from their current defaults but not raised by this API.

Query count is checked before stage provider calls; cumulative branches/products
before expanding paths; state/node/frontier quotas before insertion. Conservative
term reservations include current frontier, conditional cache, next frontier and
raw temporary product capacity; mass checking reserves a second term buffer.
Reservations can refuse before cancellation even when final sparse output would
be smaller. This is an operational quota, not a proof of required memory.
Rational bit caps precede gcd normalization checks; scalar operands/results are
checked at each recorder operation. Temporary integer cross-products are at most
twice bounded operand bits (plus an addition carry). Exponent sums/counts use
checked integer arithmetic. Child kernels retain their own existing caps: this
candidate does not independently bound or prove all child internal allocations.
A future actual process needs a separately approved OS/resource envelope.

UNKNOWN returns cause plus observed function-call/work metadata, with no states,
DAG, row polynomials or partial table. A child UNKNOWN keeps its original
stage/kind/population/required/cap plus the outer stage and entering state ID.
Spec/input errors, child errors and internal inconsistencies are distinct Error
variants. Function calls/work are recorded observations, not an exhaustion proof.
No public serialization is supplied; any later artifact transport must have its
own create-new and byte cap. No byte-budget guarantee is implied by this API.
