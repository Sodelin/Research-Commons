10 October 2026, 10:52 UTC. Implementation proposal accompanying a hand proof. No implementation, search instance, benchmark, numerical check or new Lean run is claimed.

## Bounded mathematical interface

Input: a supplied exact algebraic calibrated source, an original taxon pair whose actual exclusive word is W=E_a B(t,g)K with t>0 and 0<g<1, and an exact real-algebraic survival q_c in (0,exp(-a)). Durations use exp(-s); the inverse is arithmetic, not a physical signed-time edge.

The original-taxon transfer requires ALL ordered-pair natural COMMON calibration identities J and the original natural same-bank BOTH topology menu. Use the exact accepted calibrated decoder, including its unknown upper-law recursion. The admitted-testers observable-quotient theorem alone is insufficient. For source-description-only testing, the scalar moment calculation can be implemented separately without claiming an original-observation decoder.

## Proposed algorithm

1. Enumerate M=0,1,2,... and compute the exact private count rows through M for the fixed target. Set m_n=sum_j C_W(n,j)2^(-j), with m_0=1.
2. Build the ordinary pure-death matrix E_c through M from the exact q_c. Invert its triangular finite block exactly and verify E_c E_(-c)=I at the same cap. Form u=E_(-c)m.
3. For j+k=M test D_(j,k)=sum_i (-1)^i binom(k,i)u_(j+i) with exact real-algebraic sign comparison. Continue until one value is strictly negative. The reviewed theorem supplies termination for the stated overshoot input; it supplies no universal practical cap.
4. When an original-taxon certificate is requested, include the COMMON J observations and the accepted finite decoder's natural INDEPENDENT rows. Sum each decoded forest row by its number of components before forming m. Carry every positive decoder denominator explicitly.
5. Return j,k, q_c, the exact target/source pins, exact finite moment and inverse blocks, exact coefficient expression and strict negative sign certificate, plus the list of legal original topology tests and reconstruction formulas. Rechecking must not require trusting the search history.

## Important validation boundaries

- A positive deconvolved finite block or a run with no negative value yet is not a success or a full moment-positivity certificate.
- Arbitrary real c is not covered by the finite exact input interface. The available q_c=q_a/2 is one admissible algebraic choice.
- The residual source in the soundness theorem is positive, projectively consistent and exchangeable on current roots, with the actual private-source semantics.
- For overshoot soundness it suffices to reject one nonnegative Bernstein monomial expectation; do not replace this by numerical near-negativity.
- All original source hypotheses, row identities and calibration tests must remain in the returned certificate. Do not substitute independently fitted kernels, unregistered channels, hidden root counts or exported registers.
- A matching finite response tuple is excluded only when its corresponding actual exclusive word has a justified ordinary prefix of duration at least c. Smaller-prefix rivals remain unresolved.
- This is separate from the frozen 53-profile Lean build and from the unresolved G4 master. Any future compiler or practical execution is new evidence, to be recorded by its actual run.
