The future operation is solely `lean --src-deps`, one process at a time. Each
query preserves its exact source, command, working directory, selected
environment, route-equivalence identity, output and receipt. A missing provider,
changed body, output mismatch, exhausted query budget or failed query preserves
incomplete evidence and prevents a closure claim. The maximum is2500 queries
and ten seconds per query. Outputs above4MiB are rejected after the child exits;
the outer guard separately enforces its chosen finite file-size limit during
execution. Output must be a new direct
`/workspace/scratch/astra-full-accepted-import-query-*` directory. No existing
plan, source, object or state is overwritten and no next build starts.

Actual execution awaits independent source review, the full capture successor,
and an explicit quiet-window release from the sole compiler owner. A finite
outer guard must also constrain CPU, wall time, address space and file size,
with the established4GiB physical stop and disk/RAM floors. This draft does not
authorize increasing those limits. No actual query command is recorded as run.

The resulting source plan will not authenticate compiled objects or establish
that any aggregate passes. Exact owned/external object selection, fresh versus
