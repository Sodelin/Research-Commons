# Proposed scientific validation for both modules

Status: PROTOCOL DESIGN ONLY, version 1, 2026-10-08. No biological results, inference or fitting. The [dataset register](DATASET-REGISTER.md) identifies actual primary evidence and pending gates. This protocol complements implementation tests; mock outputs, the TERT demonstration and DNM1 reproduction do not constitute scientific validation.

## Admission and the frozen evaluation unit

Before predictions or fitting, freeze an artifact manifest with reference build/hash, all construct sequences, original coordinates, phase provenance, REF/ALT edits, cell/ontology/strand, transcript or site annotation, assay units, replicate identities, file hashes, permissions and model/SDK/scorer identifiers. Verify REF and reject conflicting/overlapping edits. Preserve matched indel coordinate maps. Report hypothetical cis separately from experimentally constructed cis and observed phased material. No personal genomes or participant-level biobank records enter this plan.

Admit the quartet REF, A, B, A+B only when the same construct window, biosample, assay and replicate design provides all four measured conditions. Artifact absence, unmatched contexts or missing labels are exclusions, not imputed joint observations. Report paper counts, available manifest counts, eligible counts and excluded counts separately. Freeze exclusions without looking at held-out prediction performance. Study-provided quality rules and required measurement uncertainties must be recorded before label processing.

Group all alleles, pair windows, replicate measurements and shared-gene/locus records. Connect groups whose chosen genomic model windows overlap; keep each resulting component in one split. Synthetic reporter families are grouped by parent construct. This avoids splitting near-identical constructs and shared prediction context. With salt `research-commons-molecular-v1-20261008`, SHA256 of the canonical group key assigns residues modulo 20: 0–13 development, 14–16 validation, 17–19 test. The exact members/hashes and counts must be saved before any fitting or test predictions. If grouping leaves too few independent components, report that failure and register a new protocol before evaluation; do not weaken grouping after seeing test outcomes.

The procedure above is predeclared, but no actual split manifest exists yet. A dataset split and exclusion from model training are different requirements: apply the per-version exposure checks in the register. Without those checks, label results “exposure unknown,” not independent generalization. Reproduction records are segregated from all held-out sets.

## Module 1: combined DNA variation

On one fixed reference window, make REF, A, B and A+B using original coordinates. Keep the model version, biosample, strand, transcript/mask, output family and aggregation identical. For a signed molecular readout `f`, define `ΔA=f(A)-f(REF)`, `ΔB=f(B)-f(REF)`, `ΔAB=f(A+B)-f(REF)` and `I=ΔAB-ΔA-ΔB`. The additive baseline predicts `ΔA+ΔB`; the combination predicts `ΔAB`. Define the analogous measured interaction from the four same-context assay values. These are interactions on the declared measurement scale, not evidence of direct biochemical contact.

For expression, declare natural-log abundance with the official scorer pseudocount and aggregation order, and convert a measured log2 contrast by the known `ln(2)` factor when the biological endpoint actually matches. Never add AVI PHRED scores, quantiles, absolute maximum scores or unrelated tracks. For usage fractions, declare a signed fraction or fixed log-odds scale before scoring, with a predeclared pseudocount. Maximum-absolute PAS/splicing scores cannot supply the sign needed for a signed interaction.

Primary module 1 comparison for the Siraj regulatory **transport stratum** is the paired difference in Spearman correlation with measured combined regulatory changes: combined score versus additive score. Secondary outcomes are interaction-sign agreement where measurement uncertainty excludes zero, interaction rank association and direction agreement. Do not calculate cross-unit abundance MAE or describe calibrated endogenous expression accuracy from reporter activity. A directly matched endpoint stratum may additionally report MAE of the signed combined effect after the fixed physical unit conversion. A constant additive interaction is zero; its correlation is undefined and must remain undefined.

Report all available eligible pairs, including weak/negative interactions, rather than selecting pairs by model score or statistical significance. Pair distance, cell type, reporter window and effect precision are predeclared descriptive strata. Whole-locus bootstrap comparisons use the same held-out groups for both methods.

## Module 2: RNA processing beyond collapsed expression

Register each target as direct, derived or unavailable. RNA-seq abundance, splice-site usage and splice-junction counts have different meanings. PSI is derived, not a direct model output. PAS effects derive from RNA-seq coverage in the official scorer; there is no independent direct PAS track. Derived readouts must preserve the same transcript, donor/acceptor or cleavage-site set, strand and biosample across REF/ALT and measurements.

Use Vex-seq only after mapping a measured exon-inclusion target to a defensible predicted PSI readout. Primary metric is held-out MAE of `ΔPSI` on a 0–1 scale; secondary metrics are effect-direction agreement, Spearman correlation and residual error by expression/read-depth strata. If only an incompatible site-usage quantity is available, it is an unavailable primary target, not PSI.

Use APARENT measured isoform/cut records only after defining matching proximal/distal sites and a coverage-to-usage readout. Primary metric is MAE of the change in proximal usage; cleavage-distribution distances are secondary only when the predicted and measured position distributions have the same support and normalization. Maximum-absolute PAS scores instead permit magnitude-ranking evaluation, clearly labeled as a different endpoint; they cannot replace signed usage or a cleavage distribution. Random reporter sequences and endogenous PAS variants remain separate context strata.

The expression-only comparison is an **unfitted baseline**: retain REF relative junction/isoform usage and scale total abundance by the predicted total expression change. This predicts zero change in relative usage. The RNA-expanded readout uses the predeclared splice/junction information or positional RNA coverage to predict relative usage. Compare paired MAE reductions against that baseline and report total-expression effects separately. PAS coverage and collapsed expression may come from the same RNA-seq modality; they are additional spatial information, not independent evidence. No stacking, regression or learned weighting of service outputs is authorized by this plan.

The Siraj RNA/DNA reporter activity provides a regulatory-expression candidate, not intact-tissue gene abundance. Endogenous expression claims require a separately admitted RNA-seq dataset/readout and exposure audit; they are not inferred from reporter performance.

## Uncertainty, failures and permissions

Use 2,000 deterministic locus/component bootstrap resamples for 95% intervals on each paired metric difference, preserving within-group dependence and experimental replicates. Experimental uncertainty comes from replicate-aware assay estimates; model predictions alone provide no calibrated confidence interval. Do not add an unsupported model confidence score. Label unidentifiable intervals, low effective group counts and zero-variance correlations explicitly. Threshold-dependent secondary precision/recall requires labels and thresholds fixed on development/validation, with no test adjustment.

Report refusal/unavailable counts and evaluated coverage against all eligible records. Failures include REF mismatch, incompatible window/indel alignment, unresolved phase, absent cell type, annotation/readout mismatch, missing quartets or replicates, zero-denominator usage, out-of-context synthetic sequences, unavailable outputs, unknown exposure and API/protocol errors. An unavailable splice/PAS endpoint never becomes zero. Present performance among evaluated records together with coverage and exclusions; selective success is not full-cohort performance.

Artifact terms are an actual gate: the FAQ states AlphaGenome outputs generally are noncommercial and must not train other ML models. This plan chooses predeclared, **nontrained** ablation/scorer analysis subject to applicable terms. Fitting on raw Atlas/API predictions, a learned combined predictor or a learned calibration/stacking layer remains PENDING artifact-specific permission and authorization. Dataset permission, code permission, output permission, redistribution permission and access credentials are separately recorded; a permissive SDK license does not cover predictions. No experimental data, API inference or model training is requested by this source-only packet.

Scientific success requires reproducible improvements on admitted, genuinely held-out matched molecular endpoints with uncertainty and failure accounting. It does not establish clinical risk, causal interventions, ancestry/genealogy reconstruction, BIO-4/BIO-5 admission or G6 completion.
