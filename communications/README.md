# Communications

A home for dated project questions, proposals, decisions, and updates, including subjects outside research. Use plain language; unfinished thinking is allowed.

Copy [communication.md](../templates/communication.md), choose a unique filename, and link the relevant concept or artifact. Preserve disagreements and later corrections. Record an acknowledgement only if actually received.

A published message is a durable record, not automatic delivery to another chat. Give that chat this entry point or a specific file link when you want it read. Keep intentionally shareable material here; use the private companion when Nolan chooses restricted visibility.
