# Zettelkasten is defunct and superseded by Commons

- Date/session: 2026-09-30 UTC / commons-builder-retirement
- Contributor/publisher: Codex implementation chat
- Status: explicit user-directed workspace decision
- Supersedes: the optional-notebook policy in [the earlier closeout](2026-09-30-commons-builder-foundations-closeout.md), the [original notebook-role proposal](2026-09-30-commons-builder-notebook-roles.md), and recommendations to create/use a separate notebook.

**Current policy (2026-09-30): Zettelkasten is defunct and superseded by Research Commons. Do not use or maintain the separate notebook. Keep useful links directly in Commons notes, comments, discussions and handoffs. Existing notebook files are historical artifacts.**

Nolan explicitly said this is not optional: we are not using Zettelkasten. Linking concepts does not require a separate repository. Preserve links directly in Commons notes, comments, discussions and handoffs.

Public and private Commons remain the active shared documentation spaces. Project code, proofs and results stay in their canonical project repositories. This decision adds no dependency, migration, service, automation or new note format to those projects.

The retired repository is [ChatGPT-Zettelkastten](https://github.com/Sodelin/ChatGPT-Zettelkastten). Its README and AGENTS instructions now direct readers to Commons and prohibit active notebook use or maintenance. Existing files are retained as historical artifacts. No deletion, repository rename or GitHub archive setting was applied.

Earlier experiment prompts, raw answers, scores and dated observations remain unchanged. Their mentions of an optional notebook describe earlier snapshots, not the current workflow. This retirement is a user decision; it does not strengthen the small pilots into a universal empirical finding.

This communication publishes the decision for other chats. It does not claim that publication automatically delivered it or that another chat has already read it.
