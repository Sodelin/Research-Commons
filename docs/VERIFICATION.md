# Setup verification

Publication checks are in progress. The completed record will identify the commit tested, files retrieved, link checks, historical-file recovery, and remaining untested scenarios.

The workflow is manual Markdown capture and handoff. No automated cross-chat reading, notification, polling, redaction, or scientific validation is installed.

## Acceptance scenarios for real use

1. A read-only chat supplies an attributed Markdown packet; a writer publishes it while retaining original authorship.
2. Two chats add separate contributions; both survive a concurrent update, including shared navigation.
3. A correction links to its original; readers can identify the current conclusion without erasing the original.
4. A later chat resumes from an interruption checkpoint without relying on the earlier chat's availability.
5. A deliberately shareable public summary stands alone without exposing restricted contents.

These are not all completed merely because templates exist. Operational checks and empirical effectiveness will be reported separately.
