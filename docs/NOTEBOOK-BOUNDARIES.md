# Three useful kinds of memory

The commons and a Zettelkasten organize different things. Nolan requested both kinds of documentation; the Zettelkasten repository's exact name and URL have not yet been verified.

| Space | Organizing principle | What belongs there |
|---|---|---|
| Zettelkasten | A linked concept or reusable idea | One concept per note, stable identifiers, explicit links, distinctions, sources, and evolving interpretations |
| communications/ | A dated exchange, question, proposal, or decision | Research or nonresearch project coordination, disagreements, requests, and context for the next participant |
| timelines/ | What happened and when | Dated observations, decisions, corrections, and artifact links |

A notebook's concept links can point to a dated communication as provenance. A communication can point to the relevant concept instead of restating it. A timeline links both without becoming their canonical content. Avoid automatically copying everything into every space.

A Zettelkasten can be an Obsidian-compatible folder of Markdown files in GitHub. Keep human-readable filenames or stable IDs and plain relative Markdown links for broad readability. Obsidian-specific features are optional; their implementation is not part of this setup. Once the repository exists, record its verified URL in projects.md.

Private visibility can reduce audience pressure while drafting. It does not make factual claims exempt from evidence. Public exploratory notes are also acceptable when labeled provisional. Decide visibility by the actual contents and intended readers; never store credentials or identifiable client records in either commons.

The current recommendation is to use commons folders for communications and chronology. A separate communications repository is worthwhile only when its audience/access differs, its volume impairs navigation, or it serves a separate ongoing project. No extra repository is needed just to preserve a question outside research.

These are asynchronous records. A published message is not automatically delivered or read, and a suggestion inside it does not authorize execution.
