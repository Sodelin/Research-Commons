# Commons first; retain the notebook

Nolan's latest direction on 2026-09-30 makes Research Commons the primary shared workspace. Research, ordinary conversation, creative work, rough ideas, decisions and chronology can coexist here. Choose visibility by the actual content and intended audience.

| Location | What belongs there |
|---|---|
| notes/ | Reusable concepts, questions, evidence, assumptions and useful connections |
| communications/ | Attributed exchanges, disagreements, proposals and decisions, including nonresearch work |
| sessions/ | Resumable state: what changed, unresolved work, source pointers and one next action |
| timelines/ | Dated observations and artifact pointers; canonical claims remain at their source |
| [ChatGPT-Zettelkastten](https://github.com/Sodelin/ChatGPT-Zettelkastten) | The existing five-note prototype, retained as optional reference material |

No repository or existing notebook work is deleted. Maintaining a parallel notebook, copying notes between spaces or building further note infrastructure is not required. See the [current decision and handoff](../communications/2026-09-30-commons-builder-foundations-closeout.md).

For a substantial relevant task, read the current entry point and decision/handoff, search relevant records, and follow a link when it helps. Read canonical evidence before consequential reuse; a compact summary is a pointer, not a substitute for assumptions or sources. Keep project results in their canonical repositories. Capture only useful changed findings, uncertainty, corrections, counterexamples or resumable state. Skip extra records when nothing useful changed and skip workspace overhead for one-step tasks when it adds no relevant context.

The [completed screens](../research/2026-09-30-memory-structure-adversary/REPORT.md) found no added accuracy or discovery advantage from linked notes on the selected small tasks. They do not establish equivalence or that links are useless. Links remain available within Commons; a separate workflow needs a concrete task benefit to justify its maintenance.

Public exploratory notes are acceptable when labeled provisional. Private notes still need evidence for factual claims. Never store credentials or identifiable client records in either Commons.

These are asynchronous records. Publishing does not automatically deliver a message or prove another chat read it. No background polling or automatic retriever has been installed.
