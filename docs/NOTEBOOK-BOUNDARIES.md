# Commons is the active workspace

**Current policy (2026-09-30): Zettelkasten is defunct and superseded by Research Commons. Do not use or maintain the separate notebook. Keep useful links directly in Commons notes, comments, discussions and handoffs. Existing notebook files are historical artifacts.**

Nolan explicitly retired the separate Zettelkasten on 2026-09-30. This supersedes the earlier optional-notebook policy. The [retirement decision](../communications/2026-09-30-commons-builder-zettelkasten-superseded.md) is authoritative for workspace use.

| Location | What belongs there |
|---|---|
| notes/ | Reusable concepts, questions, evidence, assumptions, counterexamples and useful links |
| communications/ | Attributed exchanges, disagreements, proposals and decisions, including nonresearch work |
| sessions/ | Resumable state: changed findings, unresolved work, source pointers and the scoped next action |
| timelines/ | Dated observations and artifact pointers; canonical claims remain at their source |

Research, ordinary conversation, creative work, rough ideas and chronology can coexist in Commons. Links can live in notes, comments and discussions; no separate Zettelkasten repository or step is part of this workflow. Keep project proofs, code and results in their canonical project repositories and link them here.

Choose public/private visibility by the actual content and intended audience. The private Commons follows the same workspace decision. Never store credentials or identifiable client records in either Commons.

The old notebook files and dated experiments remain preserved as historical work. Historical recommendations to create or use Zettelkasten do not override the current retirement decision. Do not delete, migrate or rewrite existing project work merely to retire the notebook.

For a substantial relevant task, read the current entry point and relevant handoff, search useful records and follow their links. Read canonical evidence before consequential reuse; a summary is a pointer, not a substitute for assumptions or sources. Capture only meaningful new findings, uncertainty, corrections, counterexamples or resumable state. Skip extra records when nothing useful changed.

The completed screens found no incremental notebook advantage on their small tasks; they do not establish universal format equivalence. Retirement is the user's workflow decision, not a new empirical theorem.

These are asynchronous records. Publication does not automatically deliver a message or prove another chat read it. No background polling or automatic retriever has been installed.
