# Component choices under the Why not Rust protocol

Choose tools for the product, integration, trust boundary and actual workload. Language is a component decision. Canonical source owner: Dot; discovery interface owner: github-maintainer-auditor; Lean E2E supplies the established PR3 gateway and evidence joins.

## Reuse inspected

Existing claims.json, CLAIM-BOARD, START-HERE, WORKFLOW and current status/duplicate-work audits are the scientific base. Exact JSON bytes, commit, digest and authorship are in dist/source.json. No parallel registry is created. The Lean gateway inspected the six-file introducing commit and current curation workflow: no generator command in those specific sources. This is bounded evidence, not proof that no prior site exists.

Existing phone native filename/fuzzy picker, supplied-transcript literal search and portable search core have different selection/literal/cursor contracts. They do not supply weighted question/assumption/prior-work retrieval. Their callable/privacy boundaries remain owned; no source or binary is silently substituted. Existing process/recovery systems remain untouched.

The public applications subtree was inspected untruncated; scientific-integration is a report/solver route. Earlier unlocated websites remain a reuse gap, and Lean asked Dot for exact overlapping tooling. This is not an exhaustive global-site census.

## Decisions

| Component | Selected base / reason | Alternatives and revisit condition |
|---|---|---|
| Claim truth/provenance | Existing owner-curated JSON and immutable sources, IDs and typed relationships; no generated scientific answers. | Parallel schemas/databases would drift. Extend through the current registry owner. |
| Full-text ranking | Pinned MiniSearch7.2.0: weighted inverted search, prefix matching and bounded fuzzy terms; cached local index. The SAME module runs in browser and Node CLI. | Pagefind is a strong Rust/Wasm base for a larger rendered-document corpus and chunked indexes. Tantivy is suitable for native/server persistence and corpus scale. A bespoke Rust/Wasm rewrite or always-on service adds no demonstrated benefit for these60 structured cards. Reevaluate on actual corpus-scale retrieval/latency/size measurements. |
| Browser interface | Buildless ES modules, semantic HTML, responsive CSS and text-node rendering; no CDN runtime scripts. | Add a framework when interaction/composition warrants it; keep one ranking implementation. |
| Agent access | Same engine/facets and exact source-pinned reuse record; explicit --refresh retrieves current public source in RAM. | Existing native clients can consume the data contract, but no actual native registration is inferred. |
| Public reader path | Existing GitHub claim anchors and generated question/connection routes; portable public source. | Private Sites preview is not a public distribution claim. |
| Hosting | Existing Sites static source/version/deploy workflow; preserve private-by-default audience. | No new credentials, private session loader, daemon, model route or native Lean job. |
| QA | Node tests and pinned jsdom for actual DOM journeys; source/link integrity checks. | No real-browser/screenshot tool was available. No visual/device acceptance is claimed. |

## Security and privacy

Only intentionally public authored claims and proof/status links enter the bundle. No private routing, runtime records, prompts, credentials or session archives. Search ranks locally and never posts queries or calls a model. Source-update fetches use public GitHub. Shared search URLs can contain the query; this is not a platform-log invisibility claim.

All source values use textContent. External links require HTTPS/noopener. Data is never evaluated as code. MiniSearch package scripts were not run; SHA512 package integrity was checked and ESM SHA256/licence retained in DEPENDENCIES.json. Test dependencies are excluded from deployment. No tokens enter the bundle.

Latest-source failure preserves the dated bundled snapshot with a visible notice. Duplicate IDs, invalid cards or dangling relationships refuse a replacement. Candidate connections remain candidates; shared principles are not theorem dependencies. Unindexed work is an explicit coverage gap, not mathematical absence.

## Integration/update contract

`python tools/refresh.py` retrieves one immutable canonical main snapshot and preserves original source bytes. Browser startup checks latest main and retains the bundled snapshot on error. `node tools/query.mjs --query TEXT --refresh` offers the same current source in memory to agents. None modifies claim truth.

reading-joins.json adds the Lean owner's already-published proof/correction/implementation entrypoints without adding a theorem premise. Canonical status/lineage remains with Dot; existing native/controller/first-writer admission remains separate. GitHub source and reader deep links use stable claim IDs, not a new naming scheme.
