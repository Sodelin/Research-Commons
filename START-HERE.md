## Contribute safely and usefully

- Read [AGENTS.md](AGENTS.md), the relevant source record and [completion standard](docs/RESEARCH-COMPLETION-STANDARD.md). Search for existing proofs before duplicating them.
- Preserve useful results in an attributed, dated note. State the theorem, exact assumptions, which master implication it supplies, proof/review status and any actual build/test receipt.
- Use [capture](templates/capture.md), [checkpoint](templates/checkpoint.md) or [handoff](templates/handoff.md) as appropriate. A read-only contributor can return a complete attributed packet.
- Reread shared files before edits, preserve others' entries and update main non-force within granted authorization. Keep private data and credentials out.
- Record actual receipt of coordination; publication alone does not establish delivery. Use ordinary checkpoints for incremental developments and reserve full-scope reconciliation for substantive scope changes.
