## Maximal completion standard

A positive return states the full class, observation mechanism, exact preserved target, necessary/sufficient conditions where achieved, constructive procedure, quantified statistical/resource promises, degeneracies and inherited premises. A negative return constructs source-admitted indistinguishable states or another genuine obstruction and states what added information can remedy it. Both separate global statements from local/finite controls. A complete component may be delivered while its promised downstream master stays open; that open register cannot be replaced by a list of successful tests.

No fixed number of larger-taxonomy checks substitutes for a coverage theorem. Computation is justified by a named proof obligation and an expected certificate. Eight-taxon optimality remains an optional bounded exact-query refinement while biological work proceeds. If the prover reaches a concrete barrier, it preserves the strongest result, the specific failed step, saved state and one next attack. Ending a turn does not establish continued background work.

## Audit output

The audit labels each conclusion established, conditional, refuted or open; checks source/observation/target correspondence; examines the strongest quantifiers and adversarial cases; verifies preserved code bytes and actual execution claims; reruns suitable small independent checks; and records corrections. Formal kernel verification and external expert review are separate gates. Canonical promotion preserves authorship and explicitly carries every remaining dependency.
